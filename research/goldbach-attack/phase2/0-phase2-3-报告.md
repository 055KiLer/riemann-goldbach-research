## 0. 一句话总结

我们把 LL 路线的缺口从"(log N)² 的三角不等式 vs δ_N"推进到**精确的结构层**，得到：

1. **新定理（[证明]）**：`S(N)·c_N = 1`，其中 `c_N = lim_{w→0} w∏_{p>2,p∤N}(1+p^{-w}/(p−2))`。它意味着 `D_N` 的 `1/w²` 双极点被 **Beta 模型 `K_N` 精确抵消**（不是被 `P_N` 抵消）；`E_N = P_N − (D_N+K_N)` 的局部奇异部分只剩一个显式单极点，系数 `κ_N = log N − log(2π) + ψ(3/4) + O((loglog N)²) ≈ log N − 2.9238`。
2. **更锐的分量范数 + 一个否定性定理（[证明]）**：`‖D_N‖_HS, ‖K_N‖_HS ≍ (log N)^{3/2}`（LL 的迹界 `α_N^{-2}` 在范数尺度浪费 `(log N)^{1/2}`）；`‖D_N+K_N‖_HS ≍ (log N)^{3/2}`；并且**三种自然的三角分解**（`P_N,D_N,K_N` ｜ `P_N, D_N+K_N` ｜ `P_N−D_N, K_N`）都给出 `Ω((log N)^{3/2})` 的下界。因此**任何"分量范数 + 三角不等式"的路线都不可能到达 δ_N**，无论 `P_N` 的估计多好（即使 `‖P_N‖_HS` 理想地只有 `(log N)²/√N`）。**缺口仍然是 √N，不是 √log。**（这一点纠正了我们中途一度乐观的 Prop 2.7；见 §3。）
3. **真正的最小未知量（[证明]+[推导]）**：唯一可能的路线是直接估计**内部抵消** `E_N = P_N − (D_N+K_N)`（在条带上的解析延拓），即"离对角素数对相关 − Beta 模型"的定量小性；这就是 Goldbach 主项抵消的算子形式。我们证明了这个量**严格强于**任何加权二元 Hardy–Littlewood 数据（"真超平面"壁垒），并把它的 HS 范数展开为**四个零点纵标的跨特征标加性能量**（严格强于 Montgomery 对相关）。
4. **数值事实（[数值]）**：LL 的有限谱模型**可以复现**——在补上 `S(N)c_N=1` 的双极点归一化后，N=30030、H=40 的矩阵特征值给出 `max|eig| = 0.357462`、`−0.353421`、`‖C‖/δ_N = 0.8269`，与论文 Appendix B 的 `−0.353421 / 0.357462 / 0.826864` 一致。这同时验证了第 1 条新定理的必要性：少掉这个归一化，矩阵范数会错到 ~105。
5. **结论**：仍然没有 Goldbach 的证明；但"墙"现在是一个**精确的、可陈述的、比 Goldbach 加权渐近更强的 L² 算子范数问题**。任何下一步工作都必须正面攻击 `E_N` 的内部抵消，而不是分量估计。

## 1. 新定理：D_N 的双极点被 K_N 精确抵消

**[证明] 定理 1.1（`S(N)c_N=1`）.** 对每个偶 `N≥4`，
`c_N := lim_{w→0+} w·∏_{p>2,p∤N}(1+p^{-w}/(p−2)) = 1/S(N)`，
其中 `S(N)=2C₂∏_{p|N,p>2}(p−1)/(p−2)` 为哥德巴赫奇异级数。等价地 `S(N)c_N=1` 对所有 N 一致成立。

证明关键：恒等分解 `∏_{p>2}(1+p^{-w}/(p−2)) = ζ(1+w)(1−2^{-1-w})·∏_{p>2}R_p(w)`，其中
`R_p(w) = (p−1)²/(p(p−2)) − (1−p^{-w})²/(p(p−2))`，
再由 Mertens 定理取 `w→0`。（细节见 `phase2/kernel-theory.md` §1.3；数值 `2C₂c₂=1.000000006`。）

**[证明] 推论 1.2（局部展开）.** `w=s+\bar z→0` 时，
`D_N(w) = w^{-2} + O((loglog N)²)`，
`D_N(w)+K_N(s,\bar z) = (1−X₁(s)X₁(\bar z))w^{-2} − X₁(s)X₁(\bar z)\log(2π/N)w^{-1} + O(1)`；
且 `X₁(s)X₁(\bar z) = 1 + X₁'(0)w + O(w²)`（`X₁'(0)=−ψ(3/4)=1.08586`），所以 `(1−X₁X₁')w^{-2}` 项并不产生更坏的极点，而是并入同一个单极点：
`D_N+K_N = κ_N w^{-1} + O(1)`，`κ_N = log N − log(2π) + ψ(3/4) + O((loglog N)²)`。

**意义**：这严格化了 LL "先减对角、再用 Euler/Beta 模型"这一步的解析含义——模型不是近似，它在 `w=0` 处把对角的双极点**精确**打掉。但注意：`w=0` 不在条带内（条带 `Re w ≥ 2α_N = 2/log N`），所以在条带上 `κ_N/w` 是量级 `~(logN)²/2` 的大项；它的抵消必须靠 `P_N` 的内部结构（这就是下一节要说的"内部抵消"）。

## 2. 更锐的分量范数与否定性定理

**[证明] 定理 2.1.** `‖D_N‖_HS ≍ α_N^{-3/2} = (log N)^{3/2}`，`‖K_N‖_HS ≍ (log N)^{3/2}`（而非 LL 迹界给出的 `(logN)²`）。证明用精确均方恒等式与 `∫(log t)²t^{-1-2σ}dt ≍ σ^{-3}`（`α_N^{-3/2}` 的尺度），下界来自双极点系数 `±1`。

**[证明] 定理 2.2（无三角路线定理）.** 对 `T_N = P_N − D_N − K_N` 的三种自然分组：
`‖P_N‖_HS+‖D_N‖_HS+‖K_N‖_HS`、`‖P_N‖_HS+‖D_N+K_N‖_HS`、`‖P_N−D_N‖_HS+‖K_N‖_HS`，
都给出 `Ω((log N)^{3/2})` 的下界。由于 `δ_N = (log N)^{3/2}/√(S(N)N^{-1})`（更准确：`δ_N=√(S/N)(logN)^{3/2}`），量级比较给出
`(logN)^{3/2} / δ_N = √(N/S(N))` —— **缺口是 √N，不是任何 log 因子。**

因此：**任何"分量范数 + 三角不等式"的方案都到不了 `δ_N`，即使 `‖P_N‖_HS` 被优化到 `(log N)²/√N`（理想 Gram 平坦情形）也一样。** 唯一的路是估计 `E_N = P_N − (D_N+K_N)` 的**内部抵消**。

> **[撤回]** 中途我们曾提出 Prop 2.7："若 Gram 平坦 (G2)，则 `‖T_N‖` 可达 `δ_N·(logN)^{1/2}`"。该推导忽略了 `‖D_N+K_N‖_HS ≍ (log N)^{3/2}` 这一项，是**错误的**；已在 `phase3/gram-attack.md` 中撤回并更正。同时撤回"G2 是最有希望目标"的表述——即使 G2 成立，三角天花板仍停在 `(log N)^{3/2}`。

**[证明] 附带结果（G1）.** 单特征标界 `max_χ ‖f_χ‖² ≪ (log N)²` 可用 LL Lemma 6.4 的 Perron + 零点计数机制**逐特征标**证明（去掉 χ-平均）；`(G2)`（跨特征标 Gram 平坦）在现有工具下不可证（大筛法只给 χ-平均/迹；近似函数方程+特征正交化会落到交叉 shift 特征相关 `Σ_n χ(n)\barψ(n+d)`，在 φ² 个对上远不够）。

## 3. 真正的最小未知量：`E_N` 的内部抵消

**结构（[证明]）**：`E_N = P_N − (D_N+K_N)` 在条带上全纯（GRH），而 `D_N+K_N` 的局部展开给出量级 `κ_N/w` 的大项；`P_N` 是 `(2/φ)Σ|f_χ⟩⟨f_χ|` 的正算子、迹 `≍(logN)²`。因此 `T_N` 小 ⟺ `P_N` 与 `D_N+K_N` 在条带上发生**√N 级**的相消——这正是 Goldbach 主项抵消的算子版本。

**两个壁垒（[证明/推导]）**：

1. **真超平面壁垒（[推导]）**：`R` 直接蕴含对 LL 权类中**所有**权 `ψ` 的加权 Hardy–Littlewood 渐近 `G_ψ(N)=c_ψS(N)+O(δ_N)`（[证明]）；但反过来，**任何** Goldbach 型加权数据都推不出 `R`：Riesz 向量族 `{v_ψ}` 落在 Fourier–Laplace 等距模型的一个**真闭超平面** `{V: ∫V(u)u^{-2}du=0}` 内，故存在与所有 `v_ψ` 正交的方向，其二次型不受任何 Goldbach 相关数据约束。**`R` 是本质的 L² 算子范数陈述，严格强于一切（哪怕一致成立的）加权二元 HL 渐近。** 因此"先证 Goldbach 型结果再推 R"的路线在逻辑上被堵死。
2. **零点对壁垒（[推导]）**：用 Hadamard 展开 `g_χ = Σ_γ[1/(s−iγ)−1/(3/2−iγ)] + O(log N)`，`E_N` 的 HS 范数展开为**四个零点纵标 `(γ,γ',δ,δ')` 的跨特征标加权和**（四阶加性能量），严格强于 Montgomery 型对相关（二阶、未证）；LL 的 Lemma 6.4 只控制二阶高度平均矩，看不到这个四指标对象。

**判定**：最小未知量就是 `‖E_N‖ ≤ δ_N` 这个 L² 抵消估计；它既不能由分量范数（§2 定理 2.2）得到，也不能由任何 Goldbach 型数据（真超平面）得到，而需要新的**跨特征标零点/素数对四阶相关**输入。Alpöge/Claude 的机器（Stepanov 多重性、theta 提升、Weil 正性、Hermitian 曲率、Chebyshev 增长显式公式）全部作用于乘性零点结构，只给零区/正性（下界方向），与所需的定量 L² 上界方向相反，目前无通道。

## 5. 诚实的结论与下一步

**我们没有证明 Goldbach，也没有证明 R。** 但"越过墙"的收获是实质性的：

1. 找到了 LL "减对角 + Beta 模型"的精确解析内容（新的 Euler 乘积恒等式 `S(N)c_N=1`），并修正了直觉图像：真正配对抵消的是 `D_N` 与 `K_N`。
2. 严格化并锐化分量 HS 范数，证明了一个**否定性定理**：所有"分量范数 + 三角不等式"的估计都不可能达到 `δ_N`（差 √N）。这解释了为什么 LL 的 (log N)² baseline 不是"再估细一点"能改进的——必须处理内部抵消。
3. 证明了两个新壁垒：R 严格强于任何加权二元 HL 数据（真超平面），并且其 HS 范数展开需要四阶跨特征标零点相关。这为"为什么 2026 年的机器（包括 Alpöge/Claude 证明）帮不上忙"给出了精确原因。
4. 复现了 LL 的有限谱模型（在正确归一化下），并在此过程中发现/证实了论文 `(log N)²` baseline 的松紧来源。

**如果真要向前推进，唯一正确的研究问题是**：
> 证明 `‖E_N‖ ≪ δ_N`，其中 `E_N = P_N − (D_N+K_N)` 是条带上"真实离对角素数对相关 − Beta 模型"的算子；这需要新的跨特征标四阶相关估计（零点或素数对 level），而不是任何分量范数、任何 Goldbach 型数据、或任何乘性零点信息。

**可能的技术入口（[推测]）**：
- 近似函数方程 + 特征正交性（长度 ~√N 的 Dirichlet 多项式）可能给出 `P_N` 的部分 L² 结构，但无法处理 `E_N` 的内部抵消符号；
- 双迹/相对迹公式（LL 论文自引的 Linnik dispersion 思想）可能更适合"二阶相关"的 L² 控制；
- 任何"正性"（Weil/热核）论证方向与所需的小量上界相反（见 phase-1 报告）。
