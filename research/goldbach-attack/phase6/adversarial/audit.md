### 4.3 定理 7.2 的 ridge 二次型与常数（解析测试函数，不依赖网格）

用解析 L² 归一化 Gaussian bump h(t)~exp(−(t/δ)²)（单条 α-line，δ=1,2,4×α）直接算 `⟨Q h,h⟩=∫∫ Q_N(2α+i(t−u)) h(t)h(u)/((1+α+it)(1+α−iu)) dt du`（`logs/analytic_test.json`）：
- N=40022：δ=α → **2.723**；δ=2α → 2.779（c=⟨Qh,h⟩/logN=**0.257/0.262**）。
- N=1000166：δ=α → **3.928**；δ=2α → 4.120（**c=0.284/0.298**）。
- **[数值] c ≈ 0.26–0.30（单线）**；若 h 同时放在 α/β 两条线上（L² 归一化），交叉项使估计约为单线的 1.5–2 倍 → **c≈0.4–0.6**。
- **为什么不是 (logN)²/2 的 1/2 logN = 0.5logN：** ridge 高度实测 `Q_N(2α) = 20.54 (N=40022), 28.08 (N=200006), 31.63 (N=400006)`，即 **≈0.183–0.190(logN)²**，而非 (logN)²/2。原因：`D_N+K_N` 的双极点只在 K_N 带 (π/N)^w 因子时被部分抵消；在 w=2α 处 (π/N)^{2α}≈e⁻²·(…)=0.14–0.18，故 K_N 只消掉 ~15% 的 1/w²，ridge 高度≈(1−0.16)/4·(logN)²≈0.21(logN)²（与实测一致）。**定理 7.2 的"(logN)²/2"高度高估了 ~2.5–2.7 倍。**
- **[推导] 下界结论：定理 7.2 的"⟳ logN"方向成立；常数 c≈0.4–0.6（两线）或 0.26–0.30（单线），不是 1。** 量纲检查：height·width·(L² 归一化) = (0.19(logN)²)·(2/logN)·(1/(1+α)²)≈0.38logN（单线 bump 的 (∫h)²·height 公式：h=W^{-1/2} ⇒ ∫h=W^{1/2}, 二次型=height·W=0.38logN ✓）。

### 4.4 定理 7.1 的"逐行 L¹"审计

数值 Schur 行积分 `R(t)=Σ_{线}∫|Q_N(s+z̄)|/(|1+s||1+z̄|) du`（s=α+it，z 在 α/β 两线，u∈[−150,150]）：
- N=40022：t=0 → **31.71**（R/logN=2.99）；t=1 →20.27；t=5 →3.60；t=20 →0.97。
- N=1000166：t=0 → **39.13**（R/logN=2.83，下降中）。
→ **sup_t R(t) ≈ 2.8–3.0 logN，O(logN) 型成立（常数 C≈3）**；且 R/logN 随 N 下降，符合 C logN − O(loglogN)。
- **[推导] 对 7.1 的修正意见**：若把"逐行积分"按字面逐点 |Q|/|1+z| 的 L¹ 做，ridge 外 |Q|~1/u² 的尾巴在 |1+z|~|u| 下会给 ∫du/u³ 从 1/logN 起 ≈(logN)²/2 —— **朴素估计是 (logN)²，不是 logN**；必须利用 ridge 只在与 |t| 同量级的 u 上有贡献（|1+s| 固定、而 z 的 u≈t 时分母才是 |t|²）这一结构，或把算子看作 ridge 卷积（Fourier 乘子），才能得到 ≲ClogN。**kernel-theorist 的"逐行 L¹≲logN"若按字面理解有隐藏放大；按卷积结构理解则数值支持 C≈3。**
- **隐藏 N-依赖检查 [推导]**：P̃_N 在 Re w>0 有界（Euler 积）；X1(s)X1(z̄) 在条带 O(1)；ζ(1−w) 的增长被 (π/N)^w 因子与 ridge 宽度压制；D_N 的相干长度 e^{1/u} 论据与数值 |Q| 尾巴一致。**结论：7.1 的 O(logN) 上界方向可信（常数 C~3），但证明细节需要补齐卷积/Fourier 步骤。**

### 4.5 Ridge 专节的合并判决

- **b=1（Θ(logN)）可信**：收敛网格下 lQ 的 log 指数 →0.89–0.91（且 lQ/logN 缓降，符合 C logN−D loglogN），解析 ridge 下界给 c≈0.4–0.6 logN。
- **b=1.5 是 (H=8,m=2) 粗设置伪影**：同一公式在收敛设置 m≥8,H=10 下给出 b≈0.9；粗设置因 ridge 宽度 ~2/logN 与 spacing 0.5 不匹配而系统性高估并超线性增长。
- **对 R 的含义**：若 b=1 且 λ≈κ‖Q‖/√n（κ≈1.8±0.2），则 ratio≈(2κC_Q/√S)(logN)^{-1/2}→0（C_Q≈1.1–1.3），**R 渐近为真**——但这依赖 (i) κ 的稳定性（实测 ±10%）与 (ii) ‖Q‖ 的 b 指数（m→0 极限仍只在 m=32 验证，最高 logN 处 ridge 宽度 2/logN≈0.047 vs 1/32=0.031，可能仍有 <2% 偏差）。**phase-5 的"b=1.5/R 渐近假"应撤回。**
