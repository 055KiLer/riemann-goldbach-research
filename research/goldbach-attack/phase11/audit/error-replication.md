## 0. 判决摘要（给 Lead 的三句话）

1. **H_Ratios 误差尺度复制成功，α=1/2（q^{1−ω}，ω_D=1/2）方向成立，未见"无 power saving"的增长证据（无预警）。** 18 个导子（6 素数 + 12 复合，q=307…4001，含 4|q 与多素因子 q，含 vacuous 对照 q=330）：固定 η 下 `median |E_q−M_q|/√q` = 素数 2.4–10.3、复合 0.26–3.0、vacuous 0 —— 与 phase-10 报告（素数 3.9–11.1、复合 0.3–2.7）**独立一致**。log-log 斜率 vs q：素数 **+0.00±0.52**（N=6）、复合 +0.30±0.65、全部 −0.07±0.96 ⇒ **与 O(1) 相容**；"无 power saving"（R~q ⇒ R/√q∝q^{1/2}，斜率 +0.5）在素数样本上被排除（斜率 0.00±0.52，本应 >0.5·N/σ~4σ）；但样本散度大（±factor 4），不能确定 ω_D 的精确值。
2. **无"漏主项"警报。** 对每个 (q,η) 把 3 组 shift 的**带符号**残差取平均：`|mean R|/√q` = 0.06–21，始终与 `median|R|/√q` 同量级（个别 q 相干性 ~0.85），**从不出现 O(q) 级的系统项**（那会给出 |mean R|/√q ~ √q，例如 q=2003 时 ~45，而实测最大 21）；即没有量级 q·常数 的缺失主项。**次要告警**：η=0.02 时相对残差可达 1.95–7.1（q=2000 两个 shift），H_Ratios 的常数按 `O_{η,ε}` 允许 η-依赖，但这说明任何对 η→0 的取用必须显式追踪常数（GWX 证明需要）。
3. **Route C：E^{(X)}→E_q（尾指数 θ≈η…1.4η，与 naive X^{1/2−σ}=X^{−η} 相符）；但 (i) E^{(X)} 只能逼近 E_q，不能逼近到 M_q 以下——|E_q−M_q| 是硬地板（即 H_Ratios 误差本身，Route C 不能绕过）；(ii) 任务给出的 `conj(P_t(χ))` 形式有结构性共轭错误：它收敛到 L(t̄,χ̄) 的比值而非 L(t,χ̄)；Im t≠0 时目标 E_q 的残差**不收敛**（dE 斜率 +0.13/+0.04），而 t→t̄ 版本与"用 χ̄ 直接求 P_t"的修正版都收敛（斜率 −0.58/−0.33 与 −0.38/−0.35）。Route C 作为"主项计算"必须先修正这一点，且终点仍是 H_Ratios 残差。**

## 1. (A) H_Ratios 误差尺度的独立复制

### 1.1 自己实现的数学对象与验证

- 公式（照 phase10 §2，canonical 转录）：
  `E_q = Σ*_{χ primitive mod q} L(a,χ)L(b,χ̄)/(L(s,χ)L(t,χ̄))`，
  `M_q = φ*(q)Z_q(a,b;s,t) + H_q(a,b)Z_q(1−b,1−a;s,t)`，
  `Z_q(a,b;c,d)=ζ_q(a+b)ζ_q(c+d)/(ζ_q(a+d)ζ_q(b+c))·A_q`，`c=s,d=t`，
  `ζ_q(u)=ζ(u)∏_{p|q}(1−p^{−u})`，`A_q=∏_{p∤q}(1−p^{−c−d})(1−p^{−a−d}−p^{−b−c}+p^{−c−d})/((1−p^{−a−d})(1−p^{−b−c}))`，
  `H_q=Σ_{e=0,1}M_e(q)X_{q,e}(a)X_{q,e}(b)`，`X_{q,e}(w)=(q/π)^{1/2−w}Γ((1−w+e)/2)/Γ((w+e)/2)`。
- **自写复用的组件**：`(Z/q)^*` 的循环因子分解（奇素数用原根；2-adic 用 (−1,5) 生成元，e≥3），单位指数向量，`T[k,x]=χ_k(x)` 全字符表，primitive 过滤（对每个 p|q，检查 χ 在 `{x≡1 mod q/p}` 的核上非平凡；v2(q)=1 时无 primitive 字符），`M_e(q)` 由 χ(−1) 精确计数。
- **验证**：`T T^H = φ I` 误差 `1e−12…1e−9`（q=307…3001；我最初用 A·conj(A) 误判过一次，正确为 A·A^H）；primitive 计数与解析公式 `∏_p(φ(p^e)−φ(p^{e−1}))` 对 q=2,3,4,5,8,…,3465,4001 全部一致；L 值装配在 Re s>1 处与直接 Dirichlet 级数（2·10^6 项）比较：非主字符误差 `1e−10…1e−14`，主字符 `~5e−4`（=截断尾，符合）。
- **求值**：`L(u,χ)=q^{−u}Σ_{x∈(Z/q)^*}χ(x)ζ(u,x/q)`，mpmath Hurwitz ζ（dps=30，~0.9 ms/call），每 (q,shift) 4 个 u 值，DFT 得到全部 primitive χ；A_q 用素数≤2·10^6 的 log-sum（尾项由 `log R_p ~ O(p^{−(c+d)})`，实部≥2.1，尾 <1e−7）。

### 1.2 样本与 shift

- **18 个导子**：素数 **307, 503, 1009, 2003, 3001, 4001**；奇复合 **1001, 1155, 1365, 2079, 3003, 3465**；4|q **420, 1260, 1680, 2000, 2520, 3600**；vacuous（v2=1，无 primitive 字符）**330**。
- 3 组 shift（a,b 在 Re=1/2；s,t 在 Re=1/2+η）：(Im a,Im b,Im s,Im t)=(0.7,1.3,0.4,2.1), (2.6,−1.1,1.7,0.3), (−2.4,0.9,2.2,1.5)；η∈{0.05,0.1,0.2}。全部 |Im|≤3，且 Im(a)+Im(b)∈{2.0,1.5,−1.5} 远离 1（避开 a+b=1 的 ζ 极点）。
- 对每 (q,shift set) 计算 E_q（primitive 求和）与 M_q（canonical）；`ratio=|E−M|/√q`。

## 2. (B) Route-C 截断 Möbius 探针

### 2.1 设置
`E_q^{(X)}=Σ*_{χ primitive}L(a,χ)L(b,χ̄)P_s(χ)\overline{P_t(χ)}`，`P_u(χ)=Σ_{m≤X}μ(m)χ(m)m^{−u}`（自写 μ sieve 到 20000；用 `T` 对单位做 DFT 累加）。
q=503,1001,2000；η∈{0.1,0.3,**0.48**}（η=0.5 时 Re s=1 恰是 Hurwitz ζ 的极点，数值上 Σ_x χ(x)ζ(1,x/q) 的逐项发散相消无法用 double 实现；用 0.48 作为"η≈0.5"代表）；主用例 s,t **实数**（Im s=Im t=0），a=1/2+0.7i, b=1/2+1.3i；另设 Im t=0.8, 2.0 的**结构性测试**。X=q^δ（δ=0.1,0.2,0.3,0.4）并延拓到 X=50,100,300,1000,3000 以测尾指数。

### 2.2 结果（[数值]）

**(a) E^{(X)} → E_q，尾指数 θ（对 |E_X−E_q| 的 log-log 拟合）**：

| q | η=0.1 | η=0.3 | η=0.48 | naive −η |
|---|---|---|---|---|
| 503 | −0.214 | −0.416 | −0.618 | −0.1/−0.3/−0.48 |
| 1001 | −0.201 | −0.586 | −0.700 | 同上 |
| 2000 | −0.114 | −0.361 | −0.577 | 同上 |

⇒ **观测尾指数 θ ≈ η…1.5η，达到或略快于 naive X^{1/2−σ}=X^{−η} 的预测**；没有"不收敛/收敛到别的东西（在实 shift 下）"的问题。

**(b) E^{(X)} vs M_q**：`|E_X−M_q|` 先随 X 下降，随后在 `|E_q−M_q|`（地板：q=503 η=0.1 为 234；q=1001 η=0.1 为 111；q=2000 η=0.1 为 518）附近振荡/回升。例：q=2000, η=0.1：dM 从 371(X=50)→303→253→123(X=1000)→82(X=3000)，地板 518（dM<floor 是接近路径效应）。**结论：E^{(X)} 收敛到 E_q，而不是"直接收敛到 M_q 且给出更好误差"；H_Ratios 残差 |E_q−M_q| 是硬地板，Route C 无法通过截断 Möbius + 数值主项把它去掉。** 若 Route C 声称能计算主项而不证 H_Ratios，需额外说明如何在 |E_q−M_q|~√q 的噪声中提取 q^{1−ω} 主项——本数值没有显示这样的机制。

**(c) 结构性共轭缺陷（关键）**：任务式子中的 `conj(P_t(χ))` 在 Im t≠0 时收敛到 `1/L(t̄,χ̄)`，而不是目标 `1/L(t,χ̄)`：
- q=1001, η=0.3, Im t=0.8：对目标 E_q（含 t）的 dE **不降**（X=50→3000：254→237，斜率 +0.13）；对"t→t̄ 版" E_q_alt 的 dEalt 从 67.8→2.69（斜率 **−0.58**）。
- Im t=2.0：dE 斜率 +0.04（不收敛），dEalt 斜率 −0.33（收敛）。
- **修正版**（用 χ̄ 直接求 Möbius 和：`P_t^{(χ̄)}[k]=Σμ(m)χ̄(m)m^{−t}`，再用 `P_s(χ)·P_t^{(χ̄)}`）对 Im t=0.8/2.0 给出收敛：斜率 **−0.38 / −0.35**（对目标 E_q），X=3000 时残差 6.6/4.9。
⇒ **Route C 若照抄带共轭的式子，会得到错误对象（等价于 t 的虚部反号）；可通过"对 χ̄ 直接展开 P_t"修正。这是对 kernel-theorist Route C 的最重要反馈。**

**(d) 其它**：X 到 3000 为止（q^0.4≈12–21，我们的延拓远超任务 δ≤0.4 范围）；主字符/小分母导致的近奇异由 `ok` 掩码显示无零分母污染（全部 finite）。μ 截断到 X=3000 远小于 q 时 P_u 远非 1/L(u,χ)（|P|~X^{1/2−σ}），因此小 δ 的"E^{(X)} vs M_q"不能直接当主项读；我们仅在延拓 X 上测尾指数。

## 4. 结论与建议

1. **[数值] 复制 verdict**：**H_Ratios 的误差尺度 R=O(√q·(1+T)^B·c(shift,η)) 与本独立数据相容（α≈1/2，无 q 增长、无漏主项）**；phase-10 的核心数值结论可复现。限制：q≤4001、|Im|≤3（大部分 ≤2.6）、固定 3 组 shift；T 到 100log(2q)~600-760 的大 shift 区未覆盖。
2. **[数值/推导] 报警**：
   (a) **η→0 的常数爆炸**：η=0.02 时 |E−M|/|M| 可达 7.1（q=2000）；H_Ratios 允许 O_{η,ε} 依赖，但 GWX 证明若需要 η→0，必须显式追踪 η^{-A} 常数，否则"uniform"表述有风险。
   (b) **q-level 相关性**：误差与 φ* 强相关（ρ=0.80）——复合 q 的"小误差"部分来自 φ* 小；不能用素数样本直接给 composite 的常数。
   (c) **shift 相干性**：同 q 内带符号残差有 ~0.4–0.85 的相干分量（不是纯随机），因此"误差项可从随机涨落估计"的直觉需谨慎；但相干分量 ≤O(√q)，不是主项级。
3. **[数值] Route C verdict**：**E^{(X)}→E_q 且尾指数 θ≈η…1.4η（符合 naive X^{−η}）**，所以"截断 Möbius 可以数值复现 E_q"成立；**但** (i) 目标函数里 `conj(P_t)` 是错的（收敛到 t̄），必须改为对 χ̄ 直接求和，否则对复 shift 不收敛到 E_q；(ii) 它永远只能到 E_q 的精度，**不能穿透 |E_q−M_q| 这层 H_Ratios 残差**——Route C 不是绕过 H_Ratios 的通道，最多是验证/计算工具。
4. **未做/建议**：(i) T≤100log(2q) 的大 shift 与"固定圆盘全纯"的检验（用本脚本可扩，但 q=2000、T~700 时 Hurwitz 求值成本高）；(ii) 精确 ω_D：需要 q 跨越 10³–10⁵ 且控制 shift/T 混合；(iii) η=0.02 异常是否稳定（更多 q/shift）；(iv) Route C 修正版的严格分析（误差项是否仍是 X^{−η} 的均匀界）。
