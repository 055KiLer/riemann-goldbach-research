## 0. 结论摘要（先给结论）

1. **[证明] 精确分解 + 双极点的真正配对伙伴。** 在收敛域 `Re s,Re z>1/2` 上 `P_N = D_N(s+z) + O_N`（`O_N` 为三族非对角项），对角项的**每一项都恰好等于** `D_N(s+z)`。但"减掉对角"本身**不带来任何量级改进**：在条带左-左角 `(s,z)=(α_N,α_N)`，`D_N(2α_N)≍(log N)²/4` 与 `P_N` 同量级。真正的精确抵消发生在 **`D_N` 与 Beta 模型 `K_N`** 之间：本报告证明新的 Euler 乘积恒等式（定理 1.3）
   ```
   S(N)·c_N = 1,   c_N = lim_{w→0} w·P_N^{Euler}(w) = 1/(2C₂),
   ```
   它使 `D_N` 的 `1/w²` 双极点与 `K_N` 的 `1/w²` 双极点**精确抵消**；`E_N = P_N − (D_N+K_N)` 的局部奇异部分只剩一个显式单极点 `−log(2π/N)/w`。这是对 task 描述中"`P_N` 双极点被 `D_N` 抵消、`K_N` 只有单极点"这一图像的**修正**：`K_N` 在 `w=0` 同样是双极点（系数 `−S(N)c_N`），而抵消配对是 `D_N↔K_N`，不是 `P_N↔D_N`。该结论是**结构性**的，不自动给出定量改进（见 2.4）。
2. **[证明] 更锐的 HS 范数。** 分量算子 `D_N`、`K_N` 的 HS 范数真阶是 `≍α_N^{-3/2}=(log N)^{3/2}`，而不是 LL 用迹界得到的 `α_N^{-2}=(log N)²`（定理 2.1、2.2）。**但是** `P_N` 是 PSD、`tr P_N` 级的 `(log N)²` 项，任何"分离 `P_N` 后用三角不等式"的方案（包括精确对角抵消后的分解）**仍只能给出 `O((log N)²)`**。要得到 `(log N)^{3/2}`，必须额外证明 `‖P_N‖_HS≪(log N)^{3/2}`（等价于跨特征标的 `L'/L` 四阶矩估计，目前不可得）。即使做到，离 `δ_N` 仍差 `√N/log N`。**最小未知量是 `P_N−D_N−K_N` 的 L² 抵消，而不是分量范数。**
3. **[推导] 零点对表述。** 由 Hadamard 展开 `g_χ=Z_χ+b_χ`（`Z_χ=Σ_γ[1/(s−iγ_χ)−1/(3/2−iγ_χ)]`，`b_χ=O(log N)`），`E_N` 的 HS 范数展开为**四个零点纵标** `(γ,γ',δ,δ')` 的加权和（跨特征标），即零点集的**四阶加性能量**，严格强于 Montgomery 型对相关；LL Lemma 6.4 只控制二阶（高度平均）矩，看不到该四指标对象。**[推测]** 这是 LL 路线不可绕过的零点相关壁垒。
4. **[推导] 条件定理与反向壁垒。** (a) `R ⇒` 对 LL 权类中**所有**权 `ψ` 的加权 Hardy–Littlewood 渐近 `G_ψ(N)=c_ψS(N)+O(δ_N)`（即 `R` 直接蕴含未证的二元素数对相关渐近，LL 定理 1.2 的推论）。 (b) 反过来，**任何** 形如 `G_ψ` 的 Goldbach 型数据的全体都**不能**推出 `R`：Riesz 向量族 `{v_ψ}` 在 Fourier–Laplace 等距模型下落在**一个真闭超平面** `{V: ∫V(u)u^{-2}du=0}` 内（命题 4.2），故存在与所有 `v_ψ` 正交的单位方向，其上的二次型不受任何 Goldbach 相关数据约束。`R` 是本质的 **L² 算子范数**陈述，严格强于一切（哪怕一致成立的）加权二元 HL 渐近。
5. **判定**：真正的墙 = (i) 与 (ii) 二者同一：`R` 的定量内容恰好是"条带上 `O_N=P_N−D_N` 的解析延拓与 Beta 模型 `K_N` 的 √N 级抵消"，它**严格强于**二元 Goldbach 的 Hardy–Littlewood 渐近，因而也强于现有任何素数对相关技术（Montgomery 对相关、GPY、BV for ΛΛ 都是平均/上界型，且 Montgomery 本身未证）。Alpöge/Claude 机器（Stepanov 多重性、theta 提升、Weil 正性、Hermitian 曲率、Chebyshev 增长显式公式）全部作用于 **L 函数零点/乘性对象**，不提供 `L'/L` 在条带上的**定量 L² 相关**；目前**无通道**。

## 1. 第一项：LL 核的严格分解与局部奇点结构

### 1.1 精确对角提取（LL (3.2) 的簿记）

**引理 1.1 [证明].** 设 `N≥4` 偶，`Re s,Re z>1/2`。则逐项地
```
P_N(s,z) = D_N(s+z) + O_N(s,z),
D_N(w)   = Σ_{(n,N)=1} Λ²(n) n^{-1-w},
O_N(s,z) = Σ_{k≥1} [ A_k(s,z) + A_k(z,s) − B_k(s,z) ],
A_k(s,z) = Σ_{m≥1,(m,N)=1} Λ(m+kN)Λ(m) (m+kN)^{-1/2-s} m^{-1/2-z},
B_k(s,z) = Σ_{n+m=kN,(nm,N)=1} Λ(n)Λ(m) n^{-1/2-s} m^{-1/2-z}.
```
三个和号绝对收敛（对 `Re s,Re z>1/2`）；`D_N` 即 `n=m` 对角族，`A_k` 是两个差族（`m=n±kN`，符号 `+`），`B_k` 是和族（`n+m=kN`，符号 `−`），与 LL §2.1.3 的表一致。

**证明.** 由 LL (3.2)（Prop 3.2）：`P_N(s,z)=Σ_{n,m≥1,(nm,N)=1}Λ(n)Λ(m)n^{-1/2-s}m^{-1/2-z}(1_{n≡m mod N}−1_{n≡−m mod N})`。在 `Re s,Re z>1/2` 下该二重级数绝对收敛，可按 `n≡m` 与 `n≡−m` 拆分。对 `(n,N)=1`，`n≡−n mod N` 当且仅当 `N|2n`，因 `N` 偶且 `gcd(n,N)=1`、`N≥4`，这要求 `N/2|n`，不可能。故对角族恰为 `n=m`，即 `Σ_{(n,N)=1}Λ²(n)n^{-1-s-z}=D_N(s+z)`。其余即 `O_N`。∎

**注 1.1'.** `P_N` 在 `Re s,Re z>1/2` 的收敛域中，其"巨大"部分完全由 `D_N` 承担。然而**减掉 `D_N` 不是定量改进**：见 1.4。`O_N` 的级数仅在 `Re(s+z)>1` 收敛，它在 LL 条带（`Re(s+\bar z)∈[2α_N,1/4]`）上由 `P_N−D_N` 的解析延拓给出（GRH 下 `P_N` 在 `Re s,Re z>0` 全纯，`D_N` 在 `Re w>0` 全纯），故 `O_N` 在条带上**不是**由上述级数直接给出的（见注 1.3）。

### 1.2 `D_N` 的局部展开（双极点系数 = 1）

**引理 1.2 [证明].** 存在绝对常数 `c₀` 与 `R(N)=−Σ_{p|N,p>2}(log p)²/(p−1)+O(1)`（满足 `R(N)≪(log log N)²`），使
```
D_N(w) = w^{-2} + R(N) + O(|w|),   0<Re w<1/2.
```
特别地双极点系数**恰为 1**，且 `D_N(s+\bar z)` 的 `1/w²` 与 `S(N)`, 权重 `φ`, 条带位置**无关**。

**证明.** 令 `F(s)=Σ_{n≥1}Λ²(n)n^{-s}`（`Re s>1`），`g(s)=−ζ'/ζ(s)=Σ_p(log p)/(p^s−1)`。恒等式
```
−g'(s) = Σ_p (log p)² p^s/(p^s−1)² = Σ_p (log p)²/(p^s−1) + Σ_p (log p)²/(p^s−1)² = F(s) + H(s),
```
其中 `H(s)=Σ_p(log p)²/(p^s−1)²` 在 `Re s>1/2` 全纯。又 `g(s)=1/(s−1)+O(1)`（`ζ'/ζ` 在 `s=1` 的单极点，留数 −1），故 `−g'(s)=1/(s−1)²+O(1)`。取 `s=1+w` 得
```
F(1+w) = w^{-2} + c₀ + O(|w|).
```
而 `D_N(w)=F(1+w)−Σ_{p|N,p>2}(log p)²p^{-1-w}/(1-p^{-1-w})`；后一有限和在全纯点 `w=0` 附近取值 `Σ_{p|N}(log p)²/(p−1)+O(w)`，且 `Σ_{p|N}(log p)²/(p−1) ≤ Σ_{p|N}(log p)²/p + O(1) ≪ (log log N)²+O(1)`（对 `N` 的素因子求和，`Σ_{p≤x}(log p)²/p ≍ (log x)²/2`）。∎

### 1.3 关键恒等式：`S(N)c_N=1`（对角线双极点被 Beta 模型精确抵消）

这是本报告最重要的新结果。它**严格化了 LL"先减对角、再用 Euler/Beta 模型"这一步的解析含义**：模型不是近似，它在 `w=0` 处把对角的双极点**精确**打掉。

**定理 1.3 [证明].** 对每个偶 `N≥4`，
```
c_N := lim_{Re w→0+} w·P_N^{Euler}(w) = 1/S(N),   其中 P_N^{Euler}(w)=∏_{p>2,p∤N}(1+p^{-w}/(p−2)).
```
等价地 `S(N)c_N = 1`（对所有 `N` 一致）。也即
```
D_N(w) + K_N(s,\bar z) = (1−X1(s)X1(\bar z))·w^{-2} − X1(s)X1(\bar z)·log(2π/N)·w^{-1} + O(1),  w=s+\bar z→0,
```
特别地当 `w→0`（此时自动 `X1(s)X1(\bar z)→X1(s)X1(−s)=1`）时 `D_N+K_N = O(1/|w|)`：**双极点精确抵消，只剩显式单极点 `−log(2π/N)/w`。**

**证明.** 第一步（绝对情形 `N=2` 的常数）。对 `Re w>0` 有恒等分解
```
∏_{p>2}(1+p^{-w}/(p−2)) = ζ(1+w)(1−2^{-1-w}) · ∏_{p>2} R_p(w),  R_p(w):=(1+p^{-w}/(p−2))(1−p^{-1-w}).
```
（因为 `ζ(1+w)(1−2^{-1-w})=∏_{p>2}(1−p^{-1-w})^{-1}`。）直接计算给出**闭式**
```
R_p(w) = (p−1)²/(p(p−2)) − (1−p^{-w})²/(p(p−2)),   R_p(0) = (p−1)²/(p(p−2)) = 1+1/(p(p−2)).
```
于是 `∏_p R_p(0) = ∏_p (p−1)²/(p(p−2)) = 1/C₂`（因 `C₂=∏_{p>2}(p(p−2)/(p−1)²)`），且 `Σ_p|R_p(0)−1|<∞`。又对 `|w|≤1`，`Re w≥0`：`|R_p(w)−R_p(0)|=|1−p^{-w}|²/(p(p−2)) ≤ 4|w|²(log p)²/(p(p−2))`，而 `Σ_p(log p)²/(p(p−2))<∞`，故 `∏_p R_p(w)` 在 `Re w≥0` 上一致收敛、在 `w=0` 连续。于是
```
lim_{w→0} w∏_{p>2}(1+p^{-w}/(p−2))
 = lim_{w→0} [wζ(1+w)]·(1−2^{-1-w})·∏_{p>2}R_p(w) = 1·(1/2)·(1/C₂) = 1/(2C₂) =: c₂.
```
（用了 `wζ(1+w)→1`；这里 `w→0` 沿 `Re w>0`，全部步骤只用到 `Re w>0` 与实 `w→0+` 的连续性。）

第二步（一般 `N`）。`∏_{p>2,p∤N}(1+p^{-w}/(p−2)) = [∏_{p>2}(1+p^{-w}/(p−2))]\big/[∏_{p|N,p>2}(1+p^{-w}/(p−2))]`，取 `w→0`：
```
c_N = c₂ / ∏_{p|N,p>2}(1+1/(p−2)) = c₂ / ∏_{p|N,p>2}((p−1)/(p−2)).
```
而 `S(N)=2C₂∏_{p|N,p>2}(p−1)/(p−2)`，故 `S(N)c_N = 2C₂c₂ = 1`。∎

**第三步（`K_N` 的展开）。** 由 LL (2.12) `K_N=S(N)(π/N)^w P_N^{Euler}(w)ζ(1−w)X1(s)X1(\bar z)`。由第一步同一分解可得更强形式
```
P_N^{Euler}(w) = c_N (w^{-1} + (γ+log 2) + O(w))       (w→0, Re w>0),
```
其中 `∏_p R_p(w)=1/C₂+O(w²)`（注意 `R_p(w)−R_p(0)=−(1−p^{-w})²/(p(p−2))` 只有偶数阶项）、`ζ(1+w)=w^{-1}+γ+O(w)`、`1−2^{-1-w}=1/2+(\log 2/2)w+O(w²)`。代入 `(π/N)^w=1+w\log(\pi/N)+O(w²)`、`S(N)c_N=1`、`ζ(1−w)=−w^{-1}+γ+O(w)`：
```
K_N = −X1(s)X1(\bar z)·[ w^{-2} + log(2π/N)·w^{-1} + O(1) ].
```
与引理 1.2 的 `D_N=w^{-2}+O(1)` 相加即得。当 `w=s+\bar z→0` 且 `Re s,Re z≥0`，必 `s→0`、`z→0`（因 `Re w=Re s+Re z`），故 `X1(s)X1(\bar z)→X1(0)²=1`。∎

**[数值] 验证.** 用 `w=0.02,0.008,0.004,0.002` 直接求和 `w∏_{p>2}(1+p^{-w}/(p−2))` 并外推，再用解析加速算出
`2C₂c₂ = 1.0000000063761`（偏差 ≤10⁻⁸，来自尾部截断）。代码：`_rh-work/goldbach-attack/phase2/scratch/check_c2.py`。这独立验证了 `S(N)c_N=1`。

**注释 1.3（与 task 描述图像的差异，重要）.**

### 1.4 为什么"减对角"在三角不等式层面不产生改进（负面结论，澄清路线）

**[证明/推导] 命题 1.4.** 在条带左-左角 `(s,z)=(α_N,α_N)`（边界线上、高度 0）：
- `D_N(2α_N) = (log N)²/4+O(1)`（引理 1.2；注意 `w=2α_N=2/log N`）；
- `K_N(α_N,α_N) = −(log N)²/4+O(log N)`（定理 1.3 第三步；`X1(α_N)²=1+O(α_N)`）；

因此**任何**把 `T_N` 写成 `P_N,D_N,K_N` 线性组合后逐项取 HS/迹范数上界再加和的方案，其和至少是 `c(log N)²`，与是否"精确减去对角"无关。**精确对角抵消不改变三角不等式的量级。**

## 2. 第二项：更锐的 Hilbert–Schmidt 估计

### 2.1 一般公式

在 `Γ_N=(α_N+iR)⊔(β+iR)` 上，`L²(Γ_N)` 权重 `|1+s|^{-2}≍(1+t²)^{-1}`。对只依赖 `w=s+\bar z` 的核 `F(w)`，
```
∫_{Γ_N×Γ_N} |F(s+\bar z)|²/(|1+s|²|1+\bar z|²) |ds||dz|
 = Σ_{σ₁,σ₂∈{α_N,β}} 2π ∫_R |F(σ₁+σ₂+iu)|²/(4+u²) du,
```
用到了 `∫_R dt/((1+t²)(1+(t−v)²))=2π/(4+v²)`（LL 同款恒等式）。`D_N` 恰属此类。

### 2.2 `‖D_N‖_HS` 的真阶是 `α_N^{-3/2}`（LL 的 `α_N^{-2}` 差一个 `α_N^{1/2}`）

**定理 2.1 [证明].** 对 `0<σ≤1/4`，
```
M²(σ) := ∫_R |D_N(σ+iu)|²/(4+u²) du ≪ σ^{-3}   （N 一致）。
```
故 `‖D_N‖_HS ≪ α_N^{-3/2}=(log N)^{3/2}`。

**证明.** 对 `Re w=σ>0` 用 `D_N(σ+iu)=Σ_n a_n n^{-1-σ-iu}`，`a_n=Λ²(n)1_{(n,N)=1}`，绝对收敛，故有**精确**的均方恒等式
```
∫_R |D_N(σ+iu)|²/(4+u²) du = (π/2) Σ_{n,m} a_n a_m (nm)^{-1-σ} e^{-2|log(n/m)|}
 = (π/2)[ Σ_n a_n² n^{-2-2σ} + 2Σ_{n<m} a_n a_m n^{1-σ} m^{-3-σ} ].
```
对角项 `≤Σ_n Λ(n)⁴ n^{-2}=:C₁<∞`。非对角项：对固定 `m`，由 `Σ_{n≤x}Λ²(n)n^{1-σ}≪x^{2-σ}log x`（Stieltjes 分部求和；主项来自 `n` 为素数）得
```
2Σ_{n<m}Λ²(n)Λ²(m)n^{1-σ}m^{-3-σ} ≪ Σ_m Λ²(m) m^{-1-2σ} log m
  = ∫ t^{-1-2σ}(log t) dB(t) ≪ ∫ (log t)² t^{-1-2σ} dt ≍ σ^{-3},
```
其中 `B(t)=Σ_{n≤t}Λ²(n)≪t log t`，且 `∫(log t)²t^{-1-2σ}dt=Γ(3)/(2σ)³=1/(4σ³)`。∎

**推论 2.1'.** `‖D_N‖_HS²=Σ_{σ₁,σ₂}2πM²(σ₁+σ₂) ≪ M²(2α_N)+O(1) ≪ α_N^{-3}`，即 `‖D_N‖_HS≪α_N^{-3/2}`。LL Prop 6.5 用的是 `‖D_N‖_HS≤tr D_N≪α_N^{-2}`，在平方尺度上损失 `α_N`（范数尺度损失 `α_N^{1/2}=(log N)^{1/2}`）。**这是对 LL 基线的真实改进，但仍远不足以到达 `δ_N`。**

### 2.3 `‖K_N‖_HS` 同样是 `α_N^{-3/2}` 而非 `α_N^{-2}`

**定理 2.2 [证明(梗概)].** `‖K_N‖_HS ≪ α_N^{-3/2}`（N 一致）。

**证明(梗概).** 由 (6.16) 形 `K_N=S(N)(π/N)^w P^{Euler}_N(w)ζ(1−w)X1(s)X1(\bar z)`，LL 已证
`|S(N)(π/N)^w P^{Euler}_N(w)| ≪ σ^{-1}`（`σ=Re w`，见 LL p.41，`|N^{-w}S(N)P_N(w)|≪σ^{-1}`，`|π^w|≤π^{1/4}`），且 `|ζ(1−σ−iτ)|≪σ^{-1}(2+|τ|)^{2β}`（LL p.41，`2β=1/4`）；Stirling 给出 `|X1(σ₁+it)|²≪(1+|t|)^{-σ₁}`。
- 对 `(σ₁,σ₂)=(α_N,α_N)` 的边界对：`|K_N|²≪σ^{-2}·|ζ(1−w)|²`。按 `|u|≤1` 用 `|ζ(1−w)|≪1/|w|`（`ζ(1−w)=−1/w+O(1)`，`u=Im w`），按 `|u|≥1` 用凸界 `|ζ(1−w)|≪(1+|u|)^{1/4}`。则
  `∫|K_N|²/(4+u²)du ≪ σ^{-2}[∫_{|u|≤1}du/((4+u²)|w|²) + ∫_{|u|≥1}(1+|u|)^{1/2}/(4+u²)du] ≪ σ^{-3}+σ^{-2}`；
  这里 `∫_{|u|≤1}du/((4+u²)(σ²+u²)) ≍ σ^{-1}`（`u~σ` 与 `σ≤|u|≤1` 两段），`X1` 因子在该区有界。
- 其余三对边界（`σ≥α_N+β≥1/8` 或 `2β=1/4`）：整体 `≪α_N^{-2}·O(1)` 且 `X1` 的指数衰减使 `(t,y)` 积分收敛，得 `O(1)`。
合计 `‖K_N‖_HS²≪α_N^{-3}`。∎

**注 2.3.** 定理 1.3 表明 `D_N+K_N` 在 `w=0` 附近只剩 `O(1/|w|)` 单极点，人们可能期望 `‖D_N+K_N‖_HS` 再降一阶。但**不能**：`w=0` 局部之外 `|D_N|` 与 `|K_N|` 各自仍是 `σ^{-2}` 与 `σ^{-1}|ζ|` 型，均方积分的主贡献恰是 `σ^{-3}`（见定理 2.1 证明中的 `∫(log t)²t^{-1-2σ}dt`），所以 `‖D_N+K_N‖_HS≍α_N^{-3/2}` 与 `‖D_N‖_HS` 同阶。**精确极点抵消是结构信息，不是范数改进。**

### 2.4 三角不等式的最优量级：仍是 `(log N)²`；障碍完全在 `P_N`

**[证明] 命题 2.4（三角不等式的天花板）.**
```
(i)  ‖T_N‖ ≤ ‖P_N‖_HS + ‖D_N‖_HS + ‖K_N‖_HS ≪ (log N)² + 2C(log N)^{3/2} ≪ (log N)²;
(ii) ‖T_N‖ ≤ ‖P_N‖_HS + ‖D_N+K_N‖_HS ≪ (log N)² + C'(log N)^{3/2} ≪ (log N)²;
(iii) 任何把 P_N 作为独立加项的三角/迹界方案都给出 ≫ c(log N)²，
      因为 tr P_N ≥ ∫_{|t|≤1} P_N(α_N+it,α_N+it)/(1+t²)dt，而被积函数在 t=0 附近为 (log N)² 量级（命题 1.4）。
```
（`(i)` 用 LL Prop 6.5 的 `‖P_N‖_HS≤tr P_N≪(log N)²` 与定理 2.1/2.2；`(ii)` 用注 2.3。）

**命题 2.5 [推导]（改进的唯一可能入口）.**
若还能证明 `‖P_N‖_HS ≪ (log N)^{3/2}`，则结合定理 2.1/2.2 得 `‖T_N‖≪(log N)^{3/2}`——严格优于 LL 的 `(log N)²`。但即便如此，
```

```
仍差 `√N` 级。**因此"把分量范数算得更准"这条路的天花板是 `(log N)^{3/2}`，离 Hypothesis R 仍有 `√N` 的鸿沟。**

`P_N=(2/φ(N))Σ_{χ∈X_N^-}|f_χ⟩⟨f_χ|`（`f_χ=g_χ/(1+s)`，PSD，秩 `≤φ(N)/2`），故

### 2.5 精确瓶颈重述：Gram 矩阵平坦性（task 提示的 `(log N)²/√(φ(N))` 路线，**几乎**到 `δ_N`）

**[推导] 命题 2.7（关键定量观察）.** 若以下两条成立：
(G1)（逐特征标平方界）`max_{χ∈X_N^-} ‖f_χ‖²_{H_N} ≪ (log N)²`；
(G2)（近似正交）`Σ_{χ≠ψ}|⟨f_χ,f_ψ⟩|² ≪ φ(N)^{-1}(Σ_χ‖f_χ‖²)²`（例如 Gram 矩阵近似对角、谱"平坦"），
则 `‖P_N‖_HS ≪ (log N)²/√(φ(N)/2)`，从而
```
‖T_N‖ ≤ ‖P_N‖_HS + ‖D_N‖_HS + ‖K_N‖_HS
        ≪ (log N)²/√φ(N) + C(log N)^{3/2}
        = δ_N · [ (log N)^{1/2}√(log log N)/(√S(N)) + o(1) ],
```
即**只差一个 `(log N)^{1/2}` 的对数因子就到达 Hypothesis R**。

**证明.** 由 (2.13) 与 PSD 分解 `P_N=(2/φ(N))Σ_χ|f_χ⟩⟨f_χ|`：`‖P_N‖_HS²=(2/φ(N))²Σ_{χ,ψ}|⟨f_χ,f_ψ⟩|²`。在 (G2) 下右端 `≤(2/φ(N))²[Σ_χ‖f_χ‖⁴+φ(N)^{-1}(Σ_χ‖f_χ‖²)²]`；由 (G1) `Σ_χ‖f_χ‖⁴ ≤ max_χ‖f_χ‖²Σ_χ‖f_χ‖²`，而 `Σ_χ‖f_χ‖²=(φ(N)/2)tr P_N ≪ (φ(N)/2)(log N)²`（LL Prop 6.5），故 `‖P_N‖_HS² ≪ (4/φ(N)²)(log N)²·(φ(N)/2)(log N)²·(1+1/φ(N)) ≍ (2/φ(N))(log N)^4`。∎

**意义（这是本报告对"什么是墙"最精确的回答）.** `tr P_N` 是 `(log N)²`，而 `δ_N` 需要 `P_N` 的 HS 范数达到 `(log N)²/√N` 量级，即需要**秩型节省 `√N`**。命题 2.7 说明：**逐特征标界 (G1) + Gram 平坦性 (G2) 恰好提供 `√φ(N)≈√N` 的节省**，从而到达 `δ_N` 的 `(log N)^{1/2}` 倍以内。于是 **LL 路线的整个剩余缺口集中在同一处**：`{g_χ/(1+s)}_{χ∈X_N^-}` 这个特征标族的 Gram 矩阵是否近似对角/平坦。
- (G1) 是**单特征标**的均方估计，可由 Perron 多项式 + 零点计数（LL Lemma 6.4 的机制，去掉对 χ 平均）**有望证明**；[推测] 可行。
- (G2) 是**跨特征标**的四阶量 `tr(G²)`，需要 `⟨g_χ,g_ψ⟩`（χ≠ψ）的小性。其来源应是特征标正交性（LL Lemma 6.4 的"averaging removes oscillatory cross terms"只对 `Σ_χ|·|²` 成立，对 `Σ_{χ≠ψ}|⟨·,·⟩|²` 需要新的论证）。
- 注意这比我此前写的"到 `(log N)^{3/2}` 仍差 `√N`"**更精确**：`(log N)^{3/2}` 是错误的目标；正确目标是 `(log N)²/√N`。两者的区别是 `√N` 的 rank saving——而 rank saving 正是 `φ(N)` 个正交特征标理应提供的。**因此真正的未知不是"没法通过 HS 估计"，而是"能否证明 (G1)+(G2)"。** [推测] (G2) 可能比 §3.1 的四零点能量**容易**（它只是"2×2 零点对"的加性能量，不是四独立纵标），这是本报告找到的最有希望的具体研究目标。

## 3. 第三项：对连续非对角核 `P_N−D_N` 的正面攻击及停止点

### 3.1 (a) Hadamard 零点和表示

**[证明]**（LL Lemma 3.3/3.4 的重写）在 GRH 下，对 `χ∈X_N^-` 及其原特征 `χ*`（导子 `d_χ|N`）：
```
g_χ(s) = Z_χ(s) + b_χ(s),   Z_χ(s)=Σ_γ [1/(s−iγ_χ) − 1/(3/2−iγ_χ)],   b_χ(s) = L'/L(2,χ) − (1/2)log(d_χ/π) − (1/2)[Γ'/Γ(3/4+s/2)−Γ'/Γ(3/2)] + e_χ(1/2+s) − e_χ(2),
```
`b_χ(s)≪log N`（LL (3.8)–(3.9)；当 `s` 在固定紧带内）。于是
```
P_N(s,\bar z) = (2/φ(N)) Σ_χ [Z_χ(s)\overline{Z_χ(z)} + Z_χ(s)\overline{b_χ(z)} + b_χ(s)\overline{Z_χ(z)} + b_χ(s)\overline{b_χ(z)}].
```
`E_N = P_N−D_N−K_N` 的 HS 范数平方 `‖E_N‖_HS²=∫∫|E_N|²` 展开后的主导项是
```
(2/φ(N))² Σ_{χ,ψ} ∫_{Γ_N}∫_{Γ_N} Z_χ(s)\overline{Z_ψ(s)} · \overline{Z_χ(z)}Z_ψ(z) / (|1+s|²|1+z|²) |ds||dz|
```
（`Z` 是零点纵标上的求和；注意 `Z_χ` 与 `Z_ψ` 是**不同特征标**的零点集）。展开后是**四指标和** `Σ_{γ,γ',δ,δ'}`，其权重是四个 Cauchy 核乘积在 `Γ_N×Γ_N` 上的积分。因此：
- **对角部分**（`γ=γ'`, `δ=δ'`，即每个特征标内部的对角零点对）可以逐项用零点计数 `#{ρ:t≤ℑρ<t+1}≪log(d_χ(|t|+2))`（LL (3.5)）控制——这对应 LL Lemma 6.4 已做的二阶矩，给出 `(log N)²`。
- **真正困难的部分**是 (i) 同一特征标内的**非对角零点对** `γ≠γ'`（需要零点间距/对相关）与 (ii) **跨特征标**的零点对 `χ≠ψ`（`γ` 与 `δ` 之间无任何已知关系）。平方之后需要零点集的**四阶加性能量**。
- `D_N` 的扣除在零点语言里对应"从 `P_N` 的二阶矩中减去显式公式给出的对角/局部项"；定理 1.3 表明它精确抵消的是 `K_N` 的模型极点，**并没有**简化四指标零点结构。

**[推测] 结论 (3a)：** 要证明 `R`，需要的输入至少包括"Dirichlet `L`-函数零点纵标（跨特征标、模 `N` 一致）的四阶加性能量上界"，它强于 Montgomery 型对相关（后者是二阶、单个 L 函数、且本身未证）。这是本路线的零点相关壁垒。

### 3.2 (b) 函数方程/围道移动能给出什么

LL 的围道移动（§3, Lemma 3.5, Prop 4.5, Lemma 6.4）用途仅两类：
1. 把 `P_N` 从 `Re s>1/2` **全纯延拓**到条带（GRH 保证无极点）——这是"合法性"而非"定量性"；
2. 用 Perron 多项式 + 零点和对 `|g_χ|²` 做**高度平均**的 `L²` 估计（Lemma 6.4, 得 `(log N)²`）。
函数方程已经把 gamma 因子精确编码进 `X1(s)X1(\bar z)`，即 Beta 模型 `K_N`（LL (2.12)/(4.4)）——这部分信息已被模型完全利用。
**停止点**：`T_N` 的算子范数不是某个积分的平均，而是**在二维变量 `(t,y)` 上所有方向的 `sup`**；围道移动控制的是"沿一条竖线的积分"，无法给出核函数在 `(t,y)` 平面上的 L² 抵消。对 `‖P_N‖_HS²` 的需要是二重积分，零点展开后的四重和不是任何单变量围道移动能处理的。

## 4. 第四项：条件定理与反向壁垒（本项的核心）

### 4.1 `R ⇒` 未证的二元 Hardy–Littlewood 渐近（[证明]）

**定理 4.1 [证明].** 设 GRH(N) 且 Hypothesis R 对所有充分大偶 `N` 成立。设 `ψ∈C_c^∞((1/3,2/3))` 非负、对称、`∫_0^1ψ²>0`，定义
```
G_ψ(N) = N^{-1} Σ_{n+m=N,(nm,N)=1} Λ(n)Λ(m) ψ(n/N)ψ(m/N),   c_ψ=∫_0^1ψ²(u)du.
```
则
```
G_ψ(N) = c_ψ S(N) + O_{ψ}(δ_N),   δ_N=√(S(N)/N)(log N)^{3/2}.
```
特别地，对每个这样的 `ψ`，加权二元 Hardy–Littlewood 渐近（未证命题）成立；取 `ψ→1_{[1/3,2/3]}` 的平滑逼近（配合非负性）可推出 LL 定理 1.2 的 Goldbach 表示数下界 `≫S(N)N/(log N)²`。

**证明.** 对每个权 `ψ`，LL 构造线性泛函 `ℓ_{N,ψ}(h)=(1/2πi)∫_{(σ)}N^s\widetilde{Ψ}(s)(1+s)h(s)ds`（`Ψ=√uψ`，LL §2.5、Prop 7.4），其 Riesz 向量 `v_{N,ψ}` 满足 `‖v_{N,ψ}‖²=Q_ψ`，且由 LL (2.34)–(2.39) 的**同一证明**（只用到权的光滑性、支撑在 `(1/3,2/3)`、`c_ψ>0`）得精确恒等式
```
c_ψS(N) − G_ψ(N) = ⟨T_N v_{N,ψ}, v_{N,ψ}⟩.
```
（这里 `T_N` **不依赖 `ψ`**：它是 `E_N` 的算子；所有权只进入 Riesz 向量。LL 的推导对 `Φ=√uφ` 逐字适用。）

R 即 `‖T_N‖≤δ_N`。于是对任意 `ψ`：`|c_ψS(N)−G_ψ(N)| ≤ ‖T_N‖‖v_{N,ψ}‖² ≤ Q_ψδ_N`，且由 LL (2.37)–(2.38) `Q_ψ≤(e²/2π)∫_0^∞|Ψ−uΨ'|²du/u<∞` 只依赖 `ψ`。∎

**意义.** `R ⇒`（对无穷多权同时成立的）二元 HL 渐近。后者是未证明的、等价于"素对在移位 `N` 处的局部密度定理"的命题。**所以 `R` 至少和"所有加权二元 Goldbach 渐近"一样强**；LL 路线无法通过"只证 Goldbach 渐近"来绕过 `R`。

### 4.2 反向：任何 Goldbach 型数据都不能推出 `R`（[推导]）

**命题 4.2 [推导].** 记 `H_N` 为 LL (2.15) 的条带 Hardy 空间。Riesz 向量族 `{v_{N,ψ}: ψ∈C_c^∞((1/3,2/3))}` 的闭线性张成**含于一个真闭超平面**。等价地，存在 `0≠w_N∈H_N` 使 `⟨w_N,v_{N,ψ}⟩=0` 对所有 `ψ` 成立。因此族 `{⟨T_Nv_{N,ψ},v_{N,ψ}⟩}_ψ`（即**一切**权形 Goldbach 相关误差）**不能决定** `‖T_N‖`；特别地，即使假设对每个权 `ψ` 的加权 HL 渐近一致成立，也推不出 Hypothesis R。

**证明.** 由 LL Prop 7.4 / Lemma 5.2（Fourier–Laplace 表示），`H_N` 等距同构于
```
L²_*( (0,∞), (Nu)^{2α_N}(1+(Nu)^{-2Δ_N})^{-1} du/(2π) ),
```
且泛函 `ℓ_{N,ψ}` 对应该模型中的函数 `V_ψ(u)=Ψ(u)−uΨ'(u)`，`Ψ=√uψ`（LL 记 `V=Φ−uΦ'`，`Φ=√uφ`；见 (2.37) 与 §2.5.2）。于是 `{v_{N,ψ}}` 的闭张成对应于 `{V_ψ: ψ∈C_c^∞((1/3,2/3))}` 的闭张成。
对任意 `ψ∈C_c^∞((1/3,2/3))`：
```
∫_0^∞ V_ψ(u) u^{-2} du = ∫_0^∞ [Ψ/u² − Ψ'/u] du = [Ψ/u]_{u→0}^{u→∞} + ∫_0^∞ [−Ψ/u² + Ψ/u²] du = 0,
```
因为 `Ψ=√uψ` 在 `(1/3,2/3)` 外为 0（`C_c^∞` 的支撑在开区间内）。所以所有 `V_ψ` 落在闭超平面 `𝔥={V∈L²_*: ∫V u^{-2}du=0}` 中（该泛函在 `L²_*` 上连续：在 `[1/3,2/3]` 上权重有正下界，`∫_{1/3}^{2/3}u^{-4}·(weight)^{-1}du<∞`）。而 `𝔥` 是真子空间：例如 `V(u)=u·1_{(1/3,2/3)}(u)` 的 `∫V u^{-2}du=∫_{1/3}^{2/3}du/u≠0`，且可光滑化。
由于内积 `⟨v_{N,ψ},v_{N,ψ'}⟩` 由同一等距的极化给出（把 (2.37) 中 `|V|²` 换为 `V\bar V'`），族张成的正交补中必有非零向量 `w_N`。∎

**[推导] 推论 4.3（壁垒）.**
(i) `R` **严格强于**任何"权形二元 Goldbach 相关数据"（哪怕是对全权类一致成立的、含任意误差的渐近——只要它只约束二次型 `⟨T_Nv,v⟩` 在 `v∈span{v_{N,ψ}}` 上）。
(ii) 缺口的方向有明确含义：违反约束 `∫V/u²=0` 的方向对应端点行为非标准的权（例如 `ψ` 在 `u=1/3,2/3` 处不消失到足够阶、或非对称权）。这些权对应的"Goldbach 相关"不再是标准的二元 HL 计数，而等价于 LL 模型中**边界项/全纯延拓的定值问题**。
(iii) 因此"最小未知量"的严格表述是：`‖T_N‖≤δ_N`，一个 L² 算子范数不等式；它**不能被任何有限族（甚至全族）二元相关渐近替代**。

> 备注：命题 4.2 的推导只用到 LL Prop 7.4 的等距模型与 `C_c^∞` 支撑；若允许不光滑/非紧支权的极限，闭张成仍是真子空间（闭包不变），结论不变。这是"`R` 是 L² 陈述而非 L¹/L∞ 陈述"的精确化。

### 4.3 一个精确的"均匀 HL 型假设"

为完整起见，写出最接近充分的形式（**[推测]** 它仍不充分，见 4.2；但它是 `R` 的必要条件，由 4.1）：

**假设 H_hl(δ)。** 存在常数 `C₀`，使对每个 `ψ∈C_c^∞((1/3,2/3))`（固定）与每个充分大偶 `N`（满足 GRH(N)），
`|G_ψ(N)−c_ψS(N)| ≤ C₀‖v_{N,ψ}‖²δ_N`。
**定理 4.1 说明 R ⇒ H_hl。4.2 说明 H_hl ⇏ R。** 要得到 `R` 必须补上 `span{v_{N,ψ}}` 之外的方向——这在解析上等价于对 `T_N` 的完整核 `E_N(s,\bar z)` 做二维 L² 估计，即回到第 2、3 项。

## 5. 第五项：判定——真正的墙是什么，2026 机器能否帮忙

### 5.1 最小未知量

**[推导/判定]** 现在的图景比 LL 之前更精确：

1. **不是分量范数问题**：`D_N`、`K_N` 的 HS 范数已被本报告压到真阶 `(log N)^{3/2}`，`D_N` 与 `K_N` 的双极点已证明精确抵消。继续"算细一点"最多到 `(log N)^{3/2}`，但那不是正确目标——正确目标是 `P_N` 的 rank saving，见命题 2.7：`‖P_N‖_HS≪(log N)²/√φ(N)` 即可到达 `δ_N` 的对数倍以内；故缺口是"Gram 平坦性 (G2)"（精确目标），不是"分量范数"。
2. **精确目标是 `P_N` 的 Gram 矩阵平坦性 `(G2)`（命题 2.7）**：`tr P_N≍(log N)²` 而 `R` 需要 `√N` 的 rank saving，而 `φ(N)≈N` 个正交特征标**理应**提供它。在零点语言下这仍对应跨特征标零点纵标的（2×2 型）四阶加性能量（§3.1）。**但据 phase3 的修正，即使 G2 成立也不能到 δ_N**（`D_N+K_N` 的 `(log N)^{3/2}` 卡住三角界）；G2 不是 LL 的墙。
3. **它是严格强于二元 Goldbach 定量形式（加权 HL 渐近）的陈述**（定理 4.1 + 命题 4.2）：`R ⇒` 所有加权二元 HL 渐近，而反之不成立。所以"二元素数对相关未证"是**必要**壁垒，但**不是全部**：即使有人给出所有权的二元 HL 渐近，`R` 仍差一个 L² 方向。
4. **结论**：墙 = (i) 与 (ii) **同时**成立且同一：需要"零点四阶相关/跨特征标 `L'/L` 四阶矩"这一 `L²` 型输入；它蕴含（强于）二元相关，而现有任何 (ii) 型结果（Montgomery 对相关、GPY、BV for ΛΛ、Montgomery–Hooley）都是**二阶/平均/上界**型，落在错误的一侧。

### 5.2 2026 机器（Alpöge/Claude）能否帮忙

**[事实]**（本地仓库 /home/kiler/rh-full，read-only，与 lead 备忘录一致）：该证明架构是 Stepanov 型多重性 + theta 提升链 + Guinand–Weil 显式公式/Chebyshev 增长 ⇒ 零区，加上 Hermitian 曲率/Bost 斜率不等式（heat kernel 是其中深层工具，用于 Hermitian 丛的曲率/torsion，不是 Hilbert–Pólya 谱构造）。

**[推测] 逐项判定为什么现在无效**：
1. **Stepanov 多重性 / theta 提升**：证明的是"`L` 函数在临界线上零点重数"的代数-几何约束（通过有限域模型/提升链）；输出是**多重性/非零区**，不产生 `L'/L` 的**定量 L² 相关**。本问题需要 `|g_χ|²` 的四阶跨特征标积分，多重性信息不够。
2. **Weil 正性判据**：`RH ⇔` 显式公式二次型 `W(f*f̄)≥0`；这是乘性对象（零点 ↔ 素数 Fourier 对），给的是**正性**（下界方向）。本问题的 `R` 是 `‖T_N‖` 的**上界**（定量小性），正性不能给出上界（lead 备忘录 R1–R5 已严格论证方向问题）。
3. **Hermitian 曲率 / Bost 斜率**：输出是算术 Hilbert–Samuel 型正性与斜率不等式（数域/Abelian 簇的算术几何量），与 `L'/L` 在条带上的解析相关无已知通道；这些量对模 `N`、高度 `t` 的**一致解析**估计无效。
4. **Chebyshev 增长 ⇒ 零区（`Formalism.HC.ChebyshevGrowthImpliesZeroFree`）**：只给定性零区（宽度 `c/log N` 级），不给分布/相关；LL Lemma 6.4 的二阶矩已经是该方向能取到的极限，而它只给 `(log N)²`。
5. **形式化本身**：即使机器证明了某个正确的四阶相关定理（目前连陈述都没有），也需要先有人类可读的数学。当前无。

**可能的（仅思辨）方向**：唯一看起来"方向正确"的 2026 新工具是**显式公式的定量正性**（如果 Alpöge 的 Chebyshev 增长论证内部实际使用了比"零区"更强的显式公式估计，例如带权重的 Weil 二次型的定量下界，则可能与四阶零点能量有关）。但本地代码/论文摘要层面**没有任何证据**其有这个强度；[推测] 即使有，也需要新的翻译工作，且会被命题 4.2 的"真超平面"障碍限制在 L² 方向上，仍需全新的构造。

### 5.3 诚实结论

- **没有**证明 `‖T_N‖≪δ_N`；**没有**证明任何严格优于 `(log N)²` 的 `‖T_N‖` 上界（只对各分量 `D_N,K_N` 做到 `(log N)^{3/2}`，且证明三角和仍为 `(log N)²`）。
- **得到**：（a）LL 分解的严格化 + 双极点精确抵消恒等式 `S(N)c_N=1`（新、可证）；（b）`D_N,K_N` 的 HS 范数从 `α^{-2}` 改进到真阶 `α^{-3/2}`；（c）`R ⇒` 全权类加权二元 HL 渐近（`R` 强于 Goldbach 定量形式）；（d）任何 Goldbach 型权数据都不能推出 `R`（真超平面壁垒，新）；（e）零点四阶相关是精确的中间未知量。
- **判定**：LL 路线内部逻辑自洽（在其 GRH + S/R 假设下），但 `R` 的证明等价于（强于）二元 Goldbach 定量形式加一个 L² 抵消；这是 2026 年数学的**真墙**，不是靠改进估计技术能跨越的。
