## 2. 机理：N^{-1/2} 是特征标族平均的涨落

### 2.1 精确的涨落分解 [证明]

**引理 2.1.** 取任意一族算子 `A_χ` 使 `(2/φ)Σ_{χ∈X^-}A_χ=D_N+K_N`（最简单：`A_χ=½(D_N+K_N)` 对每个 χ），定义 `\tilde T_χ:=|f_χ⟩⟨f_χ|−A_χ`。则精确地
```
E_N = (2/φ) Σ_{χ∈X^-} \tilde T_χ,
‖E_N‖²_HS = (4/φ²) [ Σ_{χ} ‖\tilde T_χ‖²_HS + Σ_{χ≠ψ} ⟨\tilde T_χ,\tilde T_ψ⟩_HS ].      (2.1)
```
**证明.** `(2/φ)Σ|f_χ⟩⟨f_χ|=P_N`；代入定义即得第一式；展开 HS 内积即得第二式。∎

**推论 2.2 [证明].** 若 `max_χ‖\tilde T_χ‖_HS≤ρ_N`，则
`‖E_N‖_HS ≤ (2/φ)Σχ‖\tilde T_χ‖ ≤ 2ρ_N`（三角，差）与 `‖E_N‖_HS ≤ 2ρ_N/√(φ/2)`（当交叉项 ≤0 时恒成立：`‖E_N‖²≤(4/φ²)·φ·ρ_N²`），即
```
2ρ_N/√φ ≤? — 一般地 (4/φ²)Σχ‖\tilde T_χ‖² ≤ (4/φ)ρ_N²  ⇒  ‖E_N‖_HS ≤ (2/√φ)ρ_N·√(1+交叉/(φρ_N²)).
```
若交叉项可忽略（近似正交），**`‖E_N‖_HS≈(2/√φ)ρ_N`**。这正是"Θ(N) 个特征标求平均 → 涨落 `1/√N`"的严格代数形式：**N^{-1/2} 来自 `2/√φ(N)`（`φ(N)=Θ(N)`），不是来自零对分布的额外因子。**

### 2.2 均值 = 模型；涨落 = 跨特征标相关 [推导]

- **均值**：`(2/φ)Σ_χ|f_χ⟩⟨f_χ|=P_N`。模型 `D_N+K_N` 由三族的**局部密度 `S(h)`** 构成；`S(h)` 与 χ 无关（来自 h=kN 的局部素数密度），且 `D_N` 的对角项 `Σ_{(n,N)=1}Λ²(n)n^{-1-w}` 也与 χ 无关（`|χ(n)|=1`）。故把 `|f_χ⟩⟨f_χ|` 的"期望"取为模型是自然的。**[推导]**
- **零对的作用**：GRH 下 `g_χ(s)=Σ_γ[1/(s−iγ_χ)−1/(3/2−iγ_χ)]+b_χ(s)`。对 χ 平均时，每个 χ 的零点集在平均意义下由密度 `(1/2π)log(N(|t|+2))` 替代——这给出显式公式的**均值**（即对角/密度项，回到 `D_N` 与模型）；**涨落** `Σ_χ(Σ_γ−密度积分)` 由零点位置相对于均匀密度的偏差决定，其大小由**跨特征标相关**控制，而不是单 L 函数零点密度本身。所以"零对的 N^{-1/2}"与"特征标平均的 N^{-1/2}"是同一件事的两种语言；其中**特征标平均的表述更适合用大筛/正交性处理**。**[推导]**
- **定量**：由 (2.1) 与数据 `‖T_N‖≈C₀/√N`、`φ≈N/2` 得
  `ρ_N ≈ C₀·√φ /(2√N)·... ` 精确化：`‖T_N‖≈(2/√φ)ρ_N=2√(2/N)ρ_N` ⇒ `ρ_N≈(C₀/√2)/2·?`
  数值：`C₀=62` ⇒ `ρ_N≈62/(2√(2/N)·√N)=62/(2√2)=21.9`。**故逐特征标超差 rms ≈22（O(1)，且与 `(logN)^{3/2}` 同量级：`(logN)^{3/2}≈34.5–42.6`）。** [数值]

### 2.3 与论文 `(logN)²` 的对比

论文 Thm 6.2：`‖T_N‖≤‖P_N‖_HS+‖D_N‖_HS+‖K_N‖_HS≪(logN)²`，用的是
(i) `‖P_N‖_HS≤trP_N≪(logN)²`（迹界，即逐特征标**点态** `|g_χ|≪log²N` 与 Gram 平凡界）；
(ii) `‖D_N‖_HS,‖K_N‖_HS≪(logN)²`（phase-2 已改进到真阶 `(logN)^{3/2}`）。
从 `(logN)²` 到 `N^{-1/2}` 需要 **χ-平均的平方根抵消**（`1/√φ`），即把 `Σ_χ` 的**交叉项**压小；这是论文完全没用到的信息。**[推导]**

## 3. 什么算术命题 ⇒ `‖T_N‖≪δ_N`；能证到哪里

### 3.1 条件定理（本轮最强可证形式）[证明]

**定理 3.1.** 设
```
(H_per)   对所有 χ∈X_N^-：‖\tilde T_χ‖_HS ≤ ρ_N,   且 ρ_N ≤ c₁√(S(N))(log N)^{3/2};
(H_orth)  |Σ_{χ≠ψ}⟨\tilde T_χ,\tilde T_ψ⟩_HS| ≤ ε_N φ(N) Σ_χ‖\tilde T_χ‖²_HS，  ε_N→0（或 ≤C）；
```
则对充分大偶 N，
```
‖T_N‖ ≤ ‖T_N‖_HS ≤ (2/√φ)ρ_N√(1+ε_N) + o(δ_N) ≪ δ_N,
```
即 **R 成立**（从而 S 成立、LL Thm 1.1/1.2 非空）。定量：`(2/√φ)ρ_N ≪δ_N` ⇔ `ρ_N ≪ (√φ/2)√(S/N)(logN)^{3/2} ≈ (1/√2)·√S(logN)^{3/2}`。
**证明.** 由引理 2.1、`φ(N)=Θ(N)`（`φ≥N/(e^γ loglogN+3)`，如 N 偶则 `φ(N)≥N/(2 loglog N)` 量级；只需 `φ≫1` 与 `√φ≫1`），代入 (2.1)：`‖E_N‖²≤(4/φ²)(φρ_N²+ε_Nφ²ρ_N²)=(4/φ)(1+ε_Nφ?)ρ_N²`（按 (H_orth) 形式得 `(4/φ)(1+ε_N)ρ_N²`），开方得 `‖E_N‖≤(2/√φ)√(1+ε_N)ρ_N`。再由 `‖T_N‖≤‖T_N‖_HS=‖E_N‖_HS`（T_N 的定义即 E_N 的边界核算子）与 `δ_N` 比较。∎
> **注意**：(H_per) 中的 `ρ_N` 是**逐特征标**超差，不是 `‖f_χ‖²`（后者 ≪(logN)²，只给 `‖T_N‖≪(logN)²/√N·(logN)^{1/2}` 的 `(logN)^{1/2}` 损失）。定理 3.1 把缺口精确化：**只需要逐特征标超差 `ρ_N=O((logN)^{3/2}√S)`，比平凡的逐特征标范数 `(logN)²` 好一个 `(logN)^{1/2}`。** 数据 `ρ_N≈22`（O(1)）远超所需（`(logN)^{3/2}√S≈40–55`），与 R 渐近为真相容。

### 3.2 用大筛/正交性能否证明 (H_orth) 与 (H_per)？尝试与停止点 [推导]

**(a) 逐特征标超差 (H_per)——最可能可证的部分。** `\tilde T_χ=|f_χ⟩⟨f_χ|−½(D_N+K_N)`。要证 `ρ_N≲(logN)^{3/2}√S`，需要单 χ 的 kernel 与模型之差。LL Lemma 6.4 的 Perron 恒等式 (6.12) 对单 χ 成立：
`g_χ(s)=P_{χ,X}(s)+Z_χ(s)`，`X=N/2`，`Z_χ` 为零点和。则
`‖f_χ‖²_{H_N}=E_χ(α_N)≪(logN)²`（phase-3 命题 2.1，已证）。但 `‖\tilde T_χ‖_HS≤‖f_χ‖²+½‖D_N+K_N‖_HS≪(logN)²+(logN)^{3/2}`——**平凡估计给 `(logN)²`，比目标差 `(logN)^{1/2}`**。要改进 `(logN)^{1/2}` 需要 `f_χ` 与模型"近正交"的单 χ 信息：即 `E_χ(α_N)=∫|g_χ|²/(1+t²)dt` 的**精细值**（不是平均界），以及 `⟨f_χ,½(D_N+K_N)⟩` 的相消。**这看起来可攻**（单变量问题！），例如用 (6.12) 的 `P_{χ,X}` 与 `Z_χ` 分项估计 `E_χ` 并减去模型主项——但 `Z_χ` 的点态下界/相位控制与 `L'/L` 的大值分布有关；时间盒内未完成。**[推导/开放]**
**(b) 跨特征标正交 (H_orth)——大筛的自然对象，但条带上是障碍。** 若能把 `\tilde T_χ` 写成 `Σ_n a_nχ(n)` 型短 Dirichlet 多项式（AFE/Perron 后的 `P_{χ,X}` 部分），则
`Σ_{χ,ψ}⟨\tilde T_χ,\tilde T_ψ⟩` 化为 `Σ_ω|Σ_n a_nω(n)|²`（`ω=χψ̄`），大筛给 `≪(N+M)Σ|a_n|²`。问题：`a_n=Λ(n)w(n)n^{-1/2-α_N}` 长度 `N/2`，`Σ|a_n|²≈(logN)²/4`，大筛给 `≪N(logN)²`——代入 `(4/φ²)` 得 `‖E‖²≪(4/N²)·N(logN)²·N?` 需仔细核算（`Σ_{χ,ψ}` 有 φ² 项、每个 `|⟨·,·⟩|²` 是大筛量）；粗算 `‖E‖²≤(4/φ²)·φ²·(max|⟨·,·⟩|²)`——若无大筛则无改进。**关键障碍**：`f_χ` 在条带上不是短多项式（`P_{χ,X}` 部分长度 `N/2` 太大；`Z_χ` 是零点和不具算术系数），大筛无法直接作用于 `Z_χ`。AFE 的"短和"（长度 √(N|t|)）在 phase-4 已被证明不能重现 `D_N` 的对角质量（`Δ≍(logN)²/8`），故也不能独立证明 (H_orth)。**[推导；这是精确的停止点]**
**(c) 已知技术边界**：level-aspect 零点统计（Iwaniec–Luo–Sarnak 的一阶密度、Hughes–Rudnick 的 n-级密度、Katz–Sarnak 对称型）给出的是**对 test 函数（Fourier 支撑受限）求平均的主项**，不提供 kernel 的逐点/L² 一致估计（我们需要对所有 t、且带 `1/(1+t²)` 权重的 L² 界），也不能给出 (H_orth) 中的显式 `ε_N` 与 `ρ_N`。**[推导；文献见 phase-4]**

### 3.3 另一条可能路线：不要把 `D_N+K_N` 分开，而直接证 `‖E_N‖_HS≪δ_N`

由引理 2.1 的 (2.1)，`‖E_N‖²_HS=(4/φ²)(...)`；若能用**算术展开**直接计算 `Σ_{χ,ψ}⟨\tilde T_χ,\tilde T_ψ⟩`，其主项应正好被模型的 `S(h)` 密度抵消（这是 LL 的"cancellation between components"），剩余为涨落 `~φρ_N²`。障碍同 3.2(b)：条带上无收敛展开。phase-4 的 AFE 记账给出 `Δ_{√N}≍(logN)²/8` 的不可消对角质量，说明"显式正交 + 误差项"路线不足。**[推导；否定 PH-4 结论]**

## 4. 障碍定理与 Alpöge 机器

### 4.1 定理形式的行为（R 与算术相关的精确关系）[证明/推导]

```
[∃ 逐特征标超差 ρ_N=O((logN)^{3/2}√(S(N))) 且 跨特征标 HS 交叉项 ≤o(φ)Σ‖·‖²]  ⇒ R ⇒ H_Gold ⇒ Goldbach.
```

**[证明：定理 3.1 + phase-2/3 结果]**
**注意**：如果数据最终确认 `‖T_N‖≈62/√N`（无 S），则 `R` 渐近为真；这是**首个对 LL 路线的正面结论**，但它仍需证明（§3）。若 `‖T_N‖` 真的 `≈62/√N` 且 `R` 真，则 `LL Thm 1.2` 非空——但证明 `‖T_N‖≲N^{-1/2}(logN)^A` 仍是未解的算术问题（强度**弱于** Goldbach，强于 GRH）。

### 4.2 Alpöge 机器能否给出 (H_per)/(H_orth)？[推导]

- Weil 正性/显式公式：单变量乘性，给出的是**单 L 函数**零点分布的泛函正性，不能产生 `Σ_{χ≠ψ}` 的跨特征标相关。
- Hermitian 曲率/Bost 斜率：算术几何正性，与 `L'/L` 的 level-aspect 相关无已知通道。
- theta lift/Stepanov 多重性：给出零点重数/零区，不给出 `L'/L` 的 L² 相关。
- Chebyshev 增长显式公式：定性零区；不够。
**结论**：无通道（与 phase-2/3/4 结论一致）。

## 6. Lead 追问的逐条回答：严格引理、ρ_N 核算、数值判据（本节为最终版本）

### 6.1 中心权重的更正与精确分解 [证明]

**更正**：`|X_N^-|=φ(N)/2`（奇特征标占一半），故
```
(2/φ)Σ_{χ∈X^-} (D_N+K_N) = (2/φ)·(φ/2)·(D_N+K_N) = D_N+K_N.
```
因此正确的中心是 **`c=1`（不是 ½）**：
```
T̃_χ := |f_χ⟩⟨f_χ| − (D_N+K_N)      （每个 χ 都减去完整的模型算子 Q_N:=D_N+K_N）
⇒  E_N = P_N − Q_N = (2/φ)Σ_{χ∈X^-} T̃_χ        （恒等式，无误差）
⇒  ‖E_N‖²_HS = (4/φ²)[ Σ_χ‖T̃_χ‖²_HS + Σ_{χ≠ψ}⟨T̃_χ,T̃_ψ⟩_HS ].                 (6.1)
```
（Lead 建议的 `½(D+K)` 会给 `(2/φ)Σ½=½`，只能得到 `E_N+½Q_N`，不是 `E_N`；必须用 c=1。）

**等价核算公式 [证明].** 记 `P_N=(2/φ)Σ|f_χ⟩⟨f_χ|`、`Q_N=D_N+K_N`、`G_{χψ}=⟨f_χ,f_ψ⟩`。则
```
avg_χ‖T̃_χ‖²_HS := (2/φ)Σ_χ‖T̃_χ‖² = ‖Q_N‖²_HS − 2⟨P_N,Q_N⟩_HS + (2/φ)Σ_χ‖f_χ‖⁴,     (6.2)
‖E_N‖²_HS = ‖P_N‖²_HS + ‖Q_N‖²_HS − 2⟨P_N,Q_N⟩_HS,                                    (6.3)
‖P_N‖²_HS = (2/φ)²[Σ_χ‖f_χ‖⁴ + Σ_{χ≠ψ}|G_{χψ}|²],                                     (6.4)
(2/φ)Σ_χ‖T̃_χ‖² = ‖E_N‖²_HS − (2/φ)²Σ_{χ≠ψ}|G_{χψ}|²  ≤  ‖E_N‖²_HS.                  (6.5)
```
**证明.** (6.4) 由 `P_N` 的秩一项展开；(6.2)(6.3) 用 `⟨|f_χ⟩⟨f_χ|,Q⟩=⟨f_χ,Qf_χ⟩` 与 `Σ_χ⟨f_χ,Qf_χ⟩=(φ/2)⟨P_N,Q⟩`；(6.5) 由 (6.2)+(6.3)+(6.4) 相减。∎

### 6.2 ρ_N 能否做到 (logN)^{3/2}？——GRH + Lemma 6.4 只能给 (logN)²，差一个 log^{1/2}（这正是 R 真/假的分界）[证明/推导]

**命题 6.1.** 在 GRH 与 phase-3 命题 2.1（逐特征标 `max_χ E_χ(α_N)≪(logN)²`，即 (G1)）下：
```
avg_χ‖T̃_χ‖²_HS = O((logN)^4),   即 ρ_N := √(avg‖T̃_χ‖²) = O((logN)²).
```
**证明.** (6.2) 三项估计：
1. `(2/φ)Σ_χ‖f_χ‖⁴ ≤ (max_χ‖f_χ‖²)·(2/φ)Σ_χ‖f_χ‖² = (max E_χ)·tr P_N ≪ (logN)²·(logN)² = (logN)^4`（用 (G1) 与 LL (6.9)/Prop 6.5 的 `trP_N≪(logN)²`）。
2. `‖Q_N‖²_HS ≍ (logN)³`（phase-3：`‖D_N+K_N‖_HS≍(logN)^{3/2}`）。
3. `2⟨P_N,Q_N⟩_HS ≤ 2‖P_N‖_HS‖Q_N‖_HS ≪ (logN)²·(logN)^{3/2} = (logN)^{7/2} ≤ (logN)^4`（用 LL `‖P_N‖_HS≤trP_N≪(logN)²`）。
故 `avg‖T̃‖² ≪ (logN)^4+(logN)³+(logN)^{7/2}=O((logN)^4)`。∎

**命题 6.2（缺口）. ** R 在 HS-路线的充分条件是 `avg‖T̃_χ‖² ≪ (φ/4)δ_N² ≍ N·(S/N)(logN)³/4 = (S/4)(logN)³`（由 (6.1) 忽略交叉项 `‖E‖²≤(4/φ)avg‖T̃‖²`）。与命题 6.1 的 `O((logN)^4)` 相比，**恰好差 `(logN)^{1/2}√S` 的因子**：
```
ρ_N ≤ (√S/2)(logN)^{3/2}   ⇔   R 的 HS-路线成立；   命题 6.1 只给 ρ_N=O((logN)²).
```
**回答 Lead Q2：用 GRH + Lemma 6.4 不能给出 `ρ_N=O((logN)^{3/2})`；它们只给 (logN)²，差距就是关键的 log^{1/2}。**
- 缺口性质：需要 `(2/φ)Σ_χ‖f_χ‖⁴` 与交叉项 `2⟨P_N,Q_N⟩` 相消到 `(logN)³` 量级。这不是自动的：`‖f_χ‖⁴` 的主项来自 `|f_χ|` 的大值（局部 `L'/L` 值），交叉项 `⟨f_χ,Qf_χ⟩` 依赖 `f_χ` 与模型 `Q_N` 的**相位对齐**——正是逐特征标的"四阶矩/对齐"信息，**Lemma 6.4 的二阶平均完全看不到**。
- 能否改进？**(i)** 若能用 Perron 恒等式 (6.12) 逐 χ 精确算 `E_χ(α_N)` 与 `⟨f_χ,Qf_χ⟩`，把两者在 (6.2) 中相消到 `(logN)³`——这是**单变量**问题，原则上可攻（本报告未完成）；**(ii)** 或者换中心：由于约束 `Σ_χ c_χ=(φ/2)Q_N`，无法把中心取成"逐 χ 最佳"；但可以把 `Q_N` 的**主奇异方向**从中心中提出、令 `T̃_χ=|f_χ⟩⟨f_χ|−Q_N`——本报告的分析表明 `‖f_χ‖⁴` 主导，换成秩一中心可望把 `(logN)^4` 降到 `(logN)³`（**具体：`|f_χ⟩⟨f_χ|` 的 HS 范数是 `‖f_χ‖⁴`，而 `‖f_χ‖²_(G1)≪(logN)²` 是"逐特征标平方"的界；若典型 `‖f_χ‖²≍(logN)²`，则 `‖f_χ‖⁴≍(logN)^4`——要降到 `(logN)³` 必须证明典型 `‖f_χ‖²≪(logN)^{3/2}`，这与 (G1) 的 (logN)² 差 log^{1/2}。** 即：**问题的核心精确地是逐特征标平方的典型值：`max_χ E_χ≪(logN)²`（已证）能否改进为 `avg_χ E_χ≪(logN)^{3/2}`（未证）？**）[推导]

- 注意：有限模型给的是**算子范数**（最大特征值），不是 HS 范数；`‖E‖_op≪‖E‖_HS` 是正常的（随机核矩阵：`‖E‖_op≈2‖E‖_HS/√(有效维数)`）。故不能用 `λmax` 直接核验 (6.2)。若 pipeline 能输出 `P_N` 与 `Q_N` 的矩阵元，则可直接测 (i)–(iv)。**具体请求**：请 spectral-numerics 输出 `(2/φ)Σ_χ‖f_χ‖²`、`(2/φ)Σ_χ‖f_χ‖⁴`、`‖Q_N‖_HS`、`⟨P_N,Q_N⟩_HS`（在 N=30030,40022,100042 三点，H=40/mesh=1/16），即可定量判断 HS 路线是否可行、log 指数是 1.5 还是 2。

### 6.4 最终判断（更新）

1. **标度**：`C=λ√N/√S` 数据 27–49（2p 37–49，多因子 27–39），无平滑 log 趋势；`ratio=C/(logN)^{3/2}`，2p 族 1.07–1.39 递减，N*≈3–7×10^5。**R 是否渐近为真取决于 `C(N)` 是否保持有界；现有数据与"有界"相容但不足以排除慢增长（logN 范围仅 15%）。**
2. **机理**：`N^{-1/2}=2/√φ` 的特征标平均涨落（§2、§6.1）；中心权重 `c=1`。
3. **ρ_N 问题（核心）**：GRH+Lemma 6.4 只能给 `ρ_N=O((logN)²)`；R 的 HS-路线需要 `ρ_N≲(√S/2)(logN)^{3/2}`；**差 `(logN)^{1/2}√S`**。等价地：需要把逐特征标平方的典型大小从 `(logN)²` 改进到 `(logN)^{3/2}`（或利用交叉项相消）。**这就是 LL 路线剩余的全部算术困难在 N^{-1/2} 标度下的精确表述**——比"证明 Goldbach"弱（是单变量四阶矩/对齐问题），但仍是 GRH 之外的新输入。
4. **Alpöge 机器**：仍无通道（§4.2）；该缺口是 level-aspect 的 L'/L 四阶矩/逐特征标对齐，Weil 正性等单变量工具不提供。
