## 0. 结论摘要（诚实版）

   Δ_X(w) := D_N(w) − D_N^{(X)}(w) ≈ (log N)²/4 − (log X)²/2 ≈ (log N)²/8   （≫ δ_N，且为 O((log N)²)）

   这部分质量**必然**由 Main×Dual、Dual×Dual、Γ 项与 AFE 误差携带；但这些项在对偶化后给出的对角是 `n^{-1+w}`（即 `D_N(−w)`）或 `n^{-1-s+\bar z}` 等**不同函数**，既不是 `D_N` 也不是 `K_N` 的形状；把它们在 χ-平均后精确算出来等价于回到 `P_N` 本身（循环）。**所以 AFE+正交性无法显式再现 `D_N` 以完成 `E_N` 抵消**；缺失的 `Ω((log N)²)` 没有可利用的"√N 抵消"。**[推导；定量记账为 [证明]]**

## 1. AFE 路线：定量记账与精确停止点

### 1.1 已知的严格工具：LL 的 Perron 恒等式（不是 AFE，但起同样作用）

LL Lemma 6.4（(6.12)，p.37–38）给出**严格**恒等式（对每个固定 χ，`u=1/2+σ+it`，`σ>0`，`X=N/2`，`x=√X`）：
```
−L'/L(u,χ) = P_{χ,X}(u) + (1/log x) Σ_ρ (X^{ρ−u}−x^{ρ−u})/(ρ−u)²,   P_{χ,X}(u)=Σ_{n≤X}Λ(n)χ(n)n^{-u}w_X(n).
```
其中 `ρ` 遍历原特征的零点（含重数）与 Euler 因子零点。这是"主和 + 零点对偶和"的**严格**版本；GRH 下零点 `ρ=1/2+iγ` 使对偶和的核为 `(X^{−σ+i(γ−t)}−x^{−σ+i(γ−t)})/(−σ+i(γ−t))²`。LL 用它证明平均二阶矩 (6.9)。**任何 AFE 论证都必须与它一致**；下面的记账对 (6.12) 型表示同样成立。

### 1.2 AFE 的期望形式与合法性 [推导]

对 `z_0=1/2+s`（`Re z_0∈(1/2+α_N,5/8)`），标准平滑 AFE（`L'/L` 版）形如
```
g_χ(s) = −Σ_{n≤X} Λ(n)χ(n)n^{-1/2-s} V(n/X)
        + W(χ)(d_χ/π)^{s} Σ_{n≤Y} Λ(n)χ̄(n)n^{-1/2+s} V_1(n/Y)   +  Γ_χ(s) + Err_χ(s),
XY ≍ N(|t|+2),   |Err_χ(s)| ≤ (N(|t|+2))^{-A}（C^∞ 平滑，A 任意），Γ_χ(s)= 显式 Γ 项。
```
- **合法性 [事实+推导]**：对 `L` 的标准平滑 AFE 是定理（Iwaniec–Kowalski Thm 5.3 型）；对 `L'/L` 取对数导数会引入 `1/L`，GRH 给出 `|1/L(ρ附近)| ≪ (N(|t|+2))^{o(1)}`（Littlewood 型），故误差 `(N(|t|+2))^{o(1)}`——**远小于 √N，可接受**。因此"AFE 在条带上一致有效"**不是**障碍（这一点与 task 的担心相反）。
- 平衡长度 `X≍Y≍√(N(|t|+2))`；`|t|=O(1)` 的 HS 积分主区域给 `X≍√N`。

### 1.3 特征标正交性只能看到截断对角（记账引理）[证明]

**引理 1.1.** 设 `g_χ(s)=M_χ(s)+R_χ(s)`，其中 `M_χ(s)=Σ_{n≤X}a_nχ(n)n^{-1/2-s}V(n/X)`（`a_n=Λ(n)`）。则在 `(nm,N)=1` 时
```
(2/φ(N)) Σ_{χ∈X_N^-} M_χ(s)\overline{M_χ(z)}
 = Σ_{n≤X,(n,N)=1} Λ²(n) n^{-1-w} V(n/X)²
   + Σ_{n+m=N, n,m≤X,(nm,N)=1} Λ(n)Λ(m) n^{-1/2-s}m^{-1/2-\bar z} V(n/X)V(m/X)
   + [n≡m mod N, n≠m, n,m≤X 项 = 0（因 X<X+X<N）],
w=s+\bar z.
```
**证明.** 由 LL (2.1) 的奇投影 `(2/φ)Σ_{χ∈X^-}χ(n)\barχ(m)=1_{(nm,N)=1}(1_{n≡m mod N}−1_{n≡−m mod N})`（对 `χ(n)\barχ(m)` 的正确形式；LL 印刷式中第二因子写作 `χ(m)`，在 `(n,N)=1` 时等价于对 `m` 取逆的同一投影，对本引理的两类项结果不变）。对 `n,m≤X`：`n≡m mod N` 且 `|n−m|≤X<N` ⇒ `n=m`；`n≡−m mod N` 且 `n+m≤2X=2√(N(|t|+2))<N`（对 `N` 充分大、`|t|=O(1)`）⇒ 不可能；故只剩对角与和族。∎

**推论 1.2（对角质量差距）. [证明]** 记 `D_N^{(X)}(w)=Σ_{n≤X,(n,N)=1}Λ²(n)n^{-1-w}V(n/X)²`。由 KT2 引理 1.2，`D_N(w)=w^{-2}+O(1)`；而
```
D_N^{(X)}(w) ≈ (log X)²/2 + O(log X·log(1/Re w)),
Δ_X(w):=D_N(w)−D_N^{(X)}(w) ≈ w^{-2}−(log X)²/2.
```
取 `X=√N`、`w=2α_N=2/log N`：
```
D_N(2α_N) ≍ (log N)²/4,   D_N^{(√N)}(2α_N) ≍ (log N)²/8,
Δ_{√N} ≍ (log N)²/8.
```
`Δ_{√N}/(δ_N) ≍ √N(log N)^{1/2}`：**缺失量是 δ_N 的 √N·log 倍**。

### 1.4 为什么缺失质量不能由 AFE 的其它项凑出（精确停止点）[推导]

由引理 1.1，正交性可见的部分只含：
(a) 截断对角 `D_N^{(X)}`；
(b) 和族 `n+m=N`（`n,m≤X≍√N`——注意真实 Goldbach 和族的权重支持 `n/N∈[1/3,2/3]`，即 `n~~N`！所以 `n,m≤√N` 的和族项是 `O(N^{-1/2+...})` 级别的**极小**项，不是 `G(N)` 的和族）；
而真实 `P_N` 中 `n~N` 的质量（对角 + 和族）只能来自以下项：
(c) Main×Dual、Dual×Main：对角（`n=m`）给出 `Σ_{n≤min(X,Y)}Λ²(n)n^{-1-s+\bar z}` 或 `n^{-1+s-\bar z}`——**指数不是 `−1−w`**（因为 Main 用 `n^{-1/2-s}`、Dual 用 `n^{-1/2+s}`），故不是 `D_N` 的一部分，也不能与 `K_N` 的 `(s+z)`-型匹配；
(d) Dual×Dual：对角给出 `Σ_{n≤Y}Λ²(n)n^{-1+w}·(d/π)^{2s}`——即 `D_N(−w)` 型（`n^{-1+w}`），**不是** `D_N(w)`；
(e) Γ 项：解析函数（无 `w^{-2}` 极点），O(log N)；
(f) 误差：`N^{o(1)}`。
**关键点**：`E_N = P_N−D_N−K_N` 中 `P_N` 的全部"显式正交部分"是 (a)+(c)+(d)+(e)；减去 `D_N` 后，`−Δ_X` 这个 `(log N)²` 量级的负项**必须**被 (c)(d)(e) 中对应的那些项**在解析意义上**补回来（因为 AFE 是恒等式）。但 (c)(d) 携带的指数 `n^{-1±(s−\bar z)}` 在 `s≈\bar z` 附近才接近 `n^{-1}`，且其 `χ`-平均结构是**乘积** `χ(n)χ(m)` 型（不是 `χ(n)\barχ(m)` 型），其正交性产生 `nm≡1 mod N` 一类的乘法条件——**不再是对角 `n=m`**。因此把 (c)(d) 精确化为 `D_N` 的一部分需要重新引入 `L'/L` 的算术信息（即回到起点）。**[推导]** 换句话说：AFE 把对角质量"搬到"非对角的 `χ(n)χ(m)` 乘积项上，而正交性对这些项只给出乘法条件；要证明它们的 `χ`-平均小（或抵消）就等价于控制跨特征标的 `L'/L` 乘积相关——正是 KT3 的 (G2)/四阶对象，且 KT3 已证即使有 (G2) 也不足（`D_N+K_N` 的 `(log N)^{3/2}` 地板）。

**结论（AFE 路的停止点）**：AFE 能给的是 `P_N` 的**恒等重排**，不是 `E_N` 的抵消；"正交性把双和压成 √N 长度的对角"这一希望在量级上不成立，因为 `D_N` 的质量来自 `n~N` 而非 `n~√N`（`Δ_{√N}≍(log N)²/8`）。**任何仅基于"AFE + 特征标正交性 + 误差项"的论证，其可显式处理的量 ≤(log X)²=(log N)²/4 量级，缺失的 Ω((log N)²) 落在正交性不可见项中。** 这与 KT3 命题 1.4 的三角地板 `Ω((log N)^{3/2})` 相容，且更强：AFE 甚至不能把 `E_N` 的 `(log N)²` 对角部分抵消掉。

## 2. 函数方程自对偶：精确恒等式，但不给界

### 2.1 恒等式 [证明]

设 `χ∈X_N^-`，`χ*` 为其原特征，导子 `d=d_χ|N`（奇特征 ⇒ 符号 `ε=1`）。完备函数
`Λ(u,χ*)=(d/π)^{(u+1)/2}Γ((u+1)/2)L(u,χ*)` 满足 `Λ(u,χ*)=W(χ*)Λ(1−u,χ̄*)`，`|W|=1`。取对数导数：
```
L'/L(u,χ*) = −L'/L(1−u,χ̄*) − log(d/π) − (1/2)[ψ((u+1)/2)+ψ((2−u)/2)].
```
对一般 χ（可能非本原），`g_χ(s)=L'/L(1/2+s,χ)=L'/L(1/2+s,χ*)+e_χ(1/2+s)`，`e_χ(u)=Σ_{p|N,p∤d}χ*(p)log p/(p^u−χ*(p))`（LL (3.7)；注意 LL 的 `e_χ` 定义使 `g_χ=L'/L(·,χ*)+e_χ`，符号以 LL (3.8) 为准）。取 `u=1/2+s`，整理得
```
g_χ(s) = −g_{χ̄}(−s) + h_χ(s),
h_χ(s) = e_χ(1/2+s) + e_{χ̄}(1/2−s) − log(d_χ/π) − (1/2)[ψ(3/4+s/2)+ψ(3/4−s/2)].   ∎
```
**[证明]**（对 `χ` 与 `χ̄` 的 `e` 项做了 `e_{χ̄}(1/2−s)` 的代入；`L'/L(1/2−s,χ̄*)=g_{χ̄}(−s)−e_{χ̄}(1/2−s)`。）

### 2.2 对 P_N 的变换 [证明]

由 `P_N(s,\bar z)=(2/φ)Σ_χ g_χ(s)g_{χ̄}(\bar z)` 与 2.1（对 `g_χ(s)` 与 `g_{χ̄}(\bar z)` 各用一次；注意 `\overline{g_χ(z)}=g_{χ̄}(\bar z)`）：
```
P_N(s,\bar z) − P_N(−s,−\bar z) = −(2/φ)Σ_χ h_χ(s)g_χ(−\bar z) − (2/φ)Σ_χ g_{χ̄}(−s)h_{χ̄}(\bar z) + (2/φ)Σ_χ h_χ(s)h_{χ̄}(\bar z).
```
右端是 `h_χ`（导子/Γ/Euler 修正项的显式和）与 `g` 的**线性**项 + 常数项。

### 2.3 为什么不能给出界 [推导]

1. **区域不相交**：`T_N` 的核只在 `S_N×S_N`（`Re s,Re z∈(α_N,β)` 的正半条带）上有定义；`(−s,−\bar z)` 落在 `Re∈(−β,−α_N)`。恒等式把条带上的值联系到**定义域外**的 `P_N` 值，不能直接约束 `S_N` 上的 L² 范数。
2. **非齐次项不小**：`(2/φ)Σ_χ h_χ(s)g_χ(−\bar z)` 是 `h` 的 χ-平均乘 `g` 的 χ-平均型对象；`h_χ` 含 `log(d_χ/π)`（`≪log N`）与 `e_χ`（`≪log N`），不能忽略；且 `g_χ(−\bar z)` 在 `Re(−\bar z)<0`——其 Dirichlet 级数发散，需用 FE 再转回，循环。
3. **模型/对角不尊重对称**：`D_N(w)−D_N(−w)=−2Σ_nΛ²(n)n^{-1}sinh(w log n)`（对 `Re w>0` 需延拓；不是小量，且其 `w`-展开系数发散）；`K_N(−s,−\bar z)` 含 `(π/N)^{-w}·P(−w)ζ(1+w)·X1(−s)X1(−\bar z)`，而 `X1(−s)=1/X1(s)`——`β=1/8` 与 `α_N` 不配对，无协变关系。故 `E_N` 无 "奇/偶 + 上边缘（coboundary）" 结构。
4. **零点配对 `γ↔−γ` 的无效性**：FE 把零点 `γ` 与 `−γ` 配对（`Z_χ(s)` 中的 `Σ_γ1/(s−iγ)` 在 `s↦−s` 下变成 `Σ_γ1/(−s−iγ)=−Σ_γ1/(s+iγ)`；零点集在 `γ↦−γ` 下不变（`ρ→1−ρ`）），但 `Z_χ(s)\overline{Z_χ(z)}` 的零点对相关在配对下给出的是同一四指标和的重新排列，**不产生正负抵消**（配对是自同构，不改变加性能量）。

**结论**：FE 自对偶是**精确恒等式**（2.1），但无法转化为 `E_N` 在 `S_N` 上的范数上界；它没有提供任何类似于"正性/消失"的结构。**[证明恒等式；[推导] 无界]**

## 3. 张量 Weil 正性：为什么用不上

1. **事实**：RH 等价于 Weil 显式公式二次型 `W(f*f̄)≥0`（对适当 test 函数类）；Alpöge 证明的机器把这类正性用于一变量乘性对象（零点/多重性/零区）。**[事实]**
2. **方向**：`R` 需要 `|⟨T_Nv,v⟩|≤δ_N‖v‖²` 的**双侧**小性；Weil 正性只给**单侧下界**（`≥0`）。即使能构造 `E_N = Q_1 − Q_2` 使 `Q_j≥0`，也只能得 `⟨T_Nv,v⟩ ≥ −⟨Q_2v,v⟩`，不能得 `|·|` 上界；要上界需 `Q_2` 的正性（即另一个 RH 型输入）。**[推导]**
3. **张量构造的障碍**：`W⊗W` 型正性只对"每因子正定"的和式保持（`Σ_j f_j⊗g_j` 当 `W(f_j*f̄_j)≥0, W(g_j*ḡ_j)≥0` 时非负是**乘积**型结论，对和式不成立，因为交叉项无控制）。`E_N` 的核在低高度为 `O(1)` 且**不定**（LL 自己说"Subtraction need not preserve positivity"），不可能写成非负和。**[推导]**
4. **两变量显式公式的"正性"= 未知的对相关**：两变量（张量）Weil 泛函的正性在零点语言下对应 Montgomery 型对相关/加性能量的下界；这正是 KT2 §3.1 指出的未知对象（且我们需要的还是上界）。**没有免费的正性**。**[推测/事实]**
5. **Kuznetsov/pretrace/large sieve**：这些工具对 `Σ_χ|·|²` 型（迹/平均）有效，对算子范数（`sup` 方向）或核的 L² 范数需要四阶量；KT3 §3.2 已给出具体停止点。**[推导]**

**结论**：张量 Weil 正性路线没有可用通道。

## 4. 最小条件定理（本报告的正面结果）

### 4.1 定理 A（Goldbach 的最小充分条件，比 R 弱）[证明]

**定理 A.** 设 `φ` 为 LL 固定的权（`C_c^∞([1/3,2/3])` 非负对称）。假设
```
(H_Gold)  对充分大偶 N：  |G_φ(N)−c_φS(N)| ≤ C₀ δ_N,   C₀<∞ 固定，
```
则每个充分大偶数 `N` 都是两个素数之和（且表示数 `≫N/(log N)²`）。

**证明.** 由 `G_φ(N)>0`（`G_φ` 是素数对的非负权和）即得 Goldbach（LL 的 prime-power 移除论证同 LL §2.5.3）。`G_φ>0` 由 `c_φS(N)>C₀δ_N` 对充分大 `N` 成立（`c_φ>0`，`δ_N/S(N)=(log N)^{3/2}/√(S(N)N)→0`）保证。∎

**精确刻画**：由 LL (2.34)–(2.39)，`(H_Gold) ⇔ |⟨T_Nv_{N,φ},v_{N,φ}⟩|≤C₀Q_φδ_N`，即**单个**二次型（在 Riesz 向量 `v_{N,φ}` 方向）的有界性；**不需要**算子范数 `R`。由 KT2 命题 4.2（真超平面壁垒），`v_{N,φ}` 方向的全部加权 HL 数据**推不出** `R`——故 `H_Gold` 严格弱于 `R`。**`H_Gold` 是 LL 路线到 Goldbach 的精确最小未知**（它本身即加权二元 Hardy–Littlewood 渐近，未证）。**[证明/推导]**

### 4.2 定理 B（跨特征标相关假设不足以代替 E_N）[证明]

**定理 B.** 设 `(G1)`（单特征标 `max_χ‖f_χ‖²≪(log N)²`，KT3 命题 2.1 已证）与 `(G2)`（Gram 平坦，`Σ_{χ≠ψ}|⟨f_χ,f_ψ⟩|²≪φ(N)^{-1}(Σ‖f_χ‖²)²`）都成立。则只能推出 `‖P_N‖_HS≪(log N)²/√N`；但
```
‖T_N‖ ≥ |‖D_N+K_N‖_HS − ‖P_N‖_HS| ≥ c(log N)^{3/2} − o((log N)^{3/2}) = Ω((log N)^{3/2}),
```
（用 KT3 命题 1.4 的下界 `‖D_N+K_N‖_HS≥c(log N)^{3/2}` 与 KT3 (G1)+(G2) 的 `‖P_N‖_HS` 上界；注意 `‖P_N‖_HS≤(log N)²/√N=o((log N)^{3/2})`。）故 `(G1)+(G2)` 推不出 `‖T_N‖≤δ_N`（差 `√N`）。**因此任何纯 `P_N`-侧（2-点/Gram/四阶零点）假设都不能替代 `E_N=O_N−K_N` 的抵消。** ∎

### 4.3 结论：最小未知的精确表述

**命题 4.1（归纳）.** 在 GRH 下，以下三陈述等价/层级：
```
(A) H_Gold(φ)（单个加权 HL 误差 O(δ_N)）  ⇒ Goldbach；         [定理 A]
(B) R：‖T_N‖≤δ_N（强于 H_Gold；H_Gold ⇏ R）；                 [KT2 4.2]
(C) E_N 的 L² 抵消：‖P_N−(D_N+K_N)‖_{HS}≤δ_N；
(A) 是 LL 路线到 Goldbach 的最小充分条件；(B)、(C) 的证明都超出当前技术；
已知的"标准猜想型"输入（GRH、Montgomery 对相关、Chowla、GPY、BV、大筛、零点 n-级相关）没有一条能推出 (A) 或 (B)；
两变量 Weil 正性若成立则等价于对相关型输入，亦不直接给出 (B)（§3）。
```
**[推导]**

## 7. 追加（2026-11-21 下午）：若有限谱模型显示 ‖T_N‖ 不随 N 衰减，R 是否可能为假？

> 背景：spectral-numerics 用与 LL 附录 B 完全一致（已复现 N=30030 特征值）的管道，在其他模数得到 `λmax≈0.21–0.36`、近似与模数无关；`δ_N=√(S/N)(log N)^{3/2}` 随 N→0，故对 `N=2p`（`S(N)` 最小）出现 `‖C‖/δ_N>1`（N=40022: 1.39；N=39994: 1.07）。若为真，Hypothesis R 沿 N=2p 为假。以下为理论侧回应（不改前面各节；标注同前）。

### 7.1 关于"‖T_N‖ 有与 N 无关的正下界"的分析论证 [推导/推测]

**没有找到严格下界证明；但有一个强有力的结构性论证说明"λmax 与模数近似无关"正是我们已证恒等式的自然结果**：

1. **模型归一化恒等式消去了全部 `S(N)` 依赖。** 由 KT2 定理 1.3（`S(N)c_N=1`，对所有偶 N 精确），`K_N` 的双极点系数恰为 `−S(N)c_N=−1`，与 `D_N` 的 `+1` 精确抵消；`K_N` 的单极点系数 `κ_N=log N−log 2π+ψ(3/4)+O((loglog N)²)` 只含 `log N`。即：**`E_N` 在低高度层的振幅在局部奇点层面没有 N-依赖（也没有 S(N)-依赖）**；N 只通过缓慢的 log 因子进入。因此有限模型中 `λmax` 近乎与模数无关，是**已被证明的归一化恒等式的直接结构推论**，不是意外。
2. **R 要求的是 `√N` 级衰减，而所有已证结构都不含它。** 已证：`P_N` PSD、其对角/迹、(G1)、`S(N)c_N=1`、KT3 的 `κ_N` 与 `D_N+K_N` 的 HS 下界——全部只给 `(log N)^{O(1)}` 级信息，没有任何机制把 `‖E_N‖` 压到 `N^{-1/2}`。`δ_N` 的 `1/√N` 因子来自 `S(N)/N` 的归一化，而非局部解析结构。**所以"λmax≈const 而 δ_N→0"与所有已证事实完全相容；反而是 R 的 `√N` 衰减需要一个全新机制。**
3. **稀疏模数效应**：`N=2p` 时只有 `S(N)` 达到最小（`→2C₂≈1.3204`），`δ_N` 最小；但由 1，`λmax` 不含 `S(N)`。所以"稀疏模数最先失效"正是结构所预测的模式，无需 `E_N` 的 cancelling 机制在稀疏模数下"失败"——它本来就不依赖 `S(N)`。
4. **候选下界机制为何失败**（Lead 的两个想法）：
   - **有限秩缺陷** `rank P_N≤φ(N)/2 < ∞` 与 `P_N^⊥` 无穷维：秩在范数下**不连续**；有限秩算子可在范数下逼近无穷秩算子（截断投影 `P_M→I`），故"P_N 有限秩 + H_N 无穷维"不产生任何范数下界。**无矛盾。**
   - **正性**：`D_N+K_N≈κ_N B`，`B` 的核 `1/((1+s)(1+\bar z)(s+\bar z))=∫_0^∞e^{−su}e^{−\bar z u}du` 是 **PSD**（对任意 `w∈H_N`，`⟨Bw,w⟩=∫_0^∞|∫w(s)e^{−su}/(1+s)|ds||²du≥0`）。若 `D_N+K_N` 在整个条带上都 ≈`κ_NB`，则在 `ker P_N` 上 `⟨T_Nw,w⟩=−κ_N⟨Bw,w⟩−...≤0`，于是 `‖T_N‖≥κ_N·c`（若 `B` 在 `ker P_N` 上有 ≳1 的二次型），会给出**增长**下界——但这与有限模型矛盾，说明该近似**只在 `|w|≲1` 成立**：远离 `w=0` 时 `D_N+K_N` 的核有 `O(1/Re w²)=O((log N)²)` 量级的修正项（`D_N(w)` 的绝对值界），足以抵消 `κ_N B`。**所以"正性 + 有限秩"不能给出下界；在低高度层需要 `P_N` 与 `(D_N+K_N)` 的精细算术抵消（= 我们一直说的未知量）。**
5. **结论（Q1）**：没有严格下界证明；但若有限模型可信，`λmax` 不衰减是**结构上自然**的，R 为假是**可信的**（有限模型证据：R 在 N=40022 处已失败于有限模型；且 `δ_N→0` 对任何固定 S(N) 都成立，故只要 `λmax` 不衰减，R 对所有充分大 N 失败）。**待证/待核：有限模型的方向性（Q2）。**

### 7.2 有限模型的方向：压缩原理与精确陈述 [证明/推导]

设 `K(s,z̄)=E_N(s,\bar z)/((1+s)(1+\bar z))`，`K` 是 `L²(Γ_N)` 上的核算子（LL Prop 5.3 表明 `T_N` 是 `K` **限制在 Hardy 迹空间** `H_N` 上的算子；限制不减范数）。有限模型的矩阵
`C=W^{1/2}\tilde K W^{1/2}`，`W=diag(w_i)`（trapezoid 权重），`\tilde K_{ij}=K(s_i,\bar s_j)`。
取标准正交阶梯函数 `φ_i=w_i^{-1/2}1_{arc_i}`，则 `⟨Kφ_j,φ_i⟩≈K_{ij}w_iw_j/√(w_iw_j)=√(w_iw_j)K_{ij}=C_{ij}`（对光滑核，误差 = 求积误差）。故
```
C (至多差求积误差) = K 在 V_M=span{φ_i} 上的压缩矩阵；  从而  ‖C‖ ≤ (1+η)‖K_{L²}‖，
T_N = K 在 H_N 上的压缩；                                  ‖T_N‖ ≤ ‖K_{L²}‖。
```
**两个压缩之间没有序关系**（`V_M` 与 `H_N` 是同一算子 `K` 的两个不同子空间的压缩），故严格地说：
- **不能**仅由 `‖C‖>δ_N` 推出 `‖T_N‖>δ_N`——模型可能**高估**（若 `K` 的最大特征方向在 `H_N` 之外有质量）；
- 也**不能**说模型低估。LL 自己用同一模型声称 `‖C‖/δ_N=0.827<1` 支持 R，其逻辑地位与现在 `>1` 是对称的。
**可补充的量化**：(i) 求积误差 `η=O(h^a)`（`h=1/16`，核光滑，`h^a` 很小）；(ii) 高度截断误差：H=40→60 时比值只变 1.3915→1.3959（变化 0.3%），表明截断误差 ≪1%；(iii) hermiticity 1e−16 表明对称性正确。**结论：模型值 1.39 是强证据但非证明**；要成为证明，需要验证最大特征向量在 `H_N` 中的成分（例如用 LL Lemma 5.2 的 Fourier–Laplace 表示检验其边界迹是否属于 Hardy 迹空间，或计算 `‖P_{H_N}v_M‖/‖v_M‖`）。**建议 spectral-numerics 做此 Hardy 投影检验**（这是把"R 疑似为假"升级为"R 为假"的关键一步）。
**一个部分严格化的方向**：若 `K` 的**所有**特征函数都在 `H_N` 内（即 `K` 的谱型与 `H_N` 相符），则 `‖C‖→‖T_N‖`；可检验 `K` 的边界迹是否是两边界上互为解析延拓的函数对（因 `E_N(s,\bar z)` 对 `s` 解析、对 `z` 反解析，`K` 的像函数 `s↦(Kh)(s)` 恒解析——**像空间在 `H_N` 内**；这排除了"输出非 Hardy"的情形，但不排除"输入非 Hardy 导致更大范数"）。**[推导]**

### 7.3 R/S 为假时的逻辑地位，及 H_Gold 是否仍可行 [证明/推导]

1. **R 的地位**：LL 的 Hypothesis R 是对**所有充分大偶 N** 的断言。若它在无穷多 N（如 N=2p 的无穷子列）为假，则 Hypothesis R 作为全称命题为**假**；于是 Theorem 1.2 的假设不可满足 ⇒ 该定理虽仍为真（条件命题），但**无法应用于任何充分大的 N**，对 Goldbach 无效。同理 Theorem 1.1 依赖 Hypothesis S。
2. **S 的临界比值 [证明]**：由 LL (2.28)，S 要求 `‖T_N‖≤S(N)/(2h(N)√(1−η_N))`，`η_N=h²(log N)³/(N S(N))≤1/4`。令 `x=√η_N∈(0,1/2]`，则右端 `=δ_N/(2x√(1−x²))`（因 `δ_N=√(S(N)/N)(log N)^{3/2}`）。`2x√(1−x²)` 在 `(0,1/2]` 上最大于 `x=1/2`，值 `√3/2`，故**S 的最强可能要求是 `‖T_N‖≤(2/√3)δ_N≈1.1547δ_N`**（Lead 的系数正确）。于是：有限模型比值 >1.1547 ⇒ **S 在该 N 也失败**（N=40022: 1.39 ⇒ S 失败；N=39994: 1.0722<1.1547，S 数值上仍可成立；N=90090: 1.0019<1.1547 可成立）。若 `λmax` 不衰减，则 S 沿 N=2p 的充分大子列也将失败（因 `(2/√3)δ_N→0`）。
3. **H_Gold 仍可行（关键结论）**：H_Gold（单个二次型 `|⟨T_Nv_φ,v_φ⟩|≤Qδ_N`）与 R 的失败**完全不矛盾**：
   - KT2 命题 4.2（真超平面壁垒）已证明：Goldbach 数据只约束 `span{v_ψ}` 上的二次型，**不约束**正交补方向；有限模型的大范数很可能正来自这些"非 Goldbach 权"方向（其对应测试函数的 Laplace 参数不在 `[1/3,2/3]`，Beta 模型 `K_N` 在这些方向上的归一化不再匹配，故 `E_N` 可以大）。
   - 直接算术计算（lead memo §4）显示在真实 Goldbach 权 `φ` 下 `|G_φ(N)−c_φS(N)|/δ_N≈0.003–0.014`（N≤5×10⁸），即 `v_φ` 方向的抵消远好于算子范数方向。
   - 因此：**R/S 很可能是假的（有限模型证据），但这不否定 H_Gold，也不否定 LL 的精确归约 `r(N)=⟨T_Nv_N,v_N⟩`；只否定 LL 用来证明 H_Gold 的充分条件 S/R。** LL 论文作为"条件性证明"在逻辑上仍然成立但很可能**空虚**（假设不可满足）；对 Goldbach 有用的剩余目标就是 H_Gold 本身（= 加权二元 Hardy–Littlewood 渐近）。
4. **对有限模型的进一步建议**（给 spectral-numerics/audit）：
   (a) **Hardy 投影检验**（7.2 末）：验证最大特征向量的 Hardy 迹成分，决定方向性；
   (b) **在 v_N 方向计算二次型**：把 `v_N` 的离散化向量 `v_disc` 代入 `⟨Cv,v⟩`，与直接算术 `r(N)`（`probe2.c` 体系）比较；预期（若 H_Gold 成立）该二次型/δ_N 应 ≪1（lead memo 数据 ~0.003–0.014），而算子范数 ~0.3——两者并存正是超平面壁垒的数值体现。此前 r_num/r_direct≈1.8–2.4 需用修正后代码复核（归一化/权重/1/(2π) 因子/字符完备性都可能是差异来源）。
   (c) 模数趋势：`N=2p` 子列是关键（`S(N)` 最小）；但理论上对**任何固定 S(N)** 的族，只要 `λmax` 不衰减，`λmax/δ_N→∞`。故趋势应在所有族中出现，只是快慢不同。

### 7.4 对"最小未知"的最终陈述（更新）[推导]

```
LL 归约（精确、无条件成立）：c_φS(N)−G_φ(N)=⟨T_Nv_N,v_N⟩。
R/S（充分条件）：很可能为假（有限模型证据，非证明；方向性待 Hardy 投影检验）。

   若 H_Gold 为真则 Goldbach 成立；若 H_Gold 为假则 Goldbach 的这条定量形式为假。
2026 现状：没有证明 H_Gold；有限模型不能再作为"支持 R"的证据（LL 附录 B 的地位相同）。
```
**结论**：如果 spectral-numerics 的模型与 Hardy 投影检验确认"‖T_N‖≈O(1)>δ_N"，那么 LL 路线作为 Goldbach 的证明**实际已失败**（其两个谱假设之一 R 为假；S 沿稀疏模数子列也为假），而不仅是"未证明"；但这**不**排除 H_Gold（{单二次型}），LL 的精确归约仍可作为研究框架。**本轮结论以有限模型为证据、非证明；最终判定需独立数值复核 + (7.2) 的方向性检验。**
