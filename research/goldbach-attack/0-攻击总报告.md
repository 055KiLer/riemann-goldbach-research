## 2. 路线 1：Li–Liu 条件性证明的完整审计

对象：Jiamin Li & Jianya Liu, *A Conditional Proof of the Goldbach Conjecture*，山东大学 MRC，2026-11-13，63 页，**未上 arXiv、未同行评审**（本地 PDF `/home/kiler/rh-work/liu-goldbach.pdf`；逐页审计见 `liu-audit.md`）。

### 2.1 论文的逻辑链（[事实]，式号引自论文）

1. 奇特征正交投影：`G(N) = D(N) − P(N)`（(2.1)–(2.4)）。
2. Mellin 化：`P_N(s,z) = (2/φ(N)) Σ_{χ odd} g_χ(s)g_χ(z̄)`，`g_χ = L′/L(1/2+·,χ)`（(2.6)）。
3. Beta 模型：减去对角 `D_N` 与模型 `K_N`，残差 `E_N = P_N − D_N − K_N`（§2.2）。
4. Hardy 条带 `S_N = {α_N < Re s < β}`，`α_N = 1/log N`，`β = 1/8`，核 `E_N(s,z̄)/((1+s)(1+z̄))` 定义**紧自伴 Hilbert–Schmidt 算子 T_N**（(2.17)、Prop 5.3）。
5. **精确二次型恒等式**：`r(N) = c_φS(N) − G(N) = ⟨T_N v_N, v_N⟩`（(2.39)），`‖v_N‖² = Q_N ≪ 1`。
6. 主估计：`|G(N) − c_φS(N)| ≪ ‖T_N‖`（(2.19)）。
7. 零–范数字典（我们独立重推，与论文 (2.23)/(2.28)/(2.30) 一致）：
   `X_N(q) = ∏_j (1 − 4μ_j²/(δ_N² q(1−q)))`，`δ_N² = S(N)(log N)³/N`。
   - `R(N)`（所有零点 Re q = 1/2） ⇔ `‖T_N‖ ≤ δ_N`；
   - `S(N;h)`（Re q > 1−η_N 无零点，`η_N = h²(log N)³/(N S(N))`） ⇔ `‖T_N‖ ≤ S(N)/(2h(N)√(1−η_N))`。
   - 由此可写成**统一形式**：若存在绝对常数 C 使 `‖T_N‖ ≤ C·δ_N` 对所有充分大偶数 N 成立，则 `G(N) = c_φS(N)+O(Cδ_N) = c_φS(N)(1+o(1))`，从而每个充分大偶数 = 两素数之和。
8. Theorems 1.1/1.2：S 或 R + GRH(N) ⇒ Goldbach（充分大）。

### 2.2 审计结果（[事实]/[推导]）

- **内部链条自洽，未发现致命错误**。独立重推了零–范数字典、Beta 模型恒等式 (2.32)–(2.33)（= −c_φS(N)，含 π^w 常数）、Γ 分解 (4.4)、二次型恒等式 (7.17)（含共轭细节）、素数幂剔除。N=30030 的附录独立复核：Goldbach 无序素数对 **905**（与论文一致），`S=5.1212553`，`δ=0.4323102409`，`α_N=0.09699366`，均一致。
- **论文自己明确承认 GRH 不够**：GRH 只给 `‖T_N‖ ≤ ‖T_N‖_HS ≪ (log N)²`（Thm 6.2/(2.24)），零自由宽度 `η_N^GRH ≍ S(N)/(N log N)`（(2.25)）。原文（p.12）："This available norm bound is too large to make the Goldbach error smaller than its main term; S and R impose the required improvement."（p.4 同义）。
- **精确差距**：`(log N)² / δ_N = √(N/S(N))·(log N)^{1/2}`。数值：N=10¹⁰ 时 ≈4.2×10⁵；N=10²⁰ 时 ≈5.9×10¹⁰；N=10¹⁰⁰ 时 ≈1.3×10⁵¹。
- **为什么这个差距"结构上"补不上**（Prop 6.5 的进一步分析）：`P_N` 与 `D_N` 都是**正算子**且迹类，`tr P_N ≍ (log N)²`，`tr D_N ≍ (log N)²`，`‖K_N‖_HS ≍ (log N)²`。R 要求 `T_N = P_N − D_N − K_N` 的范数 ≤ `(log N)^{3/2}/√N`，即要求量级为 `(log N)²` 的 `P_N` 与 `D_N+K_N` 发生 **~√N/(log N)^{1/2} 倍**的相消。这不是"把估计做细"能得到的：`P_N` 是正算子，其秩/迹结构决定了它在 HS 意义下就是 (log N)² 量级；要它与别的算子抵消到 1/√N，就必须精确到 Goldbach 主项本身。
- **攻击尝试（全部失败）**（详见 `liu-audit.md` §9）：
  (a) 三角不等式/HS：如上，卡在 (log N)²；  
  (b) 复制核点值下界：我们推出 `‖T_N‖ ≥ 4m²logN/(φ(N)(1+γ²))`（m 为零点重数，γ 为某奇特征 L 零点纵坐标），并用 Rosser–Schoenfeld 型下界证明它恒 `≪ δ_N`——所以这条路线甚至**不能证伪 R**；  
  (c) 借用 Alpöge/Weil 正性：Weil 显式公式是**乘性**的（单个素数幂），T_N 的核是 L′/L 的**平方/相关**结构（加性），无已知桥梁；  
  (d) 圆法/配对相关翻译：R 等价于"对所有 Hardy 检验函数一致的加权素数对相关上界"，属于 minor-arc/奇偶性层级，比 GRH 强。
- **文献状态**：只有 MRC 官方页 + 中文科普/论坛转帖，未发现任何技术批评/follow-up/arXiv 版本；也无人把本文与 2026-11-20 的 GRH 声明联系起来（Alpöge remark 全文 0 次出现 Goldbach）。
- **推测（重要且正面）**：R 未必是假命题。δ_N 换算到素数对计数误差约 `√(S(N)N)/√(log N)`，只比"随机平方根涨落" `√(S N)/log N` 大 `√(log N)` 倍，是合理量级；我们的数值实验（§5）也支持。**更准确的判断是：S/R 是"可能为真、但需要全新定理"的算子范数命题，而不是荒谬假设；Li–Liu 把 Goldbach 精确重编码成一个谱范数版加性素数对一致估计，并没有把它变简单。**

### 2.3 结论

**路线 1 = 一个诚实、内部自洽的条件性归约；缺口是一个与 Hardy–Littlewood 猜想同量级的新定理（`‖T_N‖ ≪ δ_N`）。Alpöge 的 GRH 证明不能填补它。** 我们无法在本轮（或任何现有文献）中证明 S/R。

### 3.2 严格否定结果（[证明]，可手写/可形式化）

**引理 R1（热核迹正性自动成立，零信息）**：设 A 为实 Hilbert 空间上自伴、下有界、离散谱算子，则对一切 t>0，
`Tr e^{−tA} = Σ_j e^{−tλ_j} > 0`，且对任意平移 A↦A+c 不变。∎
所以"证明热核迹正性"是重言式，无法区分任何算术命题。

**引理 R2（正生成函数不蕴含正系数）**：`F(t) = e^{−t} − 2e^{−2t} + 2e^{−3t}`。令 `u = e^{−t} ∈ (0,1)`：
`F = u(1 − 2u + 2u²) = u(2(u−1/2)² + 1/2) > 0` 对一切 t>0 成立，但系数 `a₂ = −2 < 0`。∎
即：热核/生成函数型正性**不能**推出 Goldbach 所需的系数（表示数）正性；从生成函数到系数需要解析延拓/零点控制（一个新的 RH 型问题），正性信息对它完全盲。更甚：`(Σ_p x^p)² = Σ_N r_2(N)x^N`，左边对 `0<x<1` 自动正，右边系数正性正是 Goldbach——自然热核/配分函数正性是免费的。

**引理 R3（Li–Liu 框架中正性方向反了）**：`r(N) = c_φS(N) − G(N) = ⟨T_N v_N, v_N⟩`（LL (2.39)）。若 `T_N ≥ 0` 则 `⟨T_Nv_N,v_N⟩ ≥ 0`，于是 `G(N) ≤ c_φS(N)`——而 Goldbach 需要 `G(N) > 0`，即需要 `⟨T_Nv_N,v_N⟩` 的**上界**（`‖T_N‖` 界），不是正性。有限维模型：对实内积空间 H、`v≠0`、`c∈ℝ`，
`{c − ⟨Tv,v⟩ : T 自伴, T ≥ 0} = (−∞, c]`（取 `T = α vv*`，`α = (c−g)/‖v‖⁴ ≥ 0`）。∎
所以正性甚至允许 G 任意负，**不能给出任何正下界**。此外 LL 自己说 "Subtraction need not preserve positivity, so eigenvalues of either sign must be allowed"（§2.3.1）——T_N 本身就不是正算子。

**引理 R4（迹的方向）**：紧自伴 T 的特征值 μ_j；`Tr e^{−tT} = Σ e^{−tμ_j} ≥ e^{−t‖T‖}`，所以 `‖T‖ ≥ −(1/t)log Tr e^{−tT}`——热核迹给的是范数的**下界**，不能证明所需的小范数上界。族 `T_M = M·P`（P 秩一投影）满足 `Tr e^{−tT_M} = e^{−tM} + (N−1) ≥ 1` 而 `‖T_M‖ = M→∞`。∎

**引理 R5（构造性尝试的边界）**：可显式构造"双粒子算子" `H = L⊗I + I⊗L`，使 `Tr e^{−tH} = Σ_N r(N)e^{−tN}`（r 为（加权）Goldbach 计数）；但正性自动成立，且对"某个 r(N₀)=0"完全盲（删除任一项，迹仍 >0）。这说明"热核迹 = Goldbach 相关"的算子可以造，但正性不携带系数信息。RH 的 Weil 正性是**乘性**的（`Σ_n Λ(n)f(n)` 型，只涉及单个素数幂），与加性卷积 `(p,q)↦p+q` 没有已知桥梁；圆法劣弧 + Selberg 奇偶性障碍仍是不可逾越的屏障。∎

### 3.3 结论

**路线 2 的"关键一步"在逻辑上不可能承担所宣称的作用**：无符号热核迹正性是自动重言式；有符号/超迹的正性则等价于某个未知算术命题（那需要全新的构造）。**"RH 谱架构必然蕴含 Goldbach"不成立**——它来自一篇未评审自出版预印本的摘要口号，且该文自身推导循环使用了 HL 猜想。我们甚至不能说"RH 证明是对的所以其架构蕴含 Goldbach"——Alpöge 的证明根本就不是热核谱架构（§1 末）。

### 4.4 为什么不能"造一个通过 Lean 的 Goldbach 证明"

- Mathlib（精确 pin 到 RH 证明用的 commit `0df444a3`）**没有** Goldbach 陈述；有 `RiemannHypothesis`（`NumberTheory/LSeries/RiemannZeta.lean:185`）、素数计数/Chebyshev/Selberg 筛/Dirichlet L，但**缺** Hardy 空间、Hilbert–Schmidt、奇异级数、四元数切片解析、显式公式/GRH 下的 L′/L 定量估计等。
- 把 Li–Liu 的"GRH+S/R ⇒ Goldbach 渐近"完整形式化，估计 **10–30 万行 / 60–160 人月（5–13 人年）**；最小条件版也要 3–8 人年。且前提 S/R 本身没有证明。
- Lean 内核不会让假证明通过（这正是 RH 事件教给我们的）。**"只要通过 Lean 就行"不能替代数学证明——没有证明就过不了 Lean。**

## 5. 数值实验：LL 加权相关的实际误差（[数值]，非证明）

按 LL (1.3) 计算 `G(N) = (1/N)Σ_{n+m=N,(nm,N)=1}Λ(n)Λ(m)φ(n/N)φ(m/N)`，取光滑对称权 `φ(u)=exp(−1/(1−(6u−3)²))`（支撑 [1/3,2/3]，C∞、0≤φ≤1），`c_φ=∫φ²≈0.022181020141`；C 程序 `scratch/probe2.c`（与独立 Python 实现核对一致）。结果：

| N | S(N) | G(N) | c_φS(N) | \|err\|/δ_N | δ_N/c_φS(N) |
|---|---|---|---|---|---|
| 10⁶ | 1.760 | 0.039656 | 0.039048 | 0.0089 | 1.75 |
| 10⁷ | 1.760 | 0.038875 | 0.039048 | 0.0064 | 0.70 |
| 10⁸ | 1.760 | 0.039022 | 0.039048 | 0.0025 | 0.27 |
| 3×10⁸ | 3.521 | 0.078174 | 0.078096 | 0.0083 | 0.12 |
| 5×10⁸ | 1.760 | 0.038994 | 0.039048 | 0.0102 | 0.14 |

观察：**实际加权误差比 δ_N 还小两个量级**（|err|/δ_N≈0.002–0.014）。这说明：
1. LL 想证明的结论（R 的后果，误差 ≪ δ_N）在数值上不仅成立、而且余量很大——**R 的假设在数值上是健康的，不是荒谬的**；
2. 但数值验证的是二次型 `⟨T_Nv_N,v_N⟩` 小，不是 `‖T_N‖` 小（v_N 只探测一个方向）；不能证明 R，更不能证明 Goldbach；
3. 这让我们对路线 1 的判断更精确：**不是"假设不可能"，而是"假设可能为真、但需要全新定理"**。

## 6. 最终判定与研究前沿

| 路线 | 状态 | 精确缺口 |
|---|---|---|
| 1. Li–Liu (GRH + S/R) | 内部自洽的条件性归约；论文未经评审 | `‖T_N‖ ≪ δ_N`（比 GRH 的 `(log N)²` 强 `√N` 级；需 P_N 与 D_N+K_N 的 √N 级相消） |
| 2. "热核迹正性 ⇒ Goldbach" | 不成立（来源为未评审自出版；关键步是重言式；方向相反；有严格反例与 Lean 验证） | 无法从正性得到系数正性；需要 signed trace + 定量小量估计，等价于新的 Hardy–Littlewood 型定理 |

**真实研究前沿（若有人继续）**：
1. 证明 `‖T_N‖ ≪ δ_N`（或更弱的、足够 Goldbach 的版本）——这是一个新的算子范数/加性素数对一致估计问题，比 GRH 强；需要圆法 minor arcs 或全新的加性相消机制。
2. 改进 Li–Liu 的 (1+1.9)（arXiv:2606.05224）——筛法路线的无条件前沿，但仍需突破奇偶性障碍才能到 1+1。
3. 寻找正确的 signed trace / 超迹表述，使 Goldbach 表示数成为其系数，并且正性可从已知结构推出——目前没有已知构造。
4. 形式化路线：先把 Li–Liu 的条件链形式化（5–13 人年），再谈 S/R；这可以独立于 S/R 的真假进行。

## 9. 诚实边界（必须写清）

1. 我们没有证明 Goldbach；没有产出"通过 Lean 的 Goldbach 证明"；没有伪造。
2. 我们证明的是若干**否定性引理**（路线 2 的关键步骤无效）与**归约的精确化**（路线 1 的缺口），并机器验证了否定引理的退化影子。

4. 数值实验只覆盖 N ≤ 5×10⁸；是证据不是证明。
