> Lead，2026-11-21（phase-11）。本文是 Lead 独立的结构性分析，供 kernel-theorist（task-38 构造尝试）与 liu-auditor（task-37 保守审计）交叉对照。
> 标注：**[推导]**＝本文给出推导/草图；**[标准]**＝文献标准事实（待核）；**[待核]**＝需 kernel-theorist/审计确认；**[推测]**＝判断；**[数值]**＝引用 phase-10 数据。
> 目标回顾（phase-8/10 的 H_Ratios）：存在固定 0<ω_D≤1/2、η₀>0、B≥0，使对每个 0<η<η₀、每个 ε>0、每个整数 q>1，
> `E_q(a,b;s,t) := Σ*_{χ mod q} L(a,χ)L(b,χ̄)/(L(s,χ)L(t,χ̄)) = M_q(a,b;s,t) + O(q^{1−ω_D+ε}(1+T)^B)`，
> 一致于 Re a=Re b=1/2，Re s=Re t=1/2+η，T=max|Im|≤100log(2q)，误差在 (a,b) 圆盘全纯；M_q 为 CFZ 主项（phase-10 报告 §2）。
> **关键容差观察**：GWX 只需任意固定 ω_D>0；取 ω_D 任意小（如 10⁻³）即可完成 Goldbach。因此 Route C 的目标可以弱到"证明任意正的幂次 saving"，而相对误差容许为 q^{−ω}（例如 ω=10⁻²、q=10⁶ 时仍有 87% 的相对余量）。这使"用粗糙估计拿到某个 δ>0 的 saving"在原则上可能足够。

## 0. Route C 的动机（为什么它不是 MDs，也不是显式公式路线）

phase-9 的 MDs 路线与"零点显式公式"路线都卡在两点之一：(a) 一般 primitive Dirichlet 族没有 level-aspect 多重 Dirichlet 级数/函数方程（无二次互反/theta 结构）；(b) 把 1/L 展开成零点和会引出**跨 χ 的零点对相关**（level-aspect pair correlation，未证）。

Route C 绕开这两点：它**不解析延拓**、也**不展开零点**，而是：
1. 用 GRH 把 `1/L(s,χ)`、`1/L(t,χ̄)`（σ=1/2+η）截断成**有限** Möbius 多项式（误差由 GRH 的 Mertens/字符和估计控制，q-依赖只有 log 幂）；
2. 用**光滑近似函数方程**把两个分子 L 展开成**有限** Dirichlet 和（长度 ≍√(q(1+T))，误差指数小）；
3. 对 χ mod q 做**精确**正交性求和 —— 所有"相关性"都被有限和吸收，不需要 Ratios/MDs/pair correlation；
4. 剩下的纯任务：计算这些有限和的主项，并证明其为 M_q + O(q^{1−ω})。

如果这成功，就在 GRH 之上证明了 H_Ratios 的（restricted-shift）弱化版，进而（GWX Thm 1.1）完成 Goldbach。这是当前最值得全力尝试的新方向。

## 1. C1：截断 Möbius 引理（欠 GRH 的 1/L 控制）

**命题 C1（[推导]，q-依赖待核）**。设 GRH 对所有 primitive Dirichlet L 成立，χ primitive mod q，T≥2，σ=1/2+η (0<η≤1/4)，|t|≤T。则
```
1/L(s,χ) = Σ_{m≤X} μ(m)χ(m)m^{−s} + O( X^{1/2−σ} · (1+|t|) · (log(q(1+|t|)X))^{C} ),   s=σ+it,
```
且特别地 `|1/L(σ+it,χ)| ≪η^{−C'} (1+|t|) (log(q(1+|t|)))^{C''}`。

推导要点：
- 取 A(x,χ)=Σ_{n≤x}μ(n)χ(n)。GRH 下（Perron + 轮廓移到 Re=1/2+1/log qT，零点全在 Re=1/2）有 A(x,χ) ≪ x^{1/2}(log(q(1+|t|)x))^{C} [标准]。
- Abel 部分求和：Σ_{m>X}μ(m)χ(m)m^{−s} = −s∫_X^∞ A(u,χ)u^{−s−1}du ≪ |s|X^{1/2−σ}(log)^{C}·(1/(σ−1/2))·...，在对 X 取界后得 C1。
- 注意：失败风险点是 (i) A(x,χ) 的 GRH 界常数是否真的只有 log 幂（q 依赖会不会是 q^{1/2}？）；(ii) 1/L 的**点态上界**——这依赖 1/L 在 σ=1/2+ε 的解析性质与"GRH 零自由区积分"，需 kernel-theorist 从 GWX 原文与文献核实（phase-8 审计称 GWX 用 1/L≪q^ε，见 §3.6；(3.25)）。

**备选表述（更保险）**：只需对几乎所有 χ 的截断成立 + 对例外集用第二矩控制；或把 C1 的 O(...) 换成 L² 形式（见 C2 的 Cauchy–Schwarz）。

## 2. C2：截断误差在 2/2 平均中的传播（[推导]）

记 P_s(χ)=Σ_{m≤X}μ(m)χ(m)m^{−s}，Δ_s=1/L(s,χ)−P_s(χ)，截断平均
`E_q^{(X)} := Σ*_χ L(a,χ)L(b,χ̄)P_s(χ)P_t(χ̄)`。
则 E_q − E_q^{(X)} 展开为四项：Δ_sΔ_t、Δ_s P_t、P_s Δ_t（各带 L(a)L(b)）。
- 用 C1 与 |1/L| 界、|P_t|≤|1/L|+|Δ_t|，以及 Cauchy–Schwarz 对 χ 求和；
- 需要**无条件**第二矩 `Σ*_χ |L(1/2+u,χ)|² ≪ q(1+|u|)^{1+ε}`（[标准]，AFE+大筛可得，phase-2 已有数值经验）；
- 得 `|E_q − E_q^{(X)}| ≪ q^{1+ε} X^{−η} (1+T)^{C} / η^{C'}`。
选择 `X = q^{ω/η}·(1+T)^{C/η}/η^{C'/η}`（任意固定小 ω，例如 ω=η/4 或 ω=10⁻²）即得 `≪ q^{1−ω+ε}(1+T)^{B}`。
**[推导] 结论：C2 不是障碍；截断代价仅是 q^{1+ε}X^{−η}，对任意小的 ω 都可接受。**

## 3. C3：主项计算 —— AFE 四类项与"大项相消"（核心）

对 primitive χ、分子在临界线附近，标准光滑 AFE（[标准]）：
```
L(a,χ) = Σ_{r≤R} χ(r) r^{−a} W(r/R)  +  ε(χ) X_{q,e}(a) Σ_{r≤R} χ̄(r) r^{a−1} W(r/R)  +  指数小误差,
```
R ≍ √(q(1+T))，W 为 Gauss 衰减的光滑权，e=parity(χ)，X_{q,e} 即 phase-8 的 archimedean 因子（phase-10 转录版本）。

展开 `L(a,χ)L(b,χ̄)` 后共四类（记 D=direct, R=reflected）：
| 类型 | χ-幂（含根数） | 正交条件（q 素、忽略 principal 修正） |
|---|---|---|
| ++ (D,D) | χ(rm)χ̄(sn) | rm ≡ sn (mod q) |
| +− (D,R) | χ(rsm)χ̄(n)·ε(χ̄) | 根数/高斯和项 |
| −+ (R,D) | χ(rsn)χ̄(m)·ε(χ) | 根数/高斯和项 |
| −− (R,R) | χ(sm)χ̄(rn)·ε(χ)ε(χ̄) = χ(sm)χ̄(rn)（根数抵消！） | sm ≡ rn (mod q) |

其中 r,s≤R（AFE 求和指标），m,n≤X（截断 Möbius 指标），权重 r^{−a}s^{−b}（或反射的 r^{a−1}s^{b−1}）与 μ(m)μ(n)m^{−s}n^{−t}。

**关键观察（[推导]，重要）**：取 m=n=1（μ(1)=1），类型 ++ 给出
`T^{++}(1,1) = q Σ_{r≤R} r^{−a−b}`，其模 ≈ q Σ_{r≤R} r^{−1} ≍ **q log R**。
而 phase-10 数值显示 |M_q| ∈ [0.2, 1.1]·φ*(q)（无 log q 因子）。同理 −− 类也给出 q log R。
⇒ **类与类之间存在 log q 量级的大项相消**；正项主项 M_q（φ*Z_q + H_qZ_q(1−b,1−a)）是四类项**相消后的残差**。这与标准二次矩计算里"对角主项 ~ q log q"不同，是 2/2 ratio 的独有结构。

**推论**：Route C 的主项计算**不能逐类进行**；必须先把四类合并、利用：
- 函数方程/Gamma 恒等式（GWX (3.4)、(3.11) 型：X_{q,e}(a)X_{q,e}(1−a) 关系）实现相消；
- 根数抵消 ε(χ)ε(χ̄)=1（仅 −− 类，这正是 GWX (3.3) 的 parity twist 的机制）；
- 高斯和精确求值 Σ_χ ε(χ)χ(A)（±类型）；
然后才能得到 M_q 的两项结构。**这是 Route C 的最大技术难点之一（记为 C4）**。

## 4. C4：主项匹配的猜想形式

**猜想 C4（[推测]）**：设 X=q^δ (δ=ω/η 小)、R≍√(q(1+T))。则合并四类并利用函数方程恒等式后，
```
E_q^{(X)} = φ*(q)Z_q(a,b;s,t) + H_q(a,b)Z_q(1−b,1−a;s,t) + Err,
Err ≪ q^{1−ω+ε}(1+T)^B,
```
其中 Err 来自：(i) C2 的截断尾；(ii) AFE 的光滑误差（指数小）；(iii) 各类中"非对角"剩余项（见 C5）。
**验证途径**：heat-kernel-critic 的 task-42(B) 直接数值检验 E_q^{(X)} 是否趋近 M_q（在 η 较大、截断收敛快的区域）；若趋近，C4 的主项识别正确；若趋近别的值或不收敛，则主项提取有结构性错误。

## 5. C5：最可能的墙 —— 根数交叉项与模逆指数和

类型 +−/−+ 含单根数，经高斯和求值后（q 素）：`Σ_χ ε(χ)χ(A) ≈ √q·e(±Ā/q)`（A 为 r,s,m,n 的组合，Ā 为其模逆），于是这些项变成
```
Σ_{r,s≤R, m,n≤X} (权重) · e( ± n·(rsm)^{−1}/q )
```
即**带 μ 权的"模逆指数和"**。用绝对值/几何和粗估：每项 ≤√q·R·X^{1/2−η}·(部分和大小)，在 q 大时**远超 q**；因此必须依赖相位与 μ 权重的**真实相消**。需要的引理：

**引理 C5（临界引理）**：对任意 q（或 q 素）、c∈(Z/q)^*、X≤q、Re s=1/2+η，控制
```
Σ_{m≤X} μ(m) m^{−s} e( c m / q )      （更一般：e( n (rsm)^{−1}/q ) 型联合和）
```
的不完全指数和，使 +−/−+ 类总贡献 ≤ q^{1−ω}。完整和（m mod q 完整）给出 Ramanujan 和 c_q(·)（小，≪d(q)），因此障碍只在**部分和**；候选工具：Gauss 和大筛、Kloosterman 完全和（Weil 界 |S(a,b;q)|≤√q·d(q)）的完成化（completion）+ Erdős–Turán/Vaaler 型判别、以及"逆元等分布"（large sieve for inverses / Duke–Friedlander–Iwaniec δ-method 的有限和版本）。

**关键问题**：C5 是 GRH 级还是更深（= parity barrier）？如果 C5 需要跨 χ 的零点对相关/Type II 信息，则 Route C 在此触墙（但墙的位置会清晰给出）。反之，若 C5 可用"完成化到 Kloosterman 和 + Weil 界 + 粗计数"证明（因为只需要任意小 saving），Route C 就可能成功。

**辅助观察（[推测]）**：
- 由于我们只需要**任意固定小 ω**，C5 不需要尖锐的指数和估计，只需要比平凡界好一点点（log 幂损失可接受）。
- +−/−+ 类是"反射交叉项"：在标准二次矩估计中，同类项由 Gauss 和大筛控制为误差（主项来自 ++/−− 的相消后残差）；Route C 的 2/2 情形是二次矩（L(a)L(b)）与两次 mollifier（1/L·1/L）的混合，C5 本质上是"**带 mollifier 的二次矩的根数交叉项**"——文献（Bui–Keating 型、mollified moments）可能已有可借用工具，值得 kernel-theorist 优先检索。

## 9. Lead 数值核验 C1（2026-11-21，[数值]）

用 `c1_family.py`（本目录）：q=337、1009（素数），将 `1/L(s,χ)`（Hurwitz ζ + 对 (Z/q)^* 的 DFT，mpmath dps=30）与截断 Möbius 和 `P_s(χ)=Σ_{m≤X}μ(m)χ(m)m^{-s}` 比较，对**全部 primitive χ** 取 RMS 尾项，拟合 `log RMS` vs `log X`：

| q | η=0.1 | η=0.25 | η=0.4 | GRH 预测 1/2−σ = −η |
|---|---|---|---|---|
| 337 | −0.102 | −0.254 | −0.403 | −0.10 / −0.25 / −0.40 |
| 1009 | −0.093 | −0.240 | −0.389 | 同上 |

结论 [数值]：
1. **族平均尾项精确按 X^{−η} = X^{1/2−σ} 衰减**（拟合与预测差 ≤0.01–0.02），这正是 C1 的 GRH 预测；Route C 的截断基础在数值上成立。
2. **q-依赖只有 log/常数级**：q=337→1009（×3）时同一 η、同一相对 X 位置的 RMS 几乎不变（如 η=0.1、X=q^0.7：1.130 vs 1.233），未见 q^{1/2} 型增长 ⇒ C1 的 q^ε 说法可信。
3. 注意：绝对常数不小（RMS/|1/L| ~ 0.5–0.8 at X=q^{0.1}）；C2 误差界常数会包含 (log)²/η 因子，但不影响"任意小 ω>0 足够"的结论。
4. 限制：只测了素数 q 与 3 个 η；复合 q 与更大 T 未测（可让 spectral-numerics 顺手扩展，非关键）。

**影响**：C1/C2 基本排除为该路线的障碍；Route C 的判定点仍是 C4（主项相消匹配 M_q）与 C5（根数交叉项的相消/界）。
