## 1. Route C 误差分解（精确）

q 素，σ=1/2+η，`Re a=Re b=Re s=Re t=σ`，四段长度 `N_a=N_b=N_s=N_t=X`（不对称情形见 §5）。
1. [证明/GRH] `L(u,χ)=P_u(χ)+Δ_u`，`|Δ_u|≪X^{−η}q^{ε}`；`1/L(u,χ)=Q_u(χ)+Δ'_u`，`|Δ'_u|≪X^{−η}q^{ε}`（phase-11 Lemma 1.1；GRH 的字符和/μχ 和 + Abel）。
2. [证明] `R_q−E^{(X)}≪q^{1+ε}X^{−η}`（Cauchy–Schwarz + 第二矩 `Σ*|P|²,Σ*|Q|²≪qη^{−1}(log)^{O(1)}`）。
3. [证明] (0.1) 恒等式 ⇒ **`E^{(X)}` 本身就是一个 Ratios 型平均**（截断多项式版）：`E^{(X)}=Σ_{χ≠χ0}(P_aQ_s)(χ)(P_bQ_t)(χ̄)`。主项必须等于该平均的 CFZ 预测值；wrap = 该平均的偏离对角部分。
4. 对角化条件：`A=nr≤X²`，`B=ml≤X²`。`X²≤q` ⇒ `A≡B mod q ⇔ A=B`，非主特征平均退化为对角 Euler 积（phase-11 Lead 的 Euler 积恒等式），可算 ⇒ 弱 Ratios 成立。**`X²>q` ⇒ 非主特征平均不可对角化**：wrap 项出现，且由 (0.1) 它就是该平均本身。

## 2. 路线 1：Gauss 和/FE 折叠——完整推导与判定

**推导**：对 `L(b,χ̄)` 用 FE：`L(b,χ̄)=ε(χ̄)X_q(b,χ̄)L(1−b,χ)`（b 在临界线或 1/2+η 均可形式进行）。于是
```
R_q = Σ*_χ ε(χ̄)X_q(b) L(a,χ)L(1−b,χ) / (L(s,χ)L(t,χ̄)).
```
展开 `ε(χ̄)=τ(χ̄)/(i^{e}√q)`（或 `(-i)^e`，常数无关），`τ(χ̄)=Σ_{u mod q}χ̄(u)e(u/q)`，并把三个 χ 因子展开为 Dirichlet 系数：净字符 = `χ(n n' r)\barχ(l u)`。正交性给 `nn'r≡lu mod q`；`u` 被唯一确定：`u≡l^{-1}nn'r mod q`（(l,q)=1），且对 u 的求和坍缩为**单相位**
```
Σ_{u} e(u/q) δ_{u≡nn'r \bar l} = e(nn'r\,\bar l/q).        (2.1)
```
于是折叠后的表达式是
```
R_q ≃ (q−1)/√q·ε_0 X_q(b) Σ_{n,n',r,l≤X} n^{−a}n'^{−(1−b)}μ(r)r^{−s}μ(l)l^{−t} · e(nn'r\bar l/q) (主半区),   (2.2)
```
加上 `−(1/√q)…` 的 trivial 项。**判定 [证明/推导]**：
- (2.2) 的相位是"单相位反演" `e(A\bar l/q)`（A=nn'r），**不是**标准双相位 Kloosterman 和 `Σ_x e((ax+b\bar x)/q)`；对 l 再做 Fourier 展开会得到 `e(A\bar l/q)=(1/q)Σ_vS(A,−v;q)e(vl/q)`，即 Kloosterman 和 S 的叠加，但系数序列 `μ(l)l^{−t}` 与 `n^{−a}` 不属于 Bettin–Chandee/BHM/DFI/Kuznetsov 适用的类（那些要求特定 GL(2)/尖形式系数或至少双相位结构）。
- 由于 σ=1/2+η>1/2，所有系数权**绝对可和**（`Σ_{n>N}n^{−σ}~N^{1/2−η}`，`Σ_r μ(r)r^{−s}` 条件收敛但有界），因此 (2.2) 的各个内和都是 O(1) 级，Weil √q 节省无处可用（没有完整和、没有主相位二次型）。
- **结论**：折叠只是把同一个 χ-平均写成 Fourier 对偶形式（(0.1) 的另一种表述），不产生独立估计；无法给出 c>2 所需的 `q^{2A−2+Aη}` 节省。[证明]

## 4. 路线 3：乘法结构/二次型与 Weil 界

`nm≡rl mod q` 是 `(n,r,m,l)` 在乘法 torus 上的条件；q 素时对 n,m 可解出 `r≡l m\bar n(q)`，对 (x mod q) 用 `Σ_x e(hx/q)` 或 `Σ_x e((ax+b\bar x)/q)`。但：

- 若要利用 Weil 需要把和补全到 mod q，补全的"边界项"就是 wrap 本身（循环）。
**判定：不能给出新节省。** [推导]


## 7. 最小不可行性定理（精确表述）

**定理 7.1（循环性/等价性）[证明]** 在 Route C 的截断框架（§1）中，对 q 素、σ>1/2、长度 X：
```
R_q − M_q = [E^{(X)} − M_q] + O(q^{1+ε}X^{−η}),
E^{(X)} = Σ_{χ≠χ0}(P_aQ_s)(χ)(P_bQ_t)(χ̄) = (q−1)Σ_{A≡B}c_A\bar d_B − Σ_{A,B}c_A\bar d_B.
```
主部 `(q−1)Σ_{A=B}c_A\bar d_A` 与 CFZ 主项一致（phase-11 Euler 积恒等式）；wrap 误差 = `(q−1)W`，`W=Σ_{A≡B,A≠B}c_A\bar d_B`。
其中 `F_pred` 是 CFZ/RAT 预测的对应值（由 Euler 积给出）。因此
- (a) 若 `X²≤q`（no-wrap）：`F` 退化为对角量（Euler 积），可取 `F_pred` 为精确值 ⇒ 误差仅 `q^{1+ε}X^{−η}+qX^{−2η}`，得 c≤1/2（phase-11；本报告 §0.3 修正后确认）。
- (b) 若 `X²>q`：`F` 是**非主特征上的截断比值平均**，即 H_Ratios 的对象；此时"证明 `R_q=M_q+O(q^{1−cη})`"与"证明 `F=F_pred+O(q^{1−Aη}/(q−1))`"**等价**（A=log X/log q，c=A）。特别地 c>2 等价于 A>2 与
```
|(1/q)Σ_{χ≠χ0}(P_aQ_s)(P_bQ_t) − (主项预测)| ≤ q^{−Aη+ε}
（即对截断比值非主特征平均的 q^{−Aη} 级一致 power saving）.
```
**这是本报告的"最小不可行性"**：Route C 不提供独立于 H_Ratios 的算术输入；所有"把 W 用 Poisson/Weil/Kloosterman/大筛/乘性结构估计"的尝试都会在第一步之后落回 (0.1)/(3.2) 的同一个平均（§2–§5 逐条验证）。[证明]

**推论 7.2**：任何"只改进 W 的初等/解析估计（不触及非主特征平均 F）"的方案不可能达到 c>1/2；c>2 需要 F 的 power saving，而 F 正是 phase-11 H_wrap/phase-9 MDs 缺口、phase-7 H_cov^low 的同一类 level-aspect Ratios 输入。已知工具（BV、Chowla/MRT/Tao–Teräväinen、additive divisor、Sawin 函数域）都不能给出 F 的 q-一致 power saving（理由同 phase-9/phase-11 报告）。

**与 plan 的关系**：plan §1.3 的 c≈1 账本应按 (0.1) 修正为"c≤1/2（初等界下）+ c 的提升完全取决于 F"；"c>2 ⇔ |F−F_pred|≤q^{−Aη}, A>2"是 plan 目标（"W≪q^{1−ηA}"）在精确恒等式下的正确形式（注意还有 q 的归一化：本报告的 F 是 R_q 的 q^{−1} 平均）。因此 phase-12 的核心目标应表述为：**证明截断比值非主特征平均的 q^{−Aη} 级 power saving（A>2）**——这仍是一个开放的 Ratios 型定理，但表述现在完全精确。

| Chowla/MRT/Tao–Teräväinen | 对 h 的对数平均/几乎所有尺度 o() | F 需要**一致**（所有 h/所有 χ）的 q-幂节省；parity barrier |
| additive divisor (Estermann/Motohashi/DFI/BHM) | 平滑权下 `Σ d(n)d(n+h)` 的渐近/上界 | 这里的"移位"是 q 的倍数且权为 μ 型、模 q 的**特征平均**；DFI 等不给 q-一致节省，也不覆盖 μ 权 |
| Sawin 函数域 level θ=5/6 | 函数域 squarefree AP 中素数分布 | ℤ 无对应（phase-8/9 已详述），且路线不同（不需 Ratios） |
| 大筛/第二矩 | F 的 L² 界（`Σ_{χ}|P|²`） | 只给 F 的均方根 ~(X^{2−4η}/q)^{1/2} 级，不足以 q^{−Aη} |

## 9. 结论与建议
- **c>2：不可达由 Route C 内部完成**；精确缺口 = 定理 7.1(b) 的 F 估计。
- 若 team 要继续，最值得投入的精确目标是：**对 q 素、X=q^A（A>2 任取/固定）、σ>1/2，证 `|(1/q)Σ_{χ≠1}P_aQ_s\overline{P_bQ_t} − F_pred|≪q^{−Aη+ε}`**（F_pred 由 CFZ 主项给出；对 X²≤q 的情形 phase-11 已证）。这是一个"截断版 H_Ratios"——它与 H_Ratios 同难，但**表述精确、可被 lean 有限化**（截断多项式 + 有限 q 的正交性可用 Lean 形式化，见 task-56），可作为下一 phase 的形式化/数值靶子。
- 不建议继续在"W 的初等估计"上投入：本报告证明那不可能越过 c=1/2。

## 10. 更新（Lead 新输入后）：H_wrap 的精确 equidistribution 形式、ĉ 的严格界、以及"residue-covariance"判据

### 10.1 精确恒等式（含 T 与 V_c 修正）[证明]
记号：`c_A=Σ_{nr=A}n^{−a}μ(r)r^{−s}`，`d_B=Σ_{ml=B}m^{−b}μ(l)l^{−t}`；`S_c=Σ_Ac_A`，`S_d=Σ_Bd_B`；`V_c=Σ_{q|A}c_A`，`V_d=Σ_{q|B}d_B`；`T=Σ_{q|AB}c_Ad_B=V_cS_d+S_cV_d−V_cV_d`；`D=Σ_A c_A\bar d_A`；`W=Σ_{A≠B,A≡B mod q}c_A\bar d_B`；`Sb=D+W=Σ_{A≡B mod q}c_A\bar d_B`。对 q 素：
```
E^{(X)} = Σ*_χ P_aP_bQ_sQ_t = (q−1)(D+W) − S_c\bar S_d + T − (q−1)V_cV_d.        (10.1)
```
**推导**：`Σ*χχ(A)χ̄(B)=1_{(AB,q)=1}[(q−1)1_{A≡B}−1]`；拆出 `(AB,q)>1` 的项并用 `Σ_{A≡B,q|AB}=(V_c)(V_d)`（q 素时 q|A,A≡B⇒q|B）即得。`T` 与 `V_cV_d` 都是 q-整除型**显式可算**项（L-值/ζ-商），对 H_wrap 无影响。**注**：与 Lead 的 `(q−1)(D+W)−S_cS_d+T` 相差 `−(q−1)V_cV_d`；`V_c~S_c/q` 量级，实际差别 O(1/q)·?，请在 bookkeeping 中固定此约定。

### 10.2 H_wrap 的精确 equidistribution 表述 [证明]
令 `F=(1/q)Σ_{h=1}^{q−1}ĉ(h)\overline{d̂(h)}`，`ĉ(h)=Σ_A c_Ae(hA/q)`。由 Fourier 恒等式 `Σ_{A≡B}c_A\bar d_B=(1/q)Σ_{h=0}^{q−1}ĉ(h)\overline{d̂(h)}`：
```
F − D = W − S_c\bar S_d/q  (精确),     且  F = Σ_{ρ=0}^{q−1} (S_ρ−S_c/q)(\overline{S'_ρ−S_d/q}),
其中 S_ρ=Σ_{A≡ρ(q)}c_A, S'_ρ=Σ_{B≡ρ(q)}d_B.
```
由 (10.1)：`Δ:=E^{(X)}−(q−1)D = (q−1)(F−D) − (1/q)S_c\bar S_d + T − (q−1)V_cV_d`。因此
```
**H_wrap[A]**（residue-covariance 判据）：
   |F − D| ≤ q^{−Aη+ε}(1+T)^B，  等价地   Σ_ρ(S_ρ−S_c/q)(\overline{S'_ρ−S_d/q}) = D + O(q^{−Aη+ε}).
⇒ Δ ≤ q^{1−Aη+ε} ⇒ RAT(c=A)。  反之 c>A 需更小误差：|F−D| ≤ q^{−cη+ε}。
```
**解读**：`D` 是"对角 Euler 积"（O(1) 常数），而 `F` 是 residue 类求和的**协方差**（"均匀性"指标）。H_wrap 说：**协方差必须精确等于对角 Euler 积，误差为 q^{−cη} 的幂次**。这就是 Lead 说的"系数 c_A 在 mod q residue 类中高度均匀"的**精确形式**（包含与 d 的交叉协方差，故比单序列均匀性更强）。对 `X²≤q` 该式自动成立（S_ρ=c_ρ、S_c/q=0 ⇒ F=D；c≤1/2 的机制）。

### 10.3 ĉ(h) 的严格界与差距 [证明/推导]
- **平凡界**：`|ĉ(h)| ≤ Σ_{A≤X²}|c_A| ≤ (Σ_{n≤X}n^{−σ})(Σ_{r≤X}|μ(r)|r^{−σ}) ≪ X^{2(1/2−η)} = X^{1−2η}`（σ=1/2+η<1 时两个部分和分别 ~X^{1/2−η}）。于是 `|F| ≪ (1/q)·q·X^{2−4η}η^{−2}log² = X^{2−4η}η^{−2}log²`。⇒ 目标 `|F−D|≤q^{−Aη}` 与平凡界相差 **`q^{2A−4Aη+Aη}=q^{2A−3Aη}`**（A=2：`q^{4−6η}`）。
- **GRH + μ-in-AP 界**（推导）：拆 m=ρ+tq，`M_ρ=Σ_{t}μ(ρ+tq)(ρ+tq)^{−s}`，GRH 给 `|M_ρ|≪(X/q)^{1/2−σ}q^{−σ+ε}`；`ĉ(h)=Σ_nn^{−a}Σ_ρe(hnρ/q)M_ρ`，trivial `|Σ_ρ|≤q max|M_ρ|` 给
  `|ĉ(h)| ≪ X^{1/2−2η}q^{1/2+ε}`（wrap 区 X>q 时优于平凡界 X^{1−2η}）；若 ρ 相位有 √q 抵消则 `|ĉ|≪X^{1/2−2η}q^{ε}`（**未证**）。即使如此，`|F|≲(1/q)Σ_{h≠0}|ĉ||d̂|` 仍 ≥X^{1−4η}q^{ε}（A=2：q^{2−8η}）——**仍远大于 q^{−2η}**。
- **大筛**：`Σ_h|ĉ(h)|²=qΣ_ρ|S_ρ|²`；而 `Σ_ρ|S_ρ|²≈Σ_A|c_A|²+(1/q)(Σc)²`，`Σ_A|c_A|²≲η^{−1}log³`（σ>1/2 收敛），故 `Σ_h|ĉ|²≲qη^{−1}log³`，Cauchy–Schwarz 给 `|F|≲η^{−1}log³`——**回到 O(1)**，无法给出 q^{−cη}。
**结论（b）**：所有已知无条件/GRH 级工具给 `|ĉ(h)|≥X^{1/2−2η}q^{ε}`（或 O(1) 求和层面），而 H_wrap 需要 `|F−D|≤q^{−cη}`（c>2，η 可小）——**差距是 q 的正幂**（A=2 时 q^{4−6η} 到 q^{2−8η}，视工具），不是常数因子；这就是精确的"卡点"。
