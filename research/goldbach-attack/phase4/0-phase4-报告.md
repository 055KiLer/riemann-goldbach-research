其余三个理论/审计结论：

1. **AFE 攻击路线被定量排除**：AFE 本身在 GRH 下误差 N^{o(1)} 不是障碍；致命的是对角质量记账——特征正交只给出截断到 X≍√N 的对角 `D_N^{(X)}`，而 `D_N(w)=w^{-2}+O(1)` 的质量来自 n≲1/Re w≍N；缺口 `Δ≈w^{-2}−(logX)²/2≍(logN)²/8 = √N·logN·δ_N`。缺的质量只能落在 Main×Dual / Dual×Dual / Γ 项中，使它们显式就回到 L'/L 相关——循环。**没有新的无条件界。**
2. **最小充分条件被精确重述**：H_Gold(φ)：对固定 admissible 权 ψ，`|G_ψ(N)−c_ψS(N)|≤C₀δ_N` 对所有大偶 N 成立 ⇒ Goldbach。由 LL 精确恒等式，它等价于**单个二次型** `|⟨T_N v_{N,ψ},v_{N,ψ}⟩|≤C₀Q_ψδ_N`——严格弱于 R，而 R 严格强于所有加权 HL 数据（真超平面壁垒）。**P_N 侧假设（G1+Gram 平坦 G2）即使成立也只给 (logN)²/√N，会被 ‖D_N+K_N‖_HS≍(logN)^{3/2} 的三角项压住（反向三角 ⇒ Ω((logN)^{3/2})），不能替代 E_N 抵消。**
3. **独立审计**：R 与已知结果/猜想无矛盾（R 允许的计数误差 ≈√(S N)/√log N，是随机涨落 √(SN)/logN 的 √log 倍，更宽松）；平滑二元 Goldbach 逐 N 无条件定理不存在且不可能已知（会推出弱 Goldbach）；level-aspect 的 L'/L 文献（Young 四次矩、Ghosh、Ihara 等）都是平均/固定点型，缺的正是跨 χ 的四阶/算子范数估计；Alpöge Lean 证明无定量常数可提取。审计同时修正了我们 phase2/3 的四处小错（G1 证明有 gap 不可引用、c_N 笔误、非解析项说法错、E_N=O(1) 不准确），并确认核心断言 S(N)c_N=1、κ_N、无三角路线、真超平面结论成立。

**最终判定**：仍然没有 Goldbach 的证明；但本轮把"LL 路线是否可行"从"未证"推进到"**其关键充分条件 R 很可能在论文自己声明的范围内就是假的（有限模型证据；数值上，非证明）**"。若最终确认，LL 的条件性定理不是"未证明 Goldbach"，而是**假设不可满足、定理空虚**；LL 的精确归约 `r(N)=c_φS(N)−⟨T_Nv_N,v_N⟩` 仍是有效且有价值的研究框架，而 Goldbach 的最小未知退回到 H_Gold（= 加权二元 HL 误差 O(δ_N)）本身。

## 1. 理论：为什么 AFE / 自对偶 / 正性都补不上 √N

### 1.1 AFE 路线：对角质量记账失败（[证明]）

- AFE 有效性与误差不是问题：GRH 下 `|1/L|≪(N(|t|+2))^{o(1)}`，平滑 AFE 误差 N^{o(1)}≪√N。
- 真正障碍：LL (2.1) 的特征正交 `(2/φ)Σ_{χ odd}χ(n)\barχ(m)=1(1_{n≡m}−1_{n≡−m})` 只看得到截断到 X≍√(N|t|)≍√N 的对角 `D_N^{(X)}=Σ_{n≤X}Λ²(n)n^{-1-w}V²`；而 `D_N(w)=w^{-2}+O(1)` 的质量来自 `n≤1/Re w≍N`。缺口 `Δ_{√N}(w)≈w^{-2}−(log X)²/2≍(log N)²/8`，即 √N·log N 倍 δ_N。
- 缺失质量必须由 Main×Dual、Dual×Dual、Γ 项提供；这些项的 χ-正交性给出乘法条件 `nm≡±1 mod N` 和错误指数（`D_N(−w)` 型、`n^{-1±(s−\bar z)}` 型）；把它们显式化就回到 `L'/L` 相关——循环。**结论：AFE+特征正交不能给出新界，除非先解决同一个 E_N 抵消。**

### 1.2 函数方程自对偶：精确恒等式，但无不等式（[证明]）

证明 `g_χ(s) = −g_{χ̄}(−s) + h_χ(s)`，`h_χ` 显式（digamma/conductor/Euler 项）；它把条带 `Re s∈(α_N,1/8)` 映射到不相交的 `Re s∈(−1/8,−α_N)`；`h_χ=O(logN)` 不小，`D_N(w)−D_N(−w)` 不小，`K_N` 的 X₁ 因子反转；没有 parity/coboundary 结构，推不出任何界。

### 1.3 张量 Weil 正性：无通道（[证明/推导]）

正性给的是单边（下界），而 E_N 是不定的（LL 自己说特征值两种符号都有），且 `W⊗W` 不控制交叉项；二变量正性会编码 Montgomery 型对相关（本身未知）。**无通道。**

### 1.4 最小条件与"R/S 为假"的逻辑（[证明]）

- **定理 A**：H_Gold(φ)（固定权、逐 N 的加权 HL 误差 O(δ_N)）⇒ Goldbach；由 LL 恒等式，它等价于单个二次型界，**严格弱于 R**。
- **定理 B**：P_N 侧假设（(G1)（phase-3 修正：其证明有 gap，不可引用）+ (G2)）只能给 `‖P_N‖_HS≪(logN)²/√N`，而 `‖D_N+K_N‖_HS≍(logN)^{3/2}`，反向三角 ⇒ `‖T_N‖=Ω((logN)^{3/2})`；不能替代 E_N 抵消。
- **S 的临界系数**：由 LL (2.28)，令 `x=√η_N∈(0,1/2]`，S 要求 `‖T_N‖≤δ_N/(2x√(1−x²))`；最大右端在 x=1/2 得 `(2/√3)δ_N≈1.1547δ_N`。有限模型 ratio>1.1547（N=40022: 1.39）⇒ S 在该 N 也失败。
- 若 R 在无穷多 N 上失败，**Hypothesis R 作为全称命题为假**；LL Theorem 1.2 的假设不可满足 ⇒ 定理虽真但**空虚、无法用于证明 Goldbach**。S 同样（对 N=2p 序列若 ‖T_N‖不趋于 0，则 h 有界矛盾——S 比 R 更易失败）。**但这不推翻 LL 的精确恒等式**，只说明其谱充分条件过强、可能为假。

### 2.3 收敛性：不是网格/高度伪影

- **mesh**（N=40022，H=40）：m=8/16/32 ⇒ λ_max=0.27611471/0.27572139/0.27572427，比值 1.39348/1.39150/1.39151；`|C|max` 从 0.027 降到 0.0068（求积边缘效应），而 λ_max 四位稳定 ⇒ **收敛**。m=64 进一步给出 λ=0.27572428、比值 1.3915141（m=32→64 变化 4×10⁻⁸）⇒ λ_∞=0.2757243。Hardy 投影 sanity（N=40022）：最大特征向量的 `‖P_H v‖²/‖v‖²≈0.832`（83% Hardy 质量；转移论证本身不需要此步）。
- **height**（N=40022）：H=40/60/80 ⇒ λ_max=0.27572/0.27660/0.27698，比值 1.3915/1.3959/1.3979（略升，截断误差方向不利，真值可能更高）。
- 独立 pointwise 核对（liu-auditor）：N=40022，P(α,α)=20.5774 vs D+K=20.5382 ⇒ E=0.0392（<0.5% 抵消），与 |C|max 小一致；D+K 在 w=2α 处用完整式（20.54）而非渐近 κ/w（40.7），代码正确。

### 2.4 为什么这能转移成 ‖T_N‖ 的下界（按 LL 自己的 Prop 5.3）

LL Prop 5.3（我们核对原文）证明：边界核算子 `T̃_N`（核 K=E_N/((1+s)(1+z̄))）在 `L²(Γ_N)` 上自伴、Hilbert–Schmidt、**值域在 Hardy 迹空间 H_N 内**，且自伴+值域包含 ⇒ **湮灭 H_N^⊥**，即 `T̃_N = T_N ⊕ 0`。因此对任意单位 `v∈L²(Γ_N)`：
`⟨T̃_Nv,v⟩ = ⟨T_N P_H v,P_H v⟩ ≤ ‖T_N‖·‖P_H v‖² ≤ ‖T_N‖`。
`C=√(w_iw_j)K(s_i,\bar s_j)` 是 `T̃_N` 在阶梯函数子空间 `V_M` 上的压缩（Nyström 求积），mesh 收敛后 `λ_max(C) ≤ ‖T_N‖ + 求积误差`。故 `0.275724 > δ_N=0.198147` 在 LL 自己的框架内数值上推出 **‖T_N‖ > δ_N，即 Hypothesis R 在 N=40022 为假**（有限模型证据，非证明；但收敛性 + 独立 pointwise 核对使其可信度较高）。

### 2.5 与 LL 结论的关系

- LL 的 Theorem 1.2 前提是"对所有充分大偶 N，R(N) 成立"。N=40022>e¹⁰ 在 LL 的工作范围内，但"充分大"的阈值 N₀ 可能更大（论文 Appendix A 讨论 N₀(c)）；因此**严格说，N=40022 的反例不自动推翻"最终对所有大 N"的 R**。然而：N=2p 族的有限模型到 **N=200006（H=20）仍 >1：1.1377**（p=19997/20011/30011/50021/100003 分别为 1.072/1.392/1.211/1.170/1.138，全部 >1）；λ_max 从 0.276 缓慢降到 0.125，δ 从 0.198 降到 0.110，比值只缓慢下降。**因此沿 N=2p 族，R 的有限模型失败至少持续到 2×10⁵，远超出论文声称的 N>e¹⁰ 工作范围；若 λ_max 衰减继续慢于 δ_N，R 最终也为假。** 多小因子对照 N=102102 比值 0.771<1，与 crossing scale ~S(logN)³/λ²~2–3×10⁵ 的估计一致。
- **S 假设**：N=40022 的 ratio 1.39 > (2/√3)=1.1547，故 S 在该 N 也数值上失败。
- **H_Gold 仍健康**：在同样的 N 上，直接加权 Goldbach 相关（`probe2.c`，与模型无关的算术计算）给出 `|G_φ(N)−c_φS(N)|/δ_N≈0.001–0.01`（N=30030: 0.0006；40022: 0.0014；100042: 0.0024；200006: 0.0025 等）。即：**算子范数方向的坏本征值可以完全不被 Goldbach 权方向的二次型看见**（这正是 phase-2 真超平面壁垒的数值体现）。因此 R 的（可能）失败**不否定** H_Gold，也不否定 Goldbach；它只说明 LL 用来证明 H_Gold 的谱充分条件过强/可能为假。
- **LL 论文的地位**：其条件性推导（R/S⇒Goldbach）在逻辑上仍正确；但若 R/S 为假，则假设不可满足、定理不能用。**这是对论文假设的否定，不是对条件性推导的否定；也不是对 Goldbach 的否定。**

## 3. 本轮诚实的结论

1. **没有 Goldbach 证明**；没有 Lean 制品（不存在可形式化的证明，我们不会伪造）。
2. **没有新的无条件界**：AFE/自对偶/张量正性三条进攻路线被定量/结构性地堵死；最小无条件未知仍是 E_N 的抵消。
3. **但有重要的新发现**：在 LL 自己的有限谱模型框架内（复现论文 N=30030 数值、mesh/height 收敛、独立 pointwise 核对），**Hypothesis R 在 N=40022（>e¹⁰，论文声明的范围）处数值上为假**（λ_max=0.275724 > δ_N=0.198147），且在 N=2p 族多个模数上 >1；多小因子模数在 N≈9×10⁴ 附近也可能越过 1。**若该现象在更大 N 上持续，LL 的条件性证明就是空虚的（假设不可满足），而不是"仍未证明"；其唯一的数值支持（N=30030 的 0.827）是模数特定的巧合。**
4. **最小未知被精确重述**：H_Gold（固定权、逐 N 的加权二元 HL 误差 O(δ_N)），等价于单个二次型界；它不被 R 的失败否定，且正是 Goldbach 的定量形式。LL 的精确恒等式 `r(N)=c_φS(N)−⟨T_Nv_N,v_N⟩` 仍是有效的研究框架；研究重点应从"证明 R"转向"直接证明 H_Gold"或"寻找更弱的充分条件"。
5. **候选的下一步**：(a) 完成 N=200006/更大 N 的 trend 与 m=64/H=160 收敛，判定 R 是"pre-asymptotic 失败"还是"最终失败"；(b) 对有限模型的求积误差给出显式界，把"数值证据"升级为"可严格验证的区间/下界"（例如给出 N=40022 时 ‖T_N‖ 的可验证下界 >δ_N，若能做到，就是 R 的一个真正反例）；(c) 分析坏本征向量的结构（Laplace 参数/权重类），看能否解析地构造一列 h 使 ⟨T_Nh,h⟩/‖h‖²>δ_N；(d) 回到 H_Gold 的直接解析/数值研究。
