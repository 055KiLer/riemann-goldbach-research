## 0. 一句话结论

两条路线都**没有**给出 Goldbach 的证明；它们都精确地卡在同一个地方：

- **路线 1（LL）**：论文本身是把 Goldbach 归约到算子范数界
  `‖T_N‖ ≪ √(S(N)/N)·(log N)^{3/2}`（Hypothesis S/R 的实质），
  而 GRH（即使已作为定理接受）只给出 `‖T_N‖ ≪ (log N)²` ——
  两者相差 `~√N/√(log N)` 倍，这个差距正是“哥德巴赫主项的算术内容”，不是软分析能补上的。
- **路线 2（热核迹正性）**：作为“关键一步”的热核迹正性要么是**自动成立、无信息量**的（无符号 heat trace 恒 > 0），

  要么在“从生成函数到系数”这一步失效（正生成函数不蕴含系数非负，本文给出显式反例）。
  因此“RH 谱架构必然蕴含 Goldbach”作为一个逻辑命题并不成立。

## 2. 路线 1：LL 条件性证明的精确缺口

### 2.1 LL 的逻辑链（[事实]，原文式号）

1. Dirichlet 奇特征标投影（2.1）–（2.4）：把 Goldbach 相关写成 `G(N) = D(N) − P(N)`。
2. Mellin 反演 → 解析核 `P_N(s,z) = (2/φ(N)) Σ_{χ odd} (L'/L)(1/2+s,χ)(L'/L)(1/2+z,χ̄)`（2.6）。
3. 减去对角项 `D(N)` 与 Beta 模型 `K_N`，得残差 `E_N = P_N − D_N − K_N`（§2.2.3），且
   精确恒等式 `G(N) = c_φS(N) − r(N)`，`r(N)` 是 E_N 的 Mellin 双重积分（2.34–2.35）。
4. 在竖条带 `S_N = {α_N < Re s < β}` 上，`E_N` 是对称 Hermitian 核；定义 Hardy 空间 H_N 上的积分算子
   `(T_N h)(s) = ∫_{Γ_N} E_N(s,z̄)/((1+s)(1+z̄)) h(z) |dz|`（2.17）。
   `T_N` 自伴、Hilbert–Schmidt、紧（Proposition 5.3）[事实/LL 证]。
5. 取 Riesz 向量 v_N，得**精确二次型** `r(N) = ⟨T_N v_N, v_N⟩`（2.39），`Q_N = ‖v_N‖² ≪ 1`（2.37–2.38）。
6. Cauchy–Schwarz：`|G(N) − c_φS(N)| ≤ Q_N‖T_N‖ ≪ ‖T_N‖`（2.18–2.19）。

### 2.2 零–范数字典：S/R 就是算子范数界（[推导]，复核 LL §2.4.2–2.4.4）

记 `d_j = δ_N²/μ_j²`，`δ_N = √(S(N)/N)(log N)^{3/2}`。因子方程 `q(1−q) = d_j/4`。

- 若 `|μ_j| > δ_N`（即 `d_j < 1`）：两个**实**零点 `q_± = (1 ± √(1−d_j))/2`（一“例外对”）。
- 若 `|μ_j| ≤ δ_N`（`d_j ≥ 1`）：零点满足 `Re q = 1/2`（或 `d_j=1` 时 `q=1/2` 二重）。
- 由于 `T_N` 紧、`μ_j → 0`，只有**有限多**个 `|μ_j| > δ_N` —— 所以只有有限多个实零点；无穷乘积的其它零点都在 `Re q=1/2` 上（LL §2.4.2 的收敛性论证）。

于是：
- **Hypothesis R**（所有零点 `Re q = 1/2`）⇔ 没有例外对 ⇔ `‖T_N‖ ≤ δ_N`。（LL (2.30)）
- **Hypothesis S**（`Re q > 1−η_N` 无零点）⇔ 实零点的大根 ≤ `1−η_N` ⇔ `|μ_j| ≤ (δ_N/2)√(η_N(1−η_N))` ⇔ `‖T_N‖ ≤ S(N)/(2h(N)√(1−η_N))`。（LL (2.28)）
- `R ⇒ S`（因 `‖T_N‖ ≤ δ_N` 小于 S 的界，见 LL (2.30)）。

**因此 LL 的“两个谱假设”不是玄学，而是同一个具体算子 `T_N` 的两种强度不同的范数上界。** 我把它们写成一个最小的充分条件：

> **[推导] 定理（归约的规范化）**：若存在绝对常数 `C`（任意大但固定），使对所有充分大偶数 N 有
> `‖T_N‖ ≤ C·δ_N = C·√(S(N)/N)(log N)^{3/2}`，
> 则 `G(N) = c_φS(N) + O(C δ_N) = c_φS(N)(1+o(1))`，从而每个充分大偶数 N 都是两个素数之和。
> （取 h(N) 使得 S 的界 ≥ Cδ_N：由 (2.28) 需 `h ≤ S(N)/(2Cδ_N√(1−η_N))`，而 η_N = h²(log N)³/(N S(N))；对任意固定 C 可解出正解 h ~ √(N S/(log N)³)/(2C)，η_N ~ 1/(4C²) ≤ 1/4 对 C ≥ 1 成立。）[推导；与 LL (2.26)–(2.28) 一致]

也就是说：**整个 LL 路线的数学内容 = 证明 `‖T_N‖ ≪ δ_N`。** 常数多大无所谓（只要固定），关键是 `δ_N` 这个尺度。

### 2.3 GRH 给多少、差多少（[事实/推导]）

LL 的 §2.4.3 证明（依赖 GRH）：`‖T_N‖ ≤ ‖T_N‖_HS ≪ (log N)²`。而需要的是 `δ_N ≈ √(S(N)/N)(log N)^{3/2}`。

差距：
```
(log N)² / δ_N = (log N)^{1/2}·√N / √(S(N))
```
取 S(N) ≈ 2C₂ ≈ 1.32（如 N=2^k）：

| N | 需要的 δ_N | GRH 能给的上界 (log N)² | 差距倍数 |
|---|---|---|---|
| 10^6 | 5.90×10⁻² | 1.91×10² | 3.2×10³ |
| 10^10 | 1.27×10⁻³ | 5.30×10² | 4.2×10⁵ |
| 10^18 | 3.07×10⁻⁷ | 1.72×10³ | 5.6×10⁹ |
| 10^20 | 3.59×10⁻⁸ | 2.12×10³ | 5.9×10¹⁰ |

（S(N) 的两种极端：N=2^k 时 S=2C₂≈1.32；N 含很多小素因子时 S(N) ≪ log log N，会把 δ_N 放大 √(log log N)，但差距仍是 √N 级。）

**关键点**：GRH 是“零点在线上”的定性/半定量信息；`‖T_N‖ ≪ (log N)²` 是平凡的 HS 界（三个分量 `P_N`、`D_N`、`K_N` 各自的 HS 范数都是 (log N)² 级）。要达到 `δ_N`，必须利用 `P_N` 与 `K_N`（Beta 模型）之间的**巨大抵消**——LL 自己说："they do not measure cancellation between the components"（§2.4.3）。这个抵消量级 ~√N，正是 Goldbach 主项/圆法 major arcs 的算术内容；软分析（triangle inequality、HS 范数、Cauchy–Schwarz）不可能看到它。

### 2.4 具体攻击尝试与失败点（[推导]，详见 liu-auditor 的独立复核）

1. **三角不等式 / HS 范数**：把 `T_N = P_N − D_N − K_N` 分开估，每项 (log N)²；合并后还是 (log N)²。要得到 δ_N 需要跨分量的抵消，这是循环的——抵消的精确形式就是 Goldbach 渐近式本身。
2. **算子范数 ≤ HS 范数**：同上，无增益；而反方向 `‖T_N‖ ≥ ...` 给不出上界。
3. **用 RH 证明的显式公式/正性机器**：Alpöge 证明给出的是“Chebyshev 增长 ⇒ 无零区”（`Formalism.HC.ChebyshevGrowthImpliesZeroFree`），即定性零区；它不提供 `L'/L` 在临界线附近的 L² 定量界，更不提供 `T_N` 的特征值界。**GRH 已被 LL 假设，新证明不增加 LL 需要的信息。**
4. **圆法/对偶表述**：`r(N)` 的积分表示本质上是圆法的一个区域积分；要证 `|r(N)|` 小，等价于处理 minor arcs 的抵消/奇偶性问题。**这里与经典障碍重合。**
5. **有限模型/数值**：LL 附录只对 N=30030 做有限模型，并明说“不证明 Hypothesis R”。不能当作证据。


### 2.4bis 更精确的图景（读 LL §6 后修正）

LL 的 Proposition 6.5 告诉我们：三个分量算子中 `P_N`（奇特征标相关项）与 `D_N`（对角项）都是**正算子**且迹类：

- `‖P_N‖_HS ≤ tr P_N = (2/φ(N)) Σ_{χ odd} ‖g_χ/(1+s)‖²_{H_N} ≪ (log N)² + α_N^{-2}`；
- `‖D_N‖_HS ≤ tr D_N ≪ α_N^{-2} = (log N)²`；
- `‖K_N‖_HS ≪ α_N^{-2} = (log N)²`（只用模函数估计，无 positivity）。

所以 `T_N = P_N − D_N − K_N` 的 HS 范数按三角不等式得到 (log N)² 是**紧的**（各分量都是这个量级，且 P_N 是正算子迹 class，(log N)² 不是浪费）。Hypothesis R 要求

`‖T_N‖ ≤ δ_N = (log N)^{3/2}/√N`，

即要求 `P_N` 与 `D_N + K_N` 这两个 (log N)² 量级的正/不定对象**发生 ~√N·(log N)^{-1/2} 量级的抵消**。这不是“再估细一点”能得到的：P_N 的迹就是 (log N)² 量级（正算子，特征值正），要让它与别的算子抵消到 1/√N，必须精确到 Goldbach 主项本身。**这就是 LL 路线真正的墙，也是它与圆法 major-arc 抵消等价的地方。**

数值实验（见 §4）显示：对光滑权重的 G(N)，实际误差比 δ_N 还小两个量级（N≤5×10⁸ 时 |err|/δ_N≈0.002–0.014）。这说明期望的抵消在数值上是成立的（真实算术确实接近主项），但**从“数值很小”到“证明 ‖T_N‖≪δ_N”之间，就是整个猜想**。

### 2.5 路线 1 的诚实判定

- LL 作为**条件性证明**，内部逻辑（至少结构上）自洽：`GRH + (S 或 R) ⇒ Goldbach(充分大)`。
- 但 S/R 是**严格强于 GRH** 的定量算子范数界，差距 ~√N；**没有任何已知技术能证明它**，而且它看起来“至少和 Goldbach 的定量形式一样难”（[推测]，但有明确依据：证明它需要 `P_N − K_N` 的 √N 级抵消，即 Goldbach 主项抵消）。
- 因此“用 RH 证明 Goldbach”在 2026-11 的真实状态 = **把 Goldbach 归约成一个新的、未证明的、与 GRH 无关的谱范数问题**。这不是证明。

所以“黎曼猜想的谱证明架构”这个说法本身不准确：Alpöge 证明的主干是 Stepanov 式的多重性 → theta 提升链 → 显式公式/Chebyshev 增长 ⇒ 零区，**不是** Hilbert–Pólya 热核谱证明。仓库里的 heat kernel 是深层工具链中的一环，与 Goldbach 没有已知通道。

### 3.2 严格引理（[推导]，本文给出证明）

**引理 R1（热迹正性自动成立、无信息量）**：设 A 是实 Hilbert 空间上自伴、下有界、紧预解算子（离散谱 λ_j → +∞ 或 |λ_j| 有下界），则对 t>0，`tr e^{−tA} = Σ_j e^{−tλ_j} > 0` 恒成立。证明：每一项为正（e^{−tλ_j}>0），级数绝对收敛（e^{−tλ_j} 对 j 指数衰减）。∎
> 结论：任何“证明 tr e^{−tA} > 0”的步骤都是自动的，不能区分任何算术命题。

**引理 R2（正生成函数不蕴含正系数）**：存在实系数生成函数 `F(x) = x − 2x² + 2x³`，满足
- 对所有 `x ∈ (0,1)`：`F(x) = x(1 − 2x + 2x²) = x(2(x−1/2)² + 1/2) > 0`；
- 但系数 `a_2 = −2 < 0`（`a_1=1, a_3=2`）。
令 `x = e^{−t}`（t>0），即得：热核型生成函数 `Σ a_n e^{−tn} > 0 ∀t>0`，但系数不全为正。∎
> 结论：**“热迹/生成函数为正”不能推出“每个系数（如 r_2(N)）为正”**。从生成函数到系数需要解析延拓/零点控制（逆 Laplace/逆 Mellin），那正是 Goldbach 级别的难题。

**引理 R3（Goldbach 计数生成函数自动为正）**：对 `0<x<1`，
`(Σ_{p 素数} x^p)² = Σ_{N≥4} r_2(N) x^N`（r_2(N)=N 的（有序）Goldbach 表示数），左边是正数平方，**自动 > 0**；而右边系数正性 `r_2(N) ≥ 0` 恰好就是 Goldbach 猜想。∎
> 结论：自然的热核/配分函数正性是**免费**的；系数正性才是猜想本身。任何“证热迹正性 ⇒ 系数正性”的推理都缺一步不可行的系数提取。

**引理 R4（LL 框架下正性方向反了）**：LL 的精确恒等式 `r(N) = c_φS(N) − G(N) = ⟨T_N v_N, v_N⟩`（2.39）。若 `T_N ≥ 0`（或热核正性），则 `⟨T_N v_N, v_N⟩ ≥ 0`，于是 `G(N) ≤ c_φS(N)`。而 Goldbach 需要 `G(N) > 0`，即需要 `⟨T_N v_N,v_N⟩ < c_φS(N)`——一个**上界**，不是正性。∎
更精确的有限维模型：设 H 实 Hilbert 空间，`v ≠ 0`，`c ∈ ℝ`。则 `{c − ⟨Tv,v⟩ : T 自伴, T ≥ 0} = (−∞, c]`。证明：任给 `g ≤ c`，取 `T = λ vv^T`（`λ = (c−g)/‖v‖⁴ ≥ 0`，约定 ⟨Tv,v⟩ = λ‖v‖²），则 `c − ⟨Tv,v⟩ = g`。∎
> 结论：**正性允许 G(N) 任意负**，因此“正性”甚至不能给出 G(N) 的任何正下界。

**引理 R5（迹的方向）**：紧自伴 T 的特征值 μ_j；`tr e^{−tT} = Σ e^{−tμ_j} ≥ e^{−t‖T‖}`（最大特征值项）。所以
`‖T‖ ≥ −(1/t) log tr e^{−tT}`——热迹信息给的是范数的**下界**，无法证明所需的小范数上界。∎

### 3.3 为什么 RH 的“正性”不能迁移到 Goldbach（[事实/推导]）

- RH 的 Weil 正性判据：RH ⇔ 对适当 test function 族，显式公式给出的二次型 `W(f * f̄) ≥ 0`。这是**乘性**对象：它等价于“L 函数零点在线上”，其正性来自显式公式把零点与素数用 Fourier 变换联系起来。
- Goldbach 是**加性**问题：`r_2(N) = Σ_{p+q=N} 1`，等价于生成函数 `(Σ x^p)²` 的系数正性。上述正性判据对 `(Σ x^p)²` 给出的是自动平方正性，不含系数信息。
- 奇偶性障碍（Selberg parity problem）：筛法/正性平均论证无法区分 Ω(n) 的奇偶性；这是二元 Goldbach 与三素数问题的结构性差别（三素数有无条件 Vinogradov/Helfgott）。热迹/正性方法属于“平均/正性”类型，落在这个障碍的错误一侧。
- 目前唯一已知的、把 GRH 与 Goldbach 连起来的定量桥梁就是 LL 的算子范数界（§2），它本质上是**圆法 major arc 抵消**；而 major arc 的抵消又依赖 minor arc 控制/奇偶性障碍。

### 3.4 路线 2 的判定

- 作为“关键一步”的“热核迹正性”，在无符号意义下自动成立、无信息量；在有符号/超迹意义下，其正性等价于某个（未知的）算术命题——那需要全新的构造，不能从 RH 的谱架构“必然”得到。
- 因此：**“RH 谱架构必然蕴含 Goldbach”不成立**；路线 2 若要成立，必须补上一个“有符号迹公式 + 系数提取 + 抵消估计”，其难度不低于路线 1 的 S/R（[推测]，但有 R1–R5 作为硬约束）。
- 唯一可能可行的正面方向：寻找一个 **signed trace / supertrace**，使 `r_2(N)` 或 `G(N)` 成为其系数，并且该 trace 的符号来自某个已知正定结构；这属于新的研究纲领，不是形式化能把已有 RH 证明“翻译”出来的东西。

## 4. 数值实验：LL 加权相关系数实际误差 vs δ_N（[数值证据]，非证明）

观察（[数值证据]，范围 N ≤ 5×10⁸）：
1. **实际加权误差远小于 δ_N**：|err|/δ_N ~ 0.002–0.014，且绝对误差 ~10⁻⁴ 量级。说明“真实算术确实极接近 cφS(N)”，LL 想要证明的 **R 的结论（误差 ≪ δ_N）在数值上不仅成立，而且余量很大**。这支持 LL 的 S/R 在精神上是“真命题”，不是荒谬的强假设。
2. 但注意：数值验证的是**结论**（二次型 ⟨T_N v_N,v_N⟩ 小），不是 **R 本身**（‖T_N‖ ≤ δ_N）。`v_N` 只探测 T_N 的一个方向；T_N 的范数可能远大于该二次型。因此数值结果不能证明 R（更不是 Goldbach 的证明）。
3. 这是对“路线 1 完全不可能”的一个反证：R 的数值行为是健康的；墙在于**证明**，不是在于假设为假。

## 5. 诚实结论

1. **路线 1**：LL 的条件性证明把 Goldbach 归约到 `‖T_N‖ ≪ δ_N`；GRH（不管是否已证明）离这个界差 √N 级；没有已知方法能补。**归约成功，证明失败。**
2. **路线 2**：热核迹正性（无符号）自动成立；系数提取不可行；正性方向与 LL 框架相反。**该路线不能蕴含 Goldbach。**
3. **Lean**：没有 Goldbach 的数学证明，就不可能有通过内核检验的 Lean 文件。我们拒绝伪造；这是本次“不计成本”尝试的底线。
4. 如要继续：真正值得做的研究问题是 (a) LL 的 `T_N` 范数界（等价于 Goldbach 定量形式，见 §2.2），(b) 一个新的、正确的 signed-trace 表述，以及 (c) 圆法 minor arcs/奇偶性障碍的突破。**任何声称绕过这三者之一的“证明”都值得怀疑。**
