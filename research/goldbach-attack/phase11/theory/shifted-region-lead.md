## 1. 定理（移位区域弱 Ratios，q 素；[推导]，依赖 GRH）

设 q 为素数，a,b,s,t 为复数且 **Re a=Re b=Re s=Re t=σ=1/2+η**（0<η≤1/4），|Im(·)|≤T。设 R=1/2+η 为实数部分（统一记号）。则对任意固定 0<ω<η/2，
```
R_q(a,b;s,t) := Σ*_{χ mod q} L(a,χ)L(b,χ̄)/(L(s,χ)L(t,χ̄))
            = φ*(q) Z_q(a,b;s,t) + O_{η,ω,ε}( q^{1−ω+ε} (1+T)^{C} ),
```
其中 φ*(q)=q−2，Z_q 为 CFZ 主项（phase-10 boxed 公式，c=s,d=t），且误差中的 H_q 反射项被自动吸收（其相对大小 q^{−2η}）。

**证明草稿（关键步骤）**：

1. **两个截断**（GRH）：对 Re u=1/2+η，
   `L(u,χ) = Σ_{n≤X}χ(n)n^{−u} + O(X^{1/2−σ}(log qX)^C)`（Pólya–Vinogradov/GRH 部分和 + Abel）；
   `1/L(u,χ) = Σ_{m≤X}μ(m)χ(m)m^{−u} + O(X^{−η+ε}(q(1+|u|))^{ε})`（GRH，kernel-theorist Lemma 1.1）。
   且 GRH 下 `|L(u,χ)|, |1/L(u,χ)| ≪ (1+T)^{C}q^{ε}`（log L = Σ_p χ(p)p^{−u}+… 的条件收敛; [待核] 常数）。
2. **精确正交性**：定义 E^{(X)} := Σ*_χ P_a(χ)P_b(χ̄)Q_s(χ)Q_t(χ̄)，其中 P_u=Σ_{n≤X}χ(n)n^{−u}，Q_u=Σ_{m≤X}μ(m)χ(m)m^{−u}。则
   `|R_q − E^{(X)}| ≪ q^{1+ε} X^{−η} (1+T)^{C}`（四个 Δ-项的 Cauchy–Schwarz + 点态界）.
3. 把 P_aQ_s 的系数记为 c_A（A≤X²），P_bQ_t 的系数记为 d_B。对素数 q、A,B 均与 q 互素（X²<q 保证）：
   `Σ*_χχ(A)χ̄(B) = (φ*(q)+1)·1_{A≡B mod q} − 1 = φ*(q)1_{A=B} + (1_{A=B} − 1)`（用 X²<q）。
   于是**精确地**
   `E^{(X)} = φ*(q) Σ_{A≤X²} c_A d_A + [ Σ_{A≤X²} c_A d_A − (Σ_A c_A)(Σ_B d_B) ]`.
4. **Euler 积恒等式**：c_A,d_A 为乘性卷积（c=p^{−a}*μ(·)(·)^{−s}）。令 u_p=p^{−a}, v_p=p^{−s}, w_p=p^{−b}, z_p=p^{−t}，则
   `Σ_{A≥1} c_A d_A = ∏_p [1+(u_p−v_p)(w_p−z_p)/(1−u_pw_p)] = ∏_p (1−u_pz_p−w_pv_p+v_pz_p)/(1−u_pw_p) = Z_q^{(diag)}`
   —— **与 CFZ 的 Z_q 在 p∤q 处逐 Euler 因子完全相同**（对 p=q 差 O(q^{−1−2η})，乘 φ* 后为 O(q^{−2η})）。**[推导，已数值验证]**
5. 误差账本：`φ*(q)·(Σ_{A≤X²}c_Ad_A − Z_q) ≪ q^{1−2η+ε} + q·X^{−4η+ε}`；主项修正项 `[Σ_A c_Ad_A−(Σc)(Σd)] = O(1+X^{1−4η}(log)^4)`；总误差 ≪ `q^{1+ε}X^{−η}(1+T)^C`。
   取 **X=q^{ω/η}**，并要求 **X²<q**（避免 wrap-around），即 **ω/η<1/2**；则所有误差 ≤ `q^{1−ω+ε}(1+T)^C`。∎
6. 复合 q：正交性用 `Σ*_{χ mod q}χ(A)χ̄(B)` 的 divisor 公式（kernel-theorist Lemma 1.3），主项结构相同但含 p|q 局部修正（CFZ 的 ζ_q/A_q 正是为此设计）；本定理应可推广，**待核**。

**[数值] 验证**（`shifted_check.py`，q=1009/211，mpmath dps=30，全部 primitive χ 的精确求和）：
| 情形 | \|R−M\|/\|M\| | \|φ*S−φ*Z\|/\|φ*Z\| | \|φ*S−M\|/\|M\| |
|---|---|---|---|
| q=1009, σ=0.75 | 9.1×10⁻³ | 2.4×10⁻⁴ | 8.5×10⁻⁴ |
| q=1009, σ=0.60 | 2.0×10⁻² | 2.5×10⁻³ | 4.6×10⁻¹（H 项显著） |
| q=211, σ=0.75 | 9.0×10⁻³ | 1.7×10⁻⁴ | 1.8×10⁻³ |

要点：(i) **Euler 积主项恒等式成立**（S 与 Z_q 一致到 Euler 截断 ~1e−4）；(ii) R_q 与 CFZ 的 M_q 在移位区域吻合到 1–2%（即 ~q^{−1/2} 级，远好于本定理的 q^{−η/2} 上界）；(iii) σ=0.6 时 H_q 反射项相对大小 ~q^{−2η}≈0.25（观测 0.46，同量级），与"内部被吸收"的分析一致。

## 2. 为什么这个定理**不能**完成 GWX（η-权衡的定量表述）

GWX 的 (3.12) 轮廓把 s,t 移到 **σ=1/2+η**，误差被放大 N^{2σ−1}=N^{2η}；最终要求有效 saving **ω > 2η**（见 phase-8/10 审计；任意固定 ω_D>0 通过在 Lemma 3.1 中取 η,r 足够小实现）。
而本方法的最大 saving 为 **ω < η/2**（受 X²<q 的 no-wrap 与截断 X^{−η} 双重限制）。
⇒ **本方法永远差 ≥4 倍指数**：对每个 η 都有 ω/η < 1/2 而 GWX 窗需要 ω/η > 16（kernel-theorist Prop 3.1 的 sharp 版本：其不等式为 ω/η<1/2−o(1) vs 需要 ω/η>16）。

**意义**：这精确度量了"离终点"的距离：
- 在**离开临界线固定距离 η 的移位区域**，Ratios 型估计是**可证**的，saving 与 η 成正比（这是本文 §1 的正面结果；本质是 1/L 的截断误差 X^{−η} 与正交性 no-wrap 的权衡）；
- 在 GWX 需要的**临界线+无穷小移位**区域，saving 必须与 η 无关（且 >2η），这正是 Ratios 猜想的真实深度所在；Route C 在此处遇到 kernel-theorist 的 **H_wrap**（wrap-around 的 additive-divisor 型移位相关）与 liu-auditor 的 **AP 双线性型**——两者都是 parity barrier 一侧的对象（与 Chowla/零点对相关同级），GRH 级输入不能解决。
- 换句话说：**用 GRH 级工具可以把 Ratios "推到临界线外任意近，但 saving 随距离线性退化到 0"**；要拿到与距离无关的 saving，必须新输入（Type II/零点相关/Ratios 本身）。
