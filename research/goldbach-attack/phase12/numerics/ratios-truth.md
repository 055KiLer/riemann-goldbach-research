## 2. |M_q| 的 η-标度（q=10⁵, q=10⁶ 时）

|M_q|_rms（q=100003；hyp11/shifted 数值近似相同）：η=0.1:1.85×10⁵；0.05:2.36×10⁵；0.02:2.76×10⁵；0.01:2.83×10⁵；0.005:2.84×10⁵；0.002:2.83×10⁵。
**|M_q| ≈ q·f(η)**（M/q≈2.3→3.8，η=0.1→0.002；f(η)≈η^{−0.14±0.05}，**远弱于 q/η²**）。对照：|M_q| 对 q 的拟合指数 1.00±0.03（q=211…5×10⁵）。

由此**相对误差**：
|R−M|/|M| ≈ [C(η)q^{1/2}]/[q·f(η)] ≈ **q^{−1/2+o(1)}·η^{−0.7±0.15}**（在 q=10⁵–10⁶、η=0.1–0.002 数据上成立；q 指数≈−0.5 与 η 无关）。
**⇒ [数值] H_Ratios 真值的关键性质成立：误差的 q-幂 saving 指数与 η 无关**（η 只进入先验常数，幂律 ~η^{−0.7}–η^{−1}）；不是 "q^{1−cη}" 型（那样 q 指数会随 η 变化，η 减小时趋向 1；我们在 q≥10⁵ 未看到此现象：med 局部 α→0.5）。

## 5. 独立验证

- **R_q**：本轮按 primitive-root 显式特征表 + mpmath Hurwitz 值的 char-by-char 直接求和（不复用 fastpipe）：
  q=211: |ΔE|/|E| ≤1.2×10⁻¹³；q=1009: ≤8.8×10⁻¹⁴；q=5003: ≤4.9×10⁻¹²（3–6 个移位 ×2 构型）。
- **M_q**：独立 mpmath 实现（A_q 乘积截断 primes≤2×10⁵，正确 mask q%p≠0；截断尾 <10⁻⁶）与 phase-11b 修正实现：|ΔM|/|M| ≤2×10⁻⁶（q=211/1009/5003）；显式枚举 χ(−1) 的 parity counts 与 Group 计数一致（如 q=1009: M0,M1=503,504；q=5003: 2500,2501）。

## 6. 结论：真值 vs 方法

1. **真值的 saving 指数与 η 无关 [数值]**：在 q=10⁵→10⁶ 的 med 局部斜率中，η 从 0.1 降到 0.002 时 q-指数维持在 0.5–0.56 左右（无趋向 1 的迹象）；η 只使常数增长为 ~η^{−0.7…−0.85}。相对误差 ≈ q^{−1/2+o(1)}·η^{−0.7±0.15}。
2. **RAT(c) 数值自洽**：真值误差远小于 q^{1−cη}（任意固定 c）所需的界。例如 η=0.01、c=2 的界 q^{0.98}，而观测 |R−M| ≈ C q^{1/2}（C≈130 at q=10⁵）；q 足够大后自动满足。由数据外推 c_truth=(1−α)/η≳5（η=0.1）到 ≳50（η=0.01），**RAT(c>2)（甚至 c=10）在数值上被支持**；未见与 plan §1.2/§1.3 预言冲突的数据。
3. **对比 phase-11 方法**：Route C 的可证 saving 受 no-wrap 限制 c≤1/2（严格化后 c≈1），这是**方法上界**；真值（Ratios 猜想本身）的 q-saving 与 η 无关，远好于方法：所需 c>2 不被真值阻碍，阻碍在证明（H_wrap/parity barrier）。
4. **保留项/未完成**：(i) shifted 构型 q=10⁶ 的其余 η（0.01/0.005/0.002）取样在收口时仍在跑（已有 η=0.02 的 q=10⁶ med/√q=54.3，与 q=5×10⁵ 的 54.9 持平；η=0.01 的 q=10⁵ 值 79.1 已与 §1 表一致）；(ii) 小 η 重尾使 RMS 不稳定，本文结论以 med/大 q 局部斜率为准，未做 >50 移位的超大规模统计；(iii) 未分离"真值误差项"与"可能的缺失主项"（M_q 用给定第二主项形式；若真主项含额外项，则上述 q^{1/2} 行为更加成立）。
