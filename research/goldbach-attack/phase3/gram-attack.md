## 0. 结论摘要（先纠正，再给判定）

1. **【撤回】KT2 命题 2.7 的最终比较是错的。** 该命题正确部分：`(G1)+(G2) ⇒ ‖P_N‖_HS ≪ (log N)²/√(φ(N)/2)`（这部分我重新验证无误，见 §2）。**错误部分**：由此配合 `‖D_N‖_HS,‖K_N‖_HS≪(log N)^{3/2}` 用三角不等式断言 `‖T_N‖≪(log N)²/√N = δ_N·√log`。实际幂次比较：
   ```
   (log N)²/√N  ≪  (log N)^{3/2}   （对充分大 N），
   ‖T_N‖ ≤ ‖P_N‖_HS + ‖D_N+K_N‖_HS ≪ (log N)²/√N + C(log N)^{3/2} = O((log N)^{3/2}),
   (log N)^{3/2}/δ_N = √(N/S(N)) → ∞  （√N 级，不是 √log 级）。
   ```
   **修正后的判定：LL 的墙仍然是 √N，不是 √log。** `(G1)+(G2)` 至多把可证的三角界从 `(log N)²` 改进到 `(log N)^{3/2}`（一个 `log^{1/2}` 的改进），离 `R` 仍差 `√N`。
2. **【证明】`‖D_N+K_N‖_HS` 的真阶是 `(log N)^{3/2}`（不是 `(log N)²/√N`，也不是更小）。** 上界：三角 + KT2 定理 2.1/2.2。下界：`D_N+K_N` 在 `w=s+\bar z→0` 处的**单极点**系数为
   ```
   κ_N = log N − log(2π) + ψ(3/4) + O(log²(1/w))  ≈  log N − 2.9238  （大 N），
   D_N+K_N = κ_N/w + O(1+log(1+|Im w|)),     ψ(3/4)=−1.08586,  X1'(0)=−ψ(3/4)=+1.08586,
   ```
   其中 `(1−X1(s)X1(\bar z))w^{-2}` 这一项**没有**留下更坏的项：它恰好贡献 `−X1'(0)/w`（并入同一单极点），高高度带内的贡献为 `O((log N)log u)` 且对 `HS` 积分可积，合计 `O((log N)²)`，低一阶。单极点给出低高度区域 `|D_N+K_N|≳½(log N)/|w|`，故 `‖D_N+K_N‖_HS²≳(log N)²·(1/α_N)≍(log N)³`，即 `‖·‖_HS≳c(log N)^{3/2}`。
3. **【证明】更强的 no-go**：三种自然分组（`P_N,D_N,K_N`；`P_N,D_N+K_N`；`P_N−D_N,K_N`）中，三角不等式所依赖的分量 HS 范数都有**真下界** `≳c(log N)^{3/2}`（`D_N`、`K_N` 的双极点系数分别为 `+1` 与 `−1`；`D_N+K_N` 由上述单极点）。因此**任何"分量范数 + 三角不等式"路线都不可能到达 `δ_N`**；必须直接估计 `E_N=P_N−D_N−K_N` 的抵消（即 `O_N=P_N−D_N` 与 `K_N` 的抵消），这正是二元 Goldbach 的定量算术内容。
4. **【推导】G1 可证**：用 LL Lemma 6.4 的 Perron 多项式 + 零点计数机制**逐特征标**（不做 χ-平均）可得 `max_{χ∈X_N^-} E_χ(α_N)≪(log N)²`（常数绝对、`d_χ≤N` 一致）。即 (G1) 成立。
5. **【推导/推测】G2 无法证明，且即使成立对 `R` 无用**（由第 1、2 条）。G2 等价于 Gram 矩阵近对角/谱平坦（有效维数 `≳φ(N)`）；大筛只控制 Gram 的迹（χ-平均），近似函数方程 + 特征标正交性会引导到跨位移特征标相关 `Σ_n χ(n)\barψ(n+d)`，无已知小性。**[推测]** G2 可能为真（字符族随机性），但它不是 LL 路线到 Goldbach 的墙。

## 1. 自我纠错与 `D_N+K_N` 的精确核算

### 1.1 错误定位 [证明]

KT2 §2.5 命题 2.7 的推导：`‖P_N‖_HS²=(2/φ(N))²Σ_{χ,ψ}|⟨f_χ,f_ψ⟩|²`；在 (G1)+(G2) 下
`‖P_N‖_HS ≪ (log N)²/√(φ(N)/2)`。这一步**正确**。
错误在最后一步：把 `(log N)²/√N` 与 `δ_N` 直接相比而忽略了 `T_N` 中**另外的分量** `D_N+K_N`。对充分大 `N`，
```
(log N)²/√N ≪ (log N)^{3/2}  ⇔  (log N)^{1/2} ≪ √N ，
```
恒成立。因此 `‖P_N‖` 项的改进被 `‖D_N+K_N‖_HS≫(log N)^{3/2}` 完全淹没：
```
‖T_N‖ ≤ ‖P_N‖_HS + ‖D_N+K_N‖_HS ≪ (log N)²/√N + C(log N)^{3/2} = O((log N)^{3/2}),
gap = O((log N)^{3/2}/δ_N) = O(√(N/S(N)))  ——  √N 级。
```
（只有把 `D_N+K_N` 一起抵消才能到 `δ_N`；而三角不等式不能做这件事，见 §1.4。）

### 1.2 `D_N+K_N` 的局部展开与单极点系数 [证明]

记 `w=s+\bar z`。由 KT2 定理 1.3（`S(N)c_N=1`）与 (B5)：
```
D_N(s+\bar z)+K_N(s,\bar z) = (1−X1(s)X1(\bar z))·w^{-2} − X1(s)X1(\bar z)·log(2π/N)·w^{-1} + O(1),
```
其中 `X1(s)=Γ((3/2−s)/2)/Γ((3/2+s)/2)`。关键是对 `(1−X1X1')w^{-2}` 项的精确处理（Lead 特别要求）：
```
X1(s)X1(\bar z) = 1 + X1'(0)(s+\bar z) + O(|s|²+|z|²) = 1 + X1'(0)w + O(|w|²)   （低高度 |s|,|z|≲1）
X1'(0) = −ψ(3/4) = 1.0858608798...                                   （ψ=digamma）
⇒ (1−X1X1')w^{-2} = −X1'(0)w^{-1} + O(1).
```
因此**该项没有留下新的 `w^{-2}` 或 `O(1)` 大项**：它恰好贡献一个单极点 `−X1'(0)/w`，与 `K_N` 的单极点合并：
```
D_N+K_N = −[X1'(0)+log(2π/N)]w^{-1} + O(1) = [log N − log(2π) + ψ(3/4)]w^{-1} + O(1)
        = κ_N/w+O(1),      κ_N = log N − log(2π) + ψ(3/4) ≈ log N − 2.9238.      (1.1)
```
**非解析修正的说明 [推导]**：`P_N^{Euler}(w)=∏_{p>2,p∤N}(1+p^{-w}/(p−2))` 在 `w=0` 的展开不是纯 Laurent：由
`Σ_p p^{-1-w}` 的 `w`-展开（`∂_w Σ_p p^{-1-w}|_{w=0}=−Σ_p log p/p` 发散）产生 `w^k log^j(1/w)` 项，故 (1.1) 的 `O(1)` 在 `w=2α_N` 处应精确写为 `O(1+w log²(1/w))` 量级的系数修正，即
```
D_N+K_N = [κ_N + O(log²(1/|w|))]/w + O(1),     w=2α_N=2/log N 时修正 = O(log²log N) ≪ log N.
```
这不影响 `(log N)^{3/2}` 的阶，也不影响下界（大 `N` 时 `|κ_N|≥½log N`）。

### 1.3 两条边：`‖D_N+K_N‖_HS ≍ (log N)^{3/2}` [证明]

- **上界**：`‖D_N+K_N‖_HS ≤ ‖D_N‖_HS+‖K_N‖_HS ≪ α_N^{-3/2}=(log N)^{3/2}`（KT2 定理 2.1、2.2）。**[证明]**
- **下界**：取低高度区域 `|t|,|y|≤δ`（`δ>0` 取足够小使 `X1X1'=1+O(δ+α_N)→1`；实际上 `X1'(0)=O(1)`，取 `δ=10^{-2}` 即可）。在该区域 `|w|≤2δ+2α_N≤1`，由 (1.1) 且 `|s|,|z|≲δ`：
  `|D_N+K_N| ≥ (1/2)log N/|w|`（大 N）。于是
  ```
  ‖D_N+K_N‖²_HS ≥ ∫_{|t|,|y|≤δ} (log N)²/(4|w|²) · (1/2)²·(|1+s|^{-2}...≥c) dtdy
                 ≳ (log N)² ∫_{|v|≤2δ} dv/((4+v²)(4α_N²+v²))    （用 KT2 §2.1 的积分恒等式）
                 ≳ (log N)² · (1/α_N)  ≍ (log N)³,
  ```
  即 `‖D_N+K_N‖_HS ≳ c(log N)^{3/2}`。**[证明]**
- 因此 `‖D_N+K_N‖_HS ≍ (log N)^{3/2}`，与 `‖D_N‖_HS`、`‖K_N‖_HS` 同阶（不是 `(log N)²/√N`，也不是更小）。

**[数值] 尝试（部分失败，诚实记录）**：直接数值验证 (1.1) 需要计算 `F(1+w)=ΣΛ²(n)n^{-1-w}` 在 `w→0` 的取值；由于 `F(1+w)~w^{-2}` 的和由 `p≤e^{1/w}` 的素数主导，任何固定素数截断都严重低估（对 `w=0.004` 需素数到 `e^{250}`，不可能），且 `mpmath` 对 `ζ''` 的数值微分在 `s≈1` 附近不稳定——本报告**不以数值作为 (1.1) 的证据**，仅以解析推导为准。早期脚本 `scratch/kappa*.py` 的失败输出不否认 (1.1)：其误差来源于上述两点（素数截断 + `ζ` 数值微分），与 `S(N)c_N=1` 的代数证明无关（后者已由 `scratch/check_c2.py` 独立验证 `2C₂c₂=1.000000006`）。

### 1.4 更强的 no-go：三角不等式路线的严格天花板 [证明]

**命题 1.4（triangle 天花板）.** 设 `c>0` 充分小。则
```
‖D_N‖_HS ≥ c α_N^{-3/2},    ‖K_N‖_HS ≥ c α_N^{-3/2},    ‖D_N+K_N‖_HS ≥ c(log N)^{3/2}.
```
于是对三种自然分组
```
(a) T_N=P_N−D_N−K_N；   (b) T_N=P_N−(D_N+K_N)；   (c) T_N=(P_N−D_N)−K_N
```
用三角不等式 + 各分量 HS 上界，得到的 `‖T_N‖` 上界分别为
```
(a) ‖P_N‖_HS+‖D_N‖_HS+‖K_N‖_HS ≥ (‖D_N‖_HS+‖K_N‖_HS) ≥ c'α_N^{-3/2} = c'(log N)^{3/2};
(b) ‖P_N‖_HS+‖D_N+K_N‖_HS ≥ c'(log N)^{3/2};
(c) ‖P_N−D_N‖_HS+‖K_N‖_HS ≥ ‖K_N‖_HS ≥ c'(log N)^{3/2}.
```
即**任何**这类三角界都 `≳c'(log N)^{3/2} ≫ δ_N`。特别地，**即使 (G1)+(G2) 成立（把 `‖P_N‖_HS` 压到 `(log N)²/√N`），(b) 的天花板仍是 `(log N)^{3/2}`**。

**证明.** `D_N(w)=w^{-2}+O(1)`（KT2 引理 1.2；双极点系数恰为 1，且 `H_N(w)` 在低高度有界），故在低高度 `|D_N|≥1/(2|w|²)`，积分给出 `≳α_N^{-3}`。`K_N=−X1X1'[w^{-2}+O(w^{-1})]`，低高度 `|X1X1'|≥1/2` 给出同样下界。`D_N+K_N` 由 §1.3。各分组的下界只需注意：三角上界 = 各分量"正确上界"之和 ≥ 各分量真范数之和 ≥ 其中任一分量的真范数。∎

**意义.** 这把 Lead 的最初判断（"三角不等式/HS 范数不可能补上 √N 差"）严格化了：不只是"GRH 的 `(log N)²` 不够"，而是**任何**分量范数层面的改进（包括理想的 P_N 界）都不可能到 `δ_N`；到 `δ_N` 的唯一途径是**在估计内部**利用 `E_N=P_N−(D_N+K_N)` 的抵消（等价于 `O_N=P_N−D_N` 与 `K_N` 的抵消）。这正是 LL 说的 "cancellation between the components"，也正是二元 Goldbach 的定量内容。

## 2. G1：可证 [推导]

**命题 2.1（单特征标均方界）.** 在 GRH(N) 下，对每个 `χ∈X_N^-` 与 `0<σ≤β`，
```
E_χ(σ) := ∫_R |g_χ(σ+it)|²/(1+t²) dt ≪ (log N)²   （常数绝对，对 χ 与 N 一致）。
```
特别地 `(G1)` 成立：`max_{χ}‖f_χ‖²_{H_N} = 2∫_{Γ_N}|g_χ|²/(|1+s|²)|ds| ≪ (log N)²`。

**证明（沿用 LL Lemma 6.4，去掉 χ-平均）.** 逐特征标进行：
1. LL (6.10)（对照式）与 (6.12)（Perron 恒等式 + 零点计数移位）对**每个固定 χ** 成立，给出
   `|g_χ(σref+it)| ≪ |P_{χ,X}(1/2+σref+it)| + C log(N(|t|+2))`，其中 `σref=2/log N`，`P_{χ,X}` 是长度 `X=N/2` 的平滑 Dirichlet 多项式（LL p.37–38；逐 χ 版不需要平均）。
2. 单个多项式的加权均方：
   ```
   ∫_R |P_{χ,X}(1/2+σ+it)|²/(1+t²) dt
     = π Σ_{n,m≤X} Λ(n)\barχ(n)Λ(m)χ(m)w_X(n)w_X(m)(nm)^{-1/2-σ} e^{-|log(n/m)|}
     ≤ π [Σ_n Λ²(n)w_X² n^{-1-2σ} + 2Σ_{n<m}Λ(n)Λ(m)w_X² n^{1/2-σ}m^{-3/2-σ}]
     ≪ Σ_n Λ²(n)n^{-1-2σ} ≪ σ^{-2},
   ```
   最后一步：`Σ_{n≤x}Λ²(n)≪x log x` + 分部求和（与是否平均 χ 无关；`|χ|=1`）。在 `σ=σref=2/log N` 得 `≪(log N)²`。
   若 `σ<σref`，用 LL (6.14)–(6.15) 的**正性转移**（每个 χ 的 `Q_χ(σ,t)≤(σref/σ)Q_χ(σref,t)` 与 `E_χ(σ)≪K²E_χ(σref)+(log N)²`，`K=σref/σ` 有界）；若 `σ≥σref` 用 Poisson/harmonic majorant（LL 同段）。两段均逐 χ 成立。
3. 注意 `L'/L(1/2+·,χ)` 在条带上的 Euler 因子修正项 `e_χ` 满足 `|e_χ(u)|≤Σ_{p|N}log p/(p^{1/2+δ}−1)≪log N`，逐 χ；零点计数 (3.5) 中 `d_χ≤N` 使常数对 χ 一致。
故 `E_χ(α_N)≪(log N)²`，一致于 χ。∎

**备注.** G1 的证明只用到 LL 已有的机器（Perron/零点计数/正性转移），不需要 χ-平均；因此 (G1) 是"已具备但未被 LL 写出的"结论。不过如 §1 所示，G1 本身对 `R` 没有实质帮助（被 `D_N+K_N` 淹没）。

## 3. G2：攻击与障碍

### 3.1 精确形式

记 `f_χ=g_χ/(1+s)∈H_N`，`G_{χψ}=⟨f_χ,f_ψ⟩_{H_N}`。由 `P_N=(2/φ(N))Σ_χ|f_χ⟩⟨f_χ|`（PSD，秩 `≤φ(N)/2`）：
```
‖P_N‖²_HS = (2/φ(N))² Σ_{χ,ψ}|G_{χψ}|² = (2/φ(N))²[ Σ_χ‖f_χ‖⁴ + Σ_{χ≠ψ}|G_{χψ}|² ].
```
目标 (G2)：`Σ_{χ≠ψ}|G_{χψ}|² ≪ φ(N)^{-1}(Σ_χ‖f_χ‖²)²`。等价地（用 `Σ_χ‖f_χ‖²=(φ/2)tr P_N`）：
```
(G2) ⇔ tr(G²) ≪ (tr G)²/φ(N)   ⇔  G 的谱"平坦"（有效维数 ≳φ(N)）。
```
**平凡界**：`|G_{χψ}|²≤‖f_χ‖²‖f_ψ‖² ⇒ Σ_{χ≠ψ}|G|²≤(Σ‖f‖²)²=tr(G)²` — 需要节省因子 `φ(N)`。这是实质性的（要把 `φ²` 个无序对的"随机抵消"降到 `φ`）。

### 3.2 三种攻击路线及其停止点

**(a) 大筛/特征标正交性 [推导 → 停止]：** 大筛（Montgomery–Vaughan；Iwaniec–Kowalski Thm 7.2x 型）给出的是**对 χ 的平均**
`Σ_{χ mod N} |Σ_{n≤N}a_nχ(n)|² ≪ (N+Q)Σ|a_n|²`，即 Gram 矩阵的**迹**（`tr G`，LL Lemma 6.4 的平均版）。要控制 `Σ_{χ≠ψ}|G|²` 需要**四阶**（两个 χ、两个 ψ）估计——大筛没有这个方向的结果。
**(b) 近似函数方程 + 特征标正交性 [推导 → 遇到跨位移相关]：** 在 GRH 下，`g_χ(σ+it)` 在条带内可由长度 `√N` 的 Dirichlet 多项式逼近（近似函数方程，误差 `O(log N)`；LL Lemma 3.4 的零点展开已隐含此结构）。代入 `G_{χψ}` 得
```
G_{χψ} ≈ π Σ_{n,m≤√N} Λ(n)\barχ(n)Λ(m)ψ(m) a_n a_m (nm)^{-1/2-σ} e^{-|log(n/m)|} · (位相因子)
```
由于 `e^{-|log(n/m)|}` 强制 `n≈m`，主项需要
```
Σ_{n} χ(n)\barψ(n+d) Λ(n)Λ(n+d) (n(n+d))^{-1/2-σ}·(权重)   （d 小）
```
的**跨位移特征标相关**。对 `χ≠ψ`，完整区间上的正交性 `Σ_{n≤N}χ(n)\barψ(n+d) = O(√N log N)`（Pólya–Vinogradov 型，`d` 固定；一般 `(χ,ψ,d)` 情形的界不强于此）**不足以**产生所需的 `φ^{-1/2}` 节省：把 `O(√N log N)` 平方后对 `φ² 个 (χ,ψ)` 对求和给出 `φ²·N log²N`，远大于目标 `φ·(log N)^4`。换言之，逐对的相关虽"小"（相对 `N`），但对 `φ²` 对求和后爆炸。
**(c) 谱/预迹公式 [推测 → 无通道]：** `G` 的平坦性等价于族 `{g_χ}` 在 `H_N` 中"等分布"（各方向权重相当）。零点展开下 `G_{χψ}` 是零点纵标的双重 Cauchy 和；`tr(G²)` 是四重和。这又回到 KT2 §3.1 的零点四阶加性能量——没有任何已知技术（包括 Montgomery 对相关，它本身是猜想且只是二阶）。

### 3.3 G2 是否可能为真？与"真超平面"障碍的关系

- **与 KT2 命题 4.2 无关**：4.2 说的是 Goldbach 型数据（Riesz 向量族）不能决定 `T_N`；G2 是关于 `P_N` 谱（`T_N` 的一个分量）的陈述，二者方向不同，不矛盾。
- **[推测] G2 可能为真**：启发式上，`φ(N)` 个 Dirichlet 特征标的 `L'/L` 在条带内应"互不相关"（随机矩阵/矩启发），Gram 矩阵近似对角、谱平坦是自然的。但即使为真，由 §1.4 它对 `R` **没有帮助**：`T_N` 的三角界被 `D_N+K_N` 的 `(log N)^{3/2}` 卡住，与 `P_N` 的精确范数无关。
- 结论：**G2 是一个独立有趣的算术/解析问题，但不是 LL 路线到 Goldbach 的墙**。KT2 §2.5 把它称为"最有希望的具体目标"是**错误判断**，本报告撤回。

### 3.4 数值

- 独立估计 `{G_{χψ}}` 需要 2880 个奇特征标 mod 30030 的 `L'/L` 值（Hurwitz 公式 + FFT，规模可行但需 ~10–20 min 编码 + 运行），本报告时间盒内未完成。
- **不使用** `spectral-numerics` 的 H=40 矩阵（据 Lead 信息其范数 ≈105 与 LL 声称 0.827 差距大，可能其模型/截断有误或未正确实现 `K_N` 抵消；待其独立核验）。注意到 105 恰与 `(log N)²=106.3` 同量级——这与"若省略 `K_N`（即不利用 §1.2 的双极点抵消）则 `‖D_N‖~1/(4α²)=(log N)²/4` 或 `‖P_N‖~tr P_N~(log N)²`"的量级一致，但**不能**据此判断谁对谁错，需数值组的独立实现。

## 4. task-9 判定（给 Lead 的最终答复）

1. **Prop 2.7 已撤回/修正**：正确结论是 `(G1)+(G2) ⇒ ‖P_N‖_HS≪(log N)²/√N`，但三角界仍为 `O((log N)^{3/2})`；**gap 仍是 √(N/S(N))（√N 级），不是 √log**。
2. **`‖D_N+K_N‖_HS ≍ (log N)^{3/2}`**（两条边都证，单极点系数 `κ_N=log N−log2π+ψ(3/4)+O(log²(1/w))`），`(1−X1X1')w^{-2}` 项被吸收为 `−X1'(0)/w`，无更坏残留。
3. **triangle 路线的严格天花板 = Ω((log N)^{3/2})**（命题 1.4）：任何分量 HS 范数改进（包括理想的 `P_N` 界）都到不了 `δ_N`。要证 `R` 必须在估计内部利用 `E_N` 的抵消（= LL 的 arithmetic cancellation = 二元 Goldbach 定量内容）。
4. **G1 可证**（用 LL 已有 Perron/零点计数逐 χ，无需平均）；**G2 不可证且对 `R` 无用**；G2 等价于 Gram 谱平坦（有效维数 ≳φ(N)），需要跨特征标四阶相关，现有大筛/近似函数方程/正交性都不够。
5. **对 LL 墙的最终判定（不变、更硬）**：墙仍是 √N，本质是 `O_N` 与 `K_N` 的抵消（等价于二元 Goldbach 的定量形式），**不是** Gram 平坦性，也**不是**一个 √log 的松因子问题。2026 的 Alpöge 机器（零点/多重性/正性）依旧无通道。
