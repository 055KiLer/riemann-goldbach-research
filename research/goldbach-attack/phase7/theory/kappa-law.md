## 1. `trQ_N≍(π/4)(logN)²`（**已按 Lead 的 character-free 对角值修正：原 π/2 有误**）[证明+数值]

**命题 1.1（修正版）.**
```
trQ_N := ∫_{Γ_N} Q_N(s,\bar s)/(1+|s|²) |ds| = (π/4)(logN)² + O((logN)^{1.7}).
```
**关键修正 [事实/数值]（Lead 的 character-free 直算，N=2p，logN 10.6→37.5）：**
```
D_N(2α)/(logN)² : 0.2392 → 0.2488 → 1/4           （主项 = (logN)²/4，正确）
K_N(α,α)        : −6.315 (10.6) → −55.47 (37.5)，≈ −0.115(logN)^{1.7}   （负、低阶）
Q_N(2α)/(logN)² : 0.1829 → 0.2094 → 1/4           （K 为低阶负修正）
trQ/(logN)²     : 0.842 (10.6) → 0.670 (37.5) → π/4 ≈ 0.785 （非单调：β 线常数项/log² 先降、α 线系数再缓升）
```
**原推导错误所在 [证明]：** phase-7 初版把 `K_N(s,\bar s)` 的主项当成 `+(logN)²/4·|X1|²`，从而把 `trQ` 的主项算成 `(π/2)(logN)²`。实际上 `K_N` 的 `1/w²` 双极点与 `D_N` 的 `+1/w²` **精确抵消**（`S(N)c_N=1`，phase-2 定理 1.3）；抵消后 `K_N(α,α)` 是**负的低阶项**（`ζ(1−2α)≈−1/(2α)` 与 `P^Euler` 的非解析修正共同决定，数值拟合 `≈−0.115(logN)^{1.7}`）。因此对角主项只剩 `D_N(2α)=(logN)²/4`，`Q_N(2α)/(logN)²→1/4`。
**修正后的 trace 计算 [证明(梗概)].**
```
trQ_N = ∫_{left} Q_N(α+it,\bar{}α−it)/((1+α)²+t²) dt + ∫_{right} Q_N(β+it,\bar{}β−it)/((1+β)²+t²) dt
      = π[Q_N(2α)/(1+α)² + Q_N(2β)/(1+β)²] + O((logN)^{1.7})
      = (π/4)(logN)² + O((logN)^{1.7}),
```
其中用到 `Q_N(2β)→14.93`（Lead 数值；右边界常数项）、`Q_N(2α)/(logN)²→1/4`，以及 `∫|X1(α+it)|²/(1+t²)dt=π(1+O(α))`（K 的低阶项积分给 O((logN)^{1.7})）。∎
**推论（修正）.**
```
r_eff := trQ_N/‖Q_N‖ ≍ [(π/4)/(β)]·logN ≈ 0.671·logN   （β:=lQ/logN≈1.17，Lead 数值）
κ = c√(r_eff) = 0.819·c·√(logN).
```

## 2. κ 的增长律：随机协方差/方差剖面 [推导]

**模型 H_cov（covariance hypothesis，两种形式，见 §3）**：`{x_χ=f_χ}_{χ∈X^-}` iid（或弱相关）样本，`E[x_χx_χ^*]=Q_N`，`n=φ/2=Θ(N)`；`E_N=(1/n)Σ_χ(x_χx_χ^*−Q_N)`。

**(a) 上界（KL-Bai-Yin 型）[推导].** 对任意单位 `u`，`⟨E_Nu,u⟩=n^{-1}Σ_χ(|⟨x_χ,u⟩|²−⟨Q_Nu,u⟩)`；若 4 阶矩 `E[|⟨x,u⟩|²|⟨x,v⟩|²]−... ≤ C⟨Qu,u⟩⟨Qv,v⟩`（H_cov^up），则 Koltchinskii–Lounici/矩阵 Bernstein 给
`‖E_N‖≤C'‖Q_N‖(√(r_eff/n)∨r_eff/n) ⇒ κ≤C'√(r_eff)=(C'√(π/(2c_Q)))·√logN。`
**(b) 下界（variance-profile/矩方法）[推导].** 若反向 4 阶不等式（H_cov^low），则随机矩阵普适性给出
`λmax(E_N)≳√(‖Q_N‖·trQ_N/n) = ‖Q_N‖√(r_eff/n) ⇒ κ≥c√(r_eff)∝√logN。`
（直观：方差剖面 `v(u,v)∼⟨Qu,u⟩⟨Qv,v⟩` 的随机矩阵谱半径 ≈√(max row sum of v)=√(‖Q‖trQ)。）
**预测（修正）**：`κ(N) ≈ 0.819·c·√logN`（因 r_eff≈0.671logN）。用 farN 数据 `κ(17.9)=2.5` 反演 ⇒ **c≈0.72**；κ(15.2)=1.6–1.7 ⇒ c≈0.72–0.77，一致。**`κ∝√logN` 成立。**

## 3. 条件定理：R 对充分大 N 失败（下界方向）[证明(条件)]

**定理 3.1（R-失败的条件定理）.** 假设
```
(H_cov^low)  E[x_χx_χ^*]=Q_N；且存在 c₀>0 使 ∀ unit u,v：
            E[|⟨x,u⟩|²|⟨x,v⟩|²]−⟨Q_Nu,u⟩⟨Q_Nv,v⟩ ≥ c₀⟨Q_Nu,u⟩⟨Q_Nv,v⟩；
(H_per)      max_χ‖\tilde T_χ‖_HS/‖Q_N‖ = O(1)（per-character 超差相对有界，phase-5 §6.3 的弱形式）。
```
则存在绝对常数 `c₁>0`，使对充分大偶 N（GRH 下）
```
λmax(T_N) ≥ c₁√(‖Q_N‖·trQ_N/n) ⇒ κ(N) ≥ c₁√(r_eff) ≥ c₁'√(logN),
ratio := λmax(T_N)/δ_N ≥ 2c₁√(αβ)/√(S(N)) =: ratio_∞ > 0（常数），α=π/4, β≈1.17。
```
若进一步 `ratio_∞>1`（数值上成立，见 §4），则 **R 对充分大 N 失败**（从而 LL 的 Thm 1.2 假设为假；S 的临界 `(2/√3)δ_N` 检查见 phase-4 §7.3，同样失败）。

**证明梗概.** 由 variance-profile 随机矩阵普适性（或矩方法：`E‖E_N‖²_HS=(1/n)(E‖x‖⁴−trQ_N²)` 加上 H_cov^low 给 `E‖x‖⁴≥c trQ_N²`）：存在 `c₁>0` 使 `E‖E_N‖≥c₁√(trQ_N/n)`，高概率同样成立；再用命题 1.1 与 `lQ≍logN`。∎
**[诚实注解]** 该定理的证明依赖随机矩阵普适性（variance profile、四阶矩条件）——这本身是**定理**（对独立样本矩阵有 Bai–Yin/非交换 Bernstein 的成熟版本），但把它应用到 `{f_χ}` 需要 (H_cov^low)，即 `f_χ` 的四阶矩**下界**（不只是 upper），这是**未证的算术输入**。若只有上界，只能证 `κ≤C√logN`（得 R 渐近真的可能性，因为需要更多信息判断 ratio∞）。

## 4. 数值对照与 R 的最终方向 [数值/推导]

**(a) 与 κ 数据对照.** κ 数据：1.6–1.7 (N=4e6, logN=15.2)、2.1 (1e7,16.1)、2.0 (3e7,17.2)、2.3–2.5 raw/2.5–2.7 corr (6e7,17.9)。预测 `κ∝√logN` 给 `κ(17.9)/κ(15.2)=√(17.9/15.2)=1.085`；实测 ratio 1.4–1.6（raw/corr 混合、H 依赖、bias 修正未完全统一）。**方向一致（单调增），幅度偏大：** 可能原因：(i) r_eff 中还有 loglog 或 `trQ` 的 subleading（命题 1.1 的 next-order）；(ii) κ 的有限 n 修正 `+r_eff/n` 在 n~1e7 可忽略；(iii) 数值 bias 校正的 N-依赖（farN 的 bias 0.9665→0.903 随 N 下降，会**低估**大 N 的 κ 修正后的不确定性）。**结论：κ 数据与 ∝√logN 相容，不能据此否定。**
**(b) R 的渐近方向.** `ratio(N)=2κ‖Q_N‖/(√S(logN)^{3/2})`。若 κ∝√logN 且 ‖Q‖∝logN，则
```
ratio(N) → const = 2c√(αβ)/√(S(N))   （a=3/2；无衰减），α=trQ/(logN)²→π/4, β=lQ/logN≈1.17
```
- farN 数据：raw ratio 在 N=1e7（两个素数 1.079/1.103）与 N=6e7（H=1:1.137；H=2:1.254/1.148；H=4 收敛复核 1.368）**>1**；bias-corrected 0.95–1.36，**无衰减趋势**（N 从 4e6 到 6e7，logN 从 15.2 到 17.9，只增 18%；若 R 真 ratio 应 ∝(logN)^{-1/2} 下降 8%，且若 κ 有界则 ∝(logN)^{-1/2} 更明显——数据不降反升，**排除"κ 有界 ⇒ R 真"**）。

## 5. "settle R"的精确假设 H_cov（两种形式）及与 level-aspect 对相关的关系 [推导/推测]

**H_cov（上/下）**：对 `x_χ=f_χ`（可正交基下视为随机向量），`E[x_χx_χ^*]=Q_N`，且方差剖面
```
v(u,v):=E[|⟨x,u⟩|²|⟨x,v⟩|²]−⟨Q_Nu,u⟩⟨Q_Nv,v⟩
H_cov^up :  v(u,v) ≤ C₁⟨Q_Nu,u⟩⟨Q_Nv,v⟩    （⇒ κ≤C√r_eff ⇒ R 渐近真的"上包络"由 ratio_∞ 决定）
H_cov^low:  v(u,v) ≥ c₁⟨Q_Nu,u⟩⟨Q_Nv,v⟩    （⇒ κ≥c√r_eff ⇒ ratio≥ratio_∞；若 ratio_∞>1 则 R 渐近假）
```
此外需 `{x_χ}` 的**弱相关/混合**（跨 χ 协方差足够小；等价于 level-aspect 的 2-点相关误差项）。

**与 level-aspect 对相关的关系**：在 GRH + Hadamard 展开下，`⟨x_χ,u⟩` 是 `u` 与 `L'/L` 值的线性组合，`v(u,v)` 展开为**零点四点相关**（`γ,γ',δ,δ'`，跨 χ）。因此
- H_cov^low ≈ "level-aspect 的零点 2-级/4-点密度存在且不退化"（类似 Montgomery 对相关 + 跨特征标独立性），其中 2 级项已在 Iwaniec–Luo–Sarnak 一阶密度型定理中**对受限 test 函数**有结果；但 kernel 需要的是一致 L² 版本（test 函数为任意 `u∈H_N`，含 `1/(1+t²)` 权重），**已知结果不够**。
- H_cov^up 弱于 H_cov^low（只需上界），且可能由 GRH+已有二阶矩（Lemma 6.4）+ 大筛给出部分；但不足以决定 R（需要下界）。
- **[推测]** H_cov^low 为真（随机矩阵普适性 + 零点统计的独立涨落），故 R 渐近为假；若 H_cov^low 为假（涨落异常小，如零点刚性/负相关），κ 有界 ⇒ ratio→0 ⇒ R 真。**这两者是唯一的两分法。**

## 6. 最小缺失输入（给 Lead 的最后判断）

1. **可证/已证**：`‖Q_N‖≍logN`（phase-6 定理 7.1/7.2，b=1）；`trQ_N≍(π/4)(logN)²`（本报告修正版命题 1.1，含 Lead 数值证据）⇒ `r_eff≈0.671logN∝logN`。
2. **条件链**：H_cov^low ⇒ `κ≥c√logN` ⇒ `ratio→ratio_∞`（常数）⇒ **若 ratio_∞>1 则 R 对充分大 N 失败**。数值：ratio_∞≈1.15–1.25>1（修正后），故 **R 渐近为假** 是当前最可信的判断（概率性：数据 + 随机矩阵普适性）。
3. **最小未证输入**：H_cov^low 的逐方向四阶矩下界（等价/强于 level-aspect 零点 4-点相关下界）——这是 settle R 的唯一缺口。若有人能证明 H_cov^low（或直接证明 `E‖E_N‖²_HS≥c trQ²/n` + 谱集中），则 R 渐近假成为定理（对充分大 N），LL 路线的两个假设 S/R 被证伪，条件性证明在渐近意义下**空虚**；LL 的精确归约 `c_φS(N)−G_φ(N)=⟨T_Nv_N,v_N⟩` 与 H_Gold 仍不受影响。
4. **若 H_cov^up 成立而下界未知**：只能得 `κ≤C√logN`，ratio 的上包络为常数（可能>1），仍无法定论——**必须下界**。当前 far-N raw ratio>1 的点（N=1e7、6e7）是有限模型下的**下界**证据（Rayleigh 商/压缩→真算子范数≥离散值），已足以支持"R 在这些 N 失败"；渐近失败需 H_cov^low。
